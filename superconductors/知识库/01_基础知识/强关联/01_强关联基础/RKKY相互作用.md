# RKKY 相互作用

RKKY 相互作用（Ruderman-Kittel-Kasuya-Yosida）是描述**两个局域磁矩之间通过传导电子产生长程磁耦合**的理论模型。

## 物理图像：传导电子作为"信使"

在金属基底中，两个距离为 $R$ 的局域磁矩（如两个 4f 电子）之间距离很远，直接的交换相互作用几乎为零。RKKY 的作用过程：

1. **极化源**：第一个局域磁矩通过交换作用影响周围传导电子，产生自旋密度极化
2. **长程传递**：自旋极化以振荡波形式在晶格中向外传播
3. **磁耦合**：第二个磁性杂质感受振荡的自旋密度波，调整方向以最小化总能量

## 数学特征

$$J(R) \propto \frac{\cos(2k_F R)}{R^3}$$

- **振荡性**：随距离正弦/余弦振荡 → 铁磁或反铁磁排列取决于距离
- **衰减性**：按 $R^3$ 衰减（长程相互作用）
- **$k_F$ 角色**：费米波矢决定振荡周期——证明传导电子是媒介

## Doniach 相图：与近藤效应的竞争

这是重费米子物理的核心。两种效应相互竞争：

| | 近藤效应 | RKKY 相互作用 |
|---|---|---|
| 倾向 | 屏蔽局域磁矩 → 非磁性费米液体 | 锁定磁矩 → 磁有序 |
| 特征能量 | $T_K \propto e^{-1/J}$ | $T_{RKKY} \propto J^2$ |
| J 小时 | $T_K$ 极小（被压制） | $T_{RKKY}$ 主导 → 磁有序 |
| J 大时 | $T_K$ 主导 → 费米液体 | $T_{RKKY}$ 被超越 |

在两者的临界点附近 → **量子临界现象**或**非常规超导**。

## Doniach 相图的数学本质

理解 Doniach 相图的关键在于两条线对 $J\rho$ 不同的函数依赖：

$$T_K \sim \rho^{-1} e^{-1/(J\rho)} \quad (\text{指数})$$
$$T_{RKKY} \sim J^2 \rho \quad (\text{幂律})$$

这是整个重费米子物理中最重要的两组能量尺度对比。两条线的竞争决定了基态：

- **小 $J\rho$（左侧，蓝色 AFM 区）**：$e^{-1/x}$ 在 $x \to 0$ 时趋于零的速度远快于 $x^2$，所以 $T_{RKKY} > T_K$。RKKY 的"磁矩排队"跑赢了近藤的"磁矩屏蔽"，基态是反铁磁。

- **大 $J\rho$（右侧，橙色 FL 区）**：指数函数反超幂函数，$T_K > T_{RKKY}$。近藤屏蔽在磁矩之间还没来得及"商量"排列时就已经将磁矩消灭，基态是重费米液体。

- **$J_c\rho$（交点，QCP）**：这是 $T=0$ 时磁性和非磁性两种基态之间的分界——量子临界点。此处两个能量尺度相等，量子涨落最强，费米面体积跳变，有效质量发散。
