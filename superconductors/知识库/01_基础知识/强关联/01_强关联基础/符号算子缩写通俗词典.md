# 符号 · 算子 · 缩写通俗词典

> 面向铜氧化物 / 强关联超导文献里常见符号与缩写。  
> 每条尽量给出：**是什么 → 相关现象 → 关键公式 → 一句话通俗理解**。

---

## 一、字符（Symbols）

### $\delta_{ij}$ — Kronecker 符号（Kronecker tensor / delta）

| 项目 | 内容 |
|------|------|
| **是什么** | 指标张量：$i=j$ 时为 1，否则为 0 |
| **相关现象** | 正交归一、自旋求和、迹运算、各向同性项的写法 |
| **公式** | $\delta_{ij}=\begin{cases}1,&i=j\\0,&i\neq j\end{cases}$；$\sum_i\delta_{ij}=1$ |
| **通俗** | 「选同一个座位才算 1」的指示灯；用来把求和里不相干的项清掉 |

---

### $\sigma^{x,y,z}$ — Pauli 矩阵

| 项目       | 内容                                                                                                                                                                                                                                    |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **是什么**  | 自旋 $1/2$ 的三个厄米、幺正生成元                                                                                                                                                                                                                  |
| **相关现象** | 电子自旋、Zeeman 劈裂、自旋涨落配对胶水、Rashba SOC                                                                                                                                                                                                    |
| **公式**   | $\sigma^x=\begin{pmatrix}0&1\\1&0\end{pmatrix},\ \sigma^y=\begin{pmatrix}0&-i\\i&0\end{pmatrix},\ \sigma^z=\begin{pmatrix}1&0\\0&-1\end{pmatrix}$；$\{\sigma^a,\sigma^b\}=2\delta_{ab}$；$[\sigma^a,\sigma^b]=2i\epsilon_{abc}\sigma^c$ |
| **通俗**   | 描述「自旋朝哪边」的三个最简矩阵工具箱；自旋向上/向下就是 $\sigma^z$ 的本征态                                                                                                                                                                                         |

---

### $I_{ij}$ — 单位张量（identity）

| 项目       | 内容                                                  |
| -------- | --------------------------------------------------- |
| **是什么**  | 恒等映射：$I_{ij}=\delta_{ij}$                           |
| **相关现象** | 弹性理论、电流响应 $\mathbf{j}=\sigma\cdot\mathbf{E}$、各向同性介质 |
| **公式**   | $I\cdot\mathbf{v}=\mathbf{v}$；$I=\mathbb{1}$        |
| **通俗**   | 「原样输出」按钮；写进张量方程时表示没有方向偏好的那一部分                       |

---

### $e$ — 电子电荷

| 项目 | 内容 |
|------|------|
| **是什么** | 基本电荷，$e\approx 1.602\times10^{-19}\,\mathrm{C}$（常取正值，电子电荷写 $-e$） |
| **相关现象** | 霍尔效应、约瑟夫森电流、磁通量子、库仑排斥 $U$ |
| **公式** | $\Phi_0=h/(2e)$（超导磁通量子）；$E=eV$；$U\sim e^2/(\varepsilon r)$ |
| **通俗** | 电荷的「货币单位」；超导电性里成对电子让磁通量子变成 $h/2e$ |

---

### $k_B$ — 玻尔兹曼常数

| 项目 | 内容 |
|------|------|
| **是什么** | 能量与温度的换算因子，$k_B\approx 1.381\times10^{-23}\,\mathrm{J\cdot K^{-1}}$ |
| **相关现象** | 热激发、比热、费米–狄拉克分布、临界温度标度 |
| **公式** | $E\sim k_BT$；$n_F(\varepsilon)=(e^{(\varepsilon-\mu)/k_BT}+1)^{-1}$；$C\sim\gamma T$ 中 $\gamma$ 含 $k_B$ |
| **通俗** | 「温度说人话」的翻译器：$T$ 乘上 $k_B$ 就变成能量 |

---

## 二、算子（Operators）

### $\nabla$ — 梯度 / 散度 / 旋度算符

| 项目 | 内容 |
|------|------|
| **是什么** | 空间微分算符；在坐标表象里 $\nabla=(\partial_x,\partial_y,\partial_z)$ |
| **相关现象** | 电流连续性、Ginzburg–Landau 序参量空间变化、自旋流、拓扑 Berry 曲率相关的梯度结构 |
| **公式** | $\mathbf{j}=-D\nabla n$；$\mathbf{B}=\nabla\times\mathbf{A}$；GL：$f=a|\psi|^2+\frac{b}{2}|\psi|^4+\frac{\hbar^2}{2m^*}|(-i\nabla-\frac{2e}{\hbar}\mathbf{A})\psi|^2$ |
| **通俗** | 「哪里高往哪里指」；告诉你物理量在空间里怎么变 |

---

### $\mathrm{Re}$ / $\mathrm{Im}$ — 实部 / 虚部

| 项目 | 内容 |
|------|------|
| **是什么** | 取复数的实数部分 / 虚数部分 |
| **相关现象** | 格林函数响应、光学电导 $\sigma(\omega)$、自能 $\Sigma(\omega)$、超导能隙相位 |
| **公式** | $z=\mathrm{Re}\,z+i\,\mathrm{Im}\,z$；$\sigma_1=\mathrm{Re}\,\sigma(\omega)$（耗散），$\sigma_2=\mathrm{Im}\,\sigma(\omega)$（惯性响应） |
| **通俗** | 把「带相位的复数答案」拆成：真在耗散的（Re）和在存相位/惯性的（Im） |

## 三、相与现象缩写（Phases & Phenomena）

### QCP — Quantum Critical Point（量子临界点）

| 项目 | 内容 |
|------|------|
| **是什么** | $T=0$ 处、由量子涨落驱动的连续相变临界点 |
| **相关现象** | 奇异金属、非费米液体、重费米子 Doniach 相图、铜氧化物最佳掺杂附近 |
| **公式** | 调参 $g\to g_c$ 时关联长度 $\xi\sim|g-g_c|^{-\nu}$；动力学标度 $\tau\sim\xi^z$；奇异金属常伴 $\rho\sim T$ |
| **通俗** | 绝对零度上的「相变悬崖」；附近量子涨落最猛，往往催生非常规超导 |

---

### BCS — Bardeen–Cooper–Schrieffer

| 项目 | 内容 |
|------|------|
| **是什么** | 常规超导微观理论：声子介导吸引 → 库珀对 → 能隙 |
| **相关现象** | 同位素效应、全能隙、Meissner、约瑟夫森效应；氢化物超导的主范式 |
| **公式** | $\Delta=2\hbar\omega_D e^{-1/(N(0)V)}$；$k_BT_c\approx 1.14\,\hbar\omega_D\,e^{-1/(N(0)V)}$；$E_k=\sqrt{\xi_k^2+\Delta^2}$ |
| **通俗** | 「两个电子借声子当媒人结成对」；你以前做氢化物时的理论老家 |

---

### AFM — Antiferromagnetic（反铁磁）

| 项目 | 内容 |
|------|------|
| **是什么** | 近邻自旋反向排列的磁有序 |
| **相关现象** | 母体铜氧化物 Mott 反铁磁绝缘体、自旋涨落媒介 $d$ 波配对、SDW |
| **公式** | Heisenberg：$H=J\sum_{\langle ij\rangle}\mathbf{S}_i\cdot\mathbf{S}_j$（$J>0$ 为 AFM）；奈尔波矢常为 $(\pi,\pi)$ |
| **通俗** | 「你朝上我朝下」的棋盘磁序；铜氧化物母体就是这种，掺杂后磁序融化、超导出现 |

---

### FM — Ferromagnetic（铁磁）

| 项目 | 内容 |
|------|------|
| **是什么** | 自旋同向排列的磁有序 |
| **相关现象** | 铁磁量子临界、三重态超导候选、Stoner 不稳定性 |
| **公式** | $J<0$ 的 Heisenberg；Stoner：$IN(E_F)>1$ |
| **通俗** | 「大家朝同一边」的磁铁态；与 AFM 相对 |

---

### CDW — Charge Density Wave（电荷密度波）

| 项目 | 内容 |
|------|------|
| **是什么** | 电荷密度在实空间形成周期性调制 |
| **相关现象** | 铜氧化物赝能隙区、过渡金属硫化物、与超导竞争/共存 |
| **公式** | $\rho(\mathbf{r})=\rho_0+\rho_1\cos(\mathbf{Q}\cdot\mathbf{r}+\phi)$；Peierls 型能隙打开 |
| **通俗** | 电荷自己「排成波纹」；像电子密度的驻波，常与超导抢电子 |

---

### SDW — Spin Density Wave（自旋密度波）

| 项目 | 内容 |
|------|------|
| **是什么** | 自旋密度的周期性调制（可视为巡游版 AFM） |
| **相关现象** | 铬、铁基超导父相、铜氧化物低掺杂条纹相 |
| **公式** | $\mathbf{S}(\mathbf{r})=\mathbf{S}_Q\cos(\mathbf{Q}\cdot\mathbf{r})$；常由费米面嵌套驱动 |
| **通俗** | 磁矩大小/方向像波浪一样在空间起伏；比刚性奈尔 AFM 更「金属味」 |

---

### PDW — Pair Density Wave（配对密度波）

| 项目 | 内容 |
|------|------|
| **是什么** | 库珀对密度/相位在空间周期调制的超导态（有限动量配对的一类） |
| **相关现象** | 铜氧化物条纹、与 CDW 交织、FFLO 的近亲概念 |
| **公式** | $\Delta(\mathbf{r})=\Delta_Q e^{i\mathbf{Q}\cdot\mathbf{r}}+\Delta_{-Q}e^{-i\mathbf{Q}\cdot\mathbf{r}}$ |
| **通俗** | 超导「强度」本身也在空间里起波浪，不是均匀一块超导体 |

---

### FFLO — Fulde–Ferrell–Larkin–Ovchinnikov

| 项目 | 内容 |
|------|------|
| **是什么** | 强磁场/自旋极化下，库珀对带有限质心动量 $\mathbf{q}\neq0$ 的超导态 |
| **相关现象** | 重费米子 CeCoIn₅ 高场 Q 相、有机超导、自旋不平衡配对 |
| **公式** | FF：$\Delta(\mathbf{r})=\Delta_0 e^{i\mathbf{q}\cdot\mathbf{r}}$；LO：$\Delta(\mathbf{r})=\Delta_0\cos(\mathbf{q}\cdot\mathbf{r})$ |
| **通俗** | 正常 BCS 对「相对静止」；FFLO 对在「一边跑一边配对」，超导序参量带空间相位/节点 |

相关笔记：[[Q相与FFLO态]]

---

### BKT — Berezinskii–Kosterlitz–Thouless

| 项目 | 内容 |
|------|------|
| **是什么** | 二维体系中由涡旋–反涡旋束缚驱动的拓扑相变（无长程序、有准长程序） |
| **相关现象** | 二维超导体、超导薄膜、$T_c$ 与相位刚度关系、Mermin–Wagner 约束下的出路 |
| **公式** | 跃迁时 $2\pi\rho_s/T_{\mathrm{BKT}}=4$（通用跳跃）；涡旋能量 $\sim\pi\rho_s\ln(L/a)$ |
| **通俗** | 二维不能有真正长程有序，但「涡旋成对绑住」时仍可超导；热到一定程度涡旋散开就毁了 |

---

### BEC — Bose–Einstein Condensation（玻色–爱因斯坦凝聚）

| 项目 | 内容 |
|------|------|
| **是什么** | 大量玻色子占据同一宏观量子态 |
| **相关现象** | 预成型对的 BEC 极限、冷原子、BCS–BEC 交叉 |
| **公式** | 理想 3D 玻色气：$T_{\mathrm{BEC}}\propto n^{2/3}/m$；BCS–BEC 由 $1/(k_Fa_s)$ 调控 |
| **通俗** | 「所有粒子挤进同一个量子房间」；强束缚库珀对极限 ≈ 分子玻色气体凝聚 |

---

### RVB — Resonant Valence Bond（共振价键）

| 项目 | 内容 |
|------|------|
| **是什么** | Anderson 提出：自旋单态价键共振液体，无磁长程序 |
| **相关现象** | 掺杂 Mott 绝缘体、铜氧化物早期理论、量子自旋液体思路 |
| **公式** | 价键单态 $(|\uparrow\downarrow\rangle-|\downarrow\uparrow\rangle)/\sqrt{2}$；掺杂后空穴运动 + 单态背景 → 超导图像 |
| **通俗** | 自旋两两牵手成「单态舞伴」，整张晶格不断换舞伴共鸣；掺空穴后可能变成超导 |

## 四、实验探针缩写（Probes）

### NMR — Nuclear Magnetic Resonance（核磁共振）

| 项目 | 内容 |
|------|------|
| **是什么** | 用核自旋共振探测局域静磁场与自旋动力学 |
| **相关现象** | Knight 位移（测自旋磁化率）、$1/T_1$（自旋涨落）、能隙节点、AFM 涨落增强 |
| **公式** | $1/T_1T\propto\sum_{\mathbf{q}}|A(\mathbf{q})|^2\,\mathrm{Im}\chi(\mathbf{q},\omega_0)/\omega_0$；Knight：$K\propto\chi_s$ |
| **通俗** | 把原子核当「本地间谍」，听电子自旋在附近晃得有多欢 |

---

### MMP — Millis–Monien–Pines

| 项目 | 内容 |
|------|------|
| **是什么** | 描述铜氧化物近 AFM 波矢自旋涨落的唯象磁化率模型 |
| **相关现象** | NMR $1/T_1$、$T_{2G}$、自旋涨落介导 $d$ 波配对的输入谱 |
| **公式** | $\chi(\mathbf{q},\omega)\approx\frac{\chi_Q}{1+(\mathbf{q}-\mathbf{Q})^2\xi^2-i\omega/\omega_{\mathrm{sf}}}$（典型 MMP 形式） |
| **通俗** | 「反铁磁附近自旋涨落长什么样」的经验配方；很多铜氧化物理论拿它当胶水谱 |

---

### ARPES — Angle-Resolved Photoemission Spectroscopy

| 项目 | 内容 |
|------|------|
| **是什么** | 角分辨光电子能谱：直接测占据态能带 $E(\mathbf{k})$ |
| **相关现象** | 费米面、超导能隙各向异性、$d$ 波节点、赝能隙、能带重整化 |
| **公式** | 光电子强度 $\propto |M|^2 A(\mathbf{k},\omega)f(\omega)$；谱函数 $A=-\frac{1}{\pi}\mathrm{Im}G^R$ |
| **通俗** | 给晶体「拍照出电子的能量–动量地图」；看能隙在费米面上哪里深、哪里是零 |

---

### STM / STS — Scanning Tunneling Microscope / Spectroscopy

| 项目 | 内容 |
|------|------|
| **是什么** | 扫描隧道显微镜/谱：原子尺度局域态密度 |
| **相关现象** | 能隙空间 inhomogeneity、涡旋芯态、CDW/PDW 实空间图案、QPI |
| **公式** | $dI/dV\propto\rho(\mathbf{r},eV)$ |
| **通俗** | 针尖贴着表面「听」每个原子附近有多少电子态；把超导能隙画成地图 |

---

### QPI — Quasiparticle Interference（准粒子干涉）

| 项目 | 内容 |
|------|------|
| **是什么** | 杂质散射导致的准粒子驻波；STM 傅里叶变换后得 $\mathbf{q}$ 空间图案 |
| **相关现象** | 重建费米面连接、能隙对称性判定、杂质束缚态 |
| **公式** | 散射矢量 $\mathbf{q}=\mathbf{k}_f-\mathbf{k}_i$；FT-STS 强度与联合态密度相关 |
| **通俗** | 电子撞杂质溅起涟漪；从涟漪波长反推「电子从哪一点散射到哪一点」 |

---

### RIXS — Resonant Inelastic X-ray Scattering

| 项目 | 内容 |
|------|------|
| **是什么** | 共振非弹性 X 射线散射：测集体激发（自旋、电荷、轨道） |
| **相关现象** | 磁振子色散、电荷激发、轨道激发、掺杂演化 |
| **公式** | 能量损失 $\omega=\omega_{\mathrm{in}}-\omega_{\mathrm{out}}$；动量转移 $\mathbf{q}=\mathbf{k}_{\mathrm{in}}-\mathbf{k}_{\mathrm{out}}$ |
| **通俗** | X 光敲一下晶格/自旋，听它们回声里有什么集体运动模式 |

---

### μSR — Muon Spin Relaxation / Rotation

| 项目 | 内容 |
|------|------|
| **是什么** | 把 μ⁺ 植入样品，用其自旋进动/弛豫探测局域磁场 |
| **相关现象** | 磁体积分数、超导磁穿透深度 $\lambda$、静磁有序 vs 涨落 |
| **公式** | 进动 $\omega=\gamma_\mu B_{\mathrm{loc}}$；超导体中弛豫率与 $1/\lambda^2$ 相关 |
| **通俗** | 往样品里塞进「微型指南针」，看内部磁场静不静、强不强 |

---

### INS — Inelastic Neutron Scattering（非弹性中子散射）

| 项目 | 内容 |
|------|------|
| **是什么** | 中子能量/动量交换 → 测磁激发与声子 |
| **相关现象** | 自旋共振峰（铜氧化物/铁基超导特征）、磁振子、AFM 涨落谱 |
| **公式** | $S(\mathbf{q},\omega)\propto\mathrm{Im}\chi(\mathbf{q},\omega)$（磁通道） |
| **通俗** | 中子当探针去「撞」自旋波；超导能隙打开时常在特定能量出现共振峰 |

---

## 五、理论与方法缩写（Theory & Methods）

### GL — Ginzburg–Landau

| 项目       | 内容                                          |
| -------- | ------------------------------------------- |
| **是什么**  | 以序参量 $\psi$ 为变量的宏观超导唯象理论                    |
| **相关现象** | 相变、涡旋、相干长度 $\xi$、穿透深度 $\lambda$、κ 分类 I/II 类 |
| **公式**   |                                             |
| **通俗**   | 不追问微观配对机制，直接用「超导强度场」ψ 写自由能，够用且好算涡旋          |

---

### RG — Renormalization Group（重整化群）

| 项目 | 内容 |
|------|------|
| **是什么** | 逐步积掉短波长自由度，看长波有效理论如何流动 |
| **相关现象** | Kondo 效应、量子临界、配对不稳定性、无关/相关算符 |
| **公式** | $\frac{dg}d\ell=\beta(g)$；不动点 $\beta(g_*)=0$ |
| **通俗** | 「越看越远」时，哪些相互作用变强、哪些变弱；Kondo 屏蔽就是耦合往强耦合流 |

相关笔记：[[重整化群_RG_概念讲解]]

---

### RPA — Random Phase Approximation（随机相位近似）

| 项目 | 内容 |
|------|------|
| **是什么** | 在泡图级数上求和的屏蔽/集体模式近似 |
| **相关现象** | 自旋/电荷磁化率、Stoner 增强、自旋涨落配对内核 |
| **公式** | $\chi=\chi_0/(1-U\chi_0)$（最简形式） |
| **通俗** | 把电子「集体跟风」的反馈算进去：裸响应被相互作用放大或屏蔽 |

---

### DFT — Density Functional Theory（密度泛函理论）

| 项目 | 内容 |
|------|------|
| **是什么** | 用电子密度为基本变量求基态的第一性原理框架 |
| **相关现象** | 能带、结构、声子、电声耦合（你的 VASP/QE 日常） |
| **公式** | Kohn–Sham：$[-\frac{\hbar^2}{2m}\nabla^2+v_{\mathrm{eff}}]\psi_i=\varepsilon_i\psi_i$；$n=\sum|\psi_i|^2$ |
| **通俗** | 「用密度代替 10²³ 个波函数」的实用量子化学/固体计算引擎；强关联时要小心失效 |

---

### DMFT（常与 DFT 联用；本表外围但强关联核心）

> 你列表未写，但与 DFT/QMC 并列时常出现：把晶格映射为自洽量子杂质问题，捕捉局域动力学关联。

### QMC — Quantum Monte Carlo（量子蒙特卡洛）

| 项目 | 内容 |
|------|------|
| **是什么** | 用随机采样处理量子多体路径积分/配分函数 |
| **相关现象** | Hubbard 模型相图、反铁磁、超导关联、符号问题限制掺杂区 |
| **公式** | $Z=\mathrm{Tr}\,e^{-\beta H}\approx\sum_{\mathrm{configs}}w(c)$；$w$ 可能为负（符号问题） |
| **通俗** | 用掷骰子逛遍量子世界的构型；费米子常遇到「负概率」麻烦 |

---

### SAF-MC — Static Auxiliary Field Monte Carlo

| 项目 | 内容 |
|------|------|
| **是什么** | 辅助场取静态近似的蒙特卡洛（牺牲部分动力学，换可算尺度） |
| **相关现象** | 非常规配对机制数值研究、有限温度相图趋势 |
| **公式** | Hubbard–Stratonovich 后对辅助场 $\{c_i\}$ 做经典采样，电子在静场中对角化 |
| **通俗** | 把快涨落「冻住」成静背景场，再对场做蒙特卡洛；便宜，但不是完整量子动力学 |

相关：[[秦琼——静态辅助场蒙特卡洛方法与非常规超导配对机制]]

---

### HS — Hubbard–Stratonovich 变换

| 项目 | 内容 |
|------|------|
| **是什么** | 把四费米子相互作用解耦成辅助场与电子的双线性耦合 |
| **相关现象** | QMC、平均场、自旋/电荷通道解耦 |
| **公式** | $e^{\frac{1}{2}A^2}\propto\int d\phi\,e^{-\frac{1}{2}\phi^2-\phi A}$（示意）；Hubbard $U n_\uparrow n_\downarrow$ → 辅助场 |
| **通俗** | 「四个人打架」改写成「每人跟一个中介场打交道」；中介场就是辅助场 |

---

### DMRG — Density Matrix Renormalization Group

| 项目 | 内容 |
|------|------|
| **是什么** | 基于密度矩阵截断的张量网络算法，一维/准一维极准 |
| **相关现象** | t–J / Hubbard 链与梯子、条纹、自旋液体候选、能隙与纠缠谱 |
| **公式** | 保留约化密度矩阵最大本征值对应的态；与 MPS 表述等价 |
| **通俗** | 专门擅长「一条链/一条梯子」上的强关联问题；精度可以非常高 |

---

### TNW — Tensor Network（张量网络）

| 项目 | 内容 |
|------|------|
| **是什么** | 用张量收缩表示多体波函数（MPS、PEPS、MERA…） |
| **相关现象** | 二维强关联、拓扑序、纠缠结构 |
| **公式** | $|\Psi\rangle$ 由局域张量收缩构成；键维 $D$ 控制纠缠容量 |
| **通俗** | 把巨大波函数拆成乐高块再拼起来；DMRG 是其一维王牌实现 |

---

### PCA — Principal Component Analysis（主成分分析）

| 项目 | 内容 |
|------|------|
| **是什么** | 降维：找方差最大的正交方向 |
| **相关现象** | 实验/模拟大数据分类相、识别序参量候选、机器学习辅助物性 |
| **公式** | 对协方差矩阵对角化，主成分 = 最大本征矢量 |
| **通俗** | 「数据里哪几个方向变化最大」；常用来从海量谱/构型里自动找出可能的序 |
