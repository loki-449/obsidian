# 相位涨落与赝能隙

> 核心分离：配对振幅 $|\Delta|$ 与相位相干 $\theta$ 是两件不同的事。欠掺杂铜氧化物中 $T_c$ 由相位刚度决定，能隙关闭温度是 $T^*$。

## 1. 振幅–相位分解

超导序参量：

$$\Psi(\mathbf{r}) = |\Delta(\mathbf{r})|\, e^{i\theta(\mathbf{r})}$$

| 量 | 含义 | 跟踪什么 |
|----|------|---------|
| $|\Delta|$ | 配对振幅：电子绑得多牢固 | 能隙大小；探针：ARPES/STM 能隙 |
| $\theta$ | 相位：不同位置的对是否步调一致 | 超流密度 $\rho_s$；探针：穿透深度、$\mu$SR |

宏观超导（零电阻 + Meissner）要求二者同时成立：$|\Delta|\neq 0$ **且** $\theta$ 长程锁定。

## 2. Emery–Kivelson 图像

两个特征温度：

- **平均场配对温度 $T_{\mathrm{mf}}$（≈ $T^*$）**：配对振幅开始出现
- **相位相干温度 $T_\theta$（≈ $T_c$）**：相位建立长程关联，由相位刚度决定

$$T_c = \min\!\bigl(T_{\mathrm{mf}},\; T_{\theta}\bigr)$$

- 常规超导体：$T_\theta \gg T_{\mathrm{mf}}$ → $T_c = T_{\mathrm{mf}}$，BCS 适用，无赝能隙
- 低超流密度系统（欠掺杂铜氧化物、二维薄膜）：$\rho_s$ 小 → $T_\theta \ll T_{\mathrm{mf}}$ → $T_c = T_\theta$

**Uemura 标度**：$T_c \propto \rho_s(T\to 0)$——欠掺杂区相位涨落控制 $T_c$ 的直接证据。

## 3. 赝能隙温区

当 $T_c < T < T^*$：

$$\underbrace{|\Delta|\neq 0}_{\text{预形成对}} + \underbrace{\langle e^{i\theta}\rangle = 0}_{\text{无相位长程序}} \;\Rightarrow\; \text{有能隙 + 无超流 + 反常金属}$$

### 温度能量尺度线

```
T > T*     正常态（奇异金属）：整费米面闭合，无配对、无相干
T = T*     antinode 能隙打开；|Δ| 出现；θ 无长程序 → 费米弧
Tc < T < T*  赝能隙态：对在，自由涡旋搅乱相位，无超流
T = Tc     KT 转变：ρs 达临界 → 相位锁定，电阻跳零
T < Tc     超导态：θ 锁定 + |Δ| 非零，完整 d 波超导
```

关键不对称：升温先死相位（$T_c$），降温先生配对（$T^*$）。

### 赝能隙"闭合"指什么

d 波在 node（$k_x\approx k_y$）本就为零。**闭合指 antinode——$(\pi,0)$ / $(0,\pi)$——的能隙也归零**，发生在 $T^*$。

| 温区 | node | antinode | 费米面 |
|------|------|----------|--------|
| $T < T_c$ | 零（node 点） | 有限能隙 | 完整 d 波能隙 |
| $T_c < T < T^*$ | 零 + 周围弧 | 能隙减小 | 费米弧 |
| $T = T^*$ | 全开 | 能隙 → 0 | 完整费米面 |

## 4. 同源性的三个可观测量

相位涨落图像的指纹（区别于"竞争序打开赝能隙"）：

1. **$|\Delta|$ 在 $T_c$ 处不消失**——ARPES/STM 能隙穿过 $T_c$ 后仍在，变化平缓
2. **能隙的 d 波动量结构跨越 $T_c$ 不变**——赝能隙区也是 $|\cos k_x - \cos k_y|$，与超导态同构
3. **谱权重随温度连续减小，不跳变**——$T_c$ 是相干交叉，不是新序参量出现

解耦矩阵：

| 物理量 | 跟着谁 | $T_c$ 处 | $T^*$ 处 |
|--------|--------|---------|---------|
| 能隙振幅 $\|\Delta\|$ | 配对 | 几乎不跳 | 逐渐消失 |
| 超流密度 $\rho_s$ | 相位 | 从零跳到有限 | 无特殊行为 |
| 电阻 $\rho(T)$ | 相位锁定 | 跳零 | 继续增大 |

## 5. 与玻色金属 / 反常金属的关联

配对–相位分离 → 存在温区有预配对玻色子但无凝聚。若这些玻色子既不能凝聚（$T > T_{\mathrm{KT}}$）也不能局域化 → **玻色金属 / 反常金属**（有限电阻，不趋于零也不发散）。辅助场 MC 可通过连续调温追踪 $\rho_s(T)$ 与 $|\Delta(T)|$ 竞争，自然画出中间态相界。
