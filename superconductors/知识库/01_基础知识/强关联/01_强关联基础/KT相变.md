# KT（BKT）相变

> 二维系统中不依赖对称性破缺的拓扑相变：涡旋–反涡旋对解束缚。欠掺杂铜氧化物中 $T_c$ 的本质往往是 $T_{\mathrm{KT}}$。

## 1. 为什么"不该发生"却发生了

[[Luttinger定理与强关联定理集|Mermin–Wagner 定理]]：二维连续对称性不能自发破缺 → 严格长程序在 $T>0$ 不存在。但超流氦薄膜、2D 超导薄膜实验上有超流转变。

**Kosterlitz–Thouless（1973；Berezinskii 更早）**：存在不依赖对称性破缺的**拓扑相变**。2016 年诺贝尔物理学奖。

## 2. XY 模型

只保留格点相位 $\theta_i$（库珀对相位的占位符）：

$$E = -J \sum_{\langle i,j\rangle} \cos(\theta_i - \theta_j)$$

## 3. 涡旋与解束缚

绕一点走一圈，相位累积 $\pm 2\pi$ → **拓扑激发**，不能连续解开。

- 孤立涡旋能量 $\sim \ln(\text{系统尺寸})$，热力学极限发散
- 正反涡旋对能量 $\sim \ln r$（$r$ 为间距）→ 低温总以 +/- 对形式存在

拆散代价与熵收益竞争：

$$\Delta F = (2\pi J - 2 k_B T)\ln R$$

$$k_B T_{\mathrm{KT}} = \pi J \quad\text{（或用超流密度：}\; k_B T_{\mathrm{KT}} = \tfrac{\pi}{2}\,\rho_s(T_{\mathrm{KT}})\;\text{）}$$

| | $T < T_{\mathrm{KT}}$ | $T > T_{\mathrm{KT}}$ |
|--|----------------------|----------------------|
| 涡旋 | 成对束缚 | 自由涡旋涌现 |
| 超流 | $\rho=0$（无耗散） | 自由涡旋漂移 → flux-flow 电阻 |
| 配对 | $\|\Delta\|\neq 0$ | $\|\Delta\|$ 仍可非零（赝能隙） |

## 4. 标志性特征

**超流密度普适跳变（universal jump）**：

$$\frac{\rho_s(T_{\mathrm{KT}}^-)}{T_{\mathrm{KT}}} = \frac{2}{\pi}$$

不是连续 → 0，而是从有限普适值直接跳到 0。铜氧化物中已观测到接近该比值。

关联函数：$T < T_{\mathrm{KT}}$ 时 $\langle e^{i\theta(r)} e^{-i\theta(0)}\rangle \sim r^{-\eta(T)}$，在 $T_{\mathrm{KT}}$ 处 $\eta=1/4$；之上指数衰减。

比热在 $T_{\mathrm{KT}}$ 处解析（无限阶相变，无 λ 奇点）。

## 5. 与常规相变对比

| | 常规相变（Ising, BCS） | KT 相变 |
|--|----------------------|---------|
| 机制 | 对称性自发破缺 | 拓扑激发解束缚 |
| 序参量 | 局域序参量 | 无局域序参量，有拓扑序 |
| 高温激发 | 振幅涨落 | 自由涡旋 |
| $T_c$ 以下关联 | 趋于常数（长程序） | 幂律衰减（准长程序） |
| 低维 | 受 Mermin–Wagner 限制 | **二维允许** |

## 6. 铜氧化物中的含义

- $T_c$ 本质是 $T_{\mathrm{KT}}$：涡旋对解束缚，不是配对拆散
- 赝能隙区 = 有配对振幅但自由涡旋已涌现
- Uemura 关系 $T_c \propto \rho_s(0)$ 可从 KT 条件自然导出

物理对应：XY 涡旋 ↔ 真实磁通量子 $\Phi_0 = h/2e$；自由涡旋漂移 ↔ 磁通流阻。
