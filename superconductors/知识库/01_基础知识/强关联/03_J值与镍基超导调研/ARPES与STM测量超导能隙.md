# ARPES 与 STM 测量超导能隙

## 一、ARPES 测量超导能隙

### 基本原理
ARPES 用光子打入材料，踢出电子。测量电子的动能和出射角度（换算成晶体动量 k），计数在该动能和角度上踢出了多少电子。结果是二维图：横轴结合能，纵轴信号强度。

### EDC（能量分布曲线）
在固定动量 k 上沿结合能扫出的曲线。正常态下是一个台阶（费米边），因为费米-狄拉克分布在 E_F 附近渐变。

### 超导态的双峰结构
进入超导态后，E_F ± Δ 处各堆出一个态密度峰。两个峰中间的 dip 是超导能隙。双峰间距的一半 = 该动量 k 处的 Δ(k)。

```
正常态 EDC：
信号 ↑
     │     ____
     │    /    \
     │   /      \_____ ← 费米边（台阶状）
     └──────────────→ 结合能

超导态 EDC：
信号 ↑
     │     峰1（E_F + Δ）
     │     /\
     │    /  \
     │   /    \_____ 能隙内部
     │  /      \
     │ /        \峰2（E_F − Δ）
     └──────────────→ 结合能
```

### 关键数据处理：去掉费米分布
ARPES 信号 = 谱函数 A(k, ω) × 费米分布 f(ω, T)。有限温度下 f(ω) 在 E_F 附近有宽度 ~ 4k_BT 的渐变，会模糊超导能隙。必须除以 f(ω)（做对称化处理）才能得到纯 A(k, ω)，看到真实的双峰间距 Δ(k)。

### 费米面上的 Δ(k) 分布
对费米面上不同 k 方向逐一测 EDC，提取双峰间距 → 得到 Δ(k) 的角度依赖 → 确定配对对称性（d 波、s 波、s± 等）。

## 二、STM 测量超导能隙

### 基本原理
STM 针尖悬在样品表面上约一个原子间距处。加偏压 V，测隧穿电流的导数 dI/dV。**dI/dV ∝ 局域态密度（LDOS）**。

### 局域态密度 → 总态密度
表面上所有位置的 dI/dV 平均 → 总态密度 N(E)。

### 三种低能态密度形状

| 形状 | 低能行为 | 节点类型 | 物理含义 |
|:---|:---|:---|:---|
| **U 型** | N(E) ≈ 0，底部平坦 | 无节点 | 费米面全域有能隙 |
| **V 型** | N(E) ∝ \|E\| | 线节点 | 费米面上有闭合线 Δ=0 |
| **E² 型** | N(E) ∝ E² | 点节点 | 费米面上有几个孤立点 Δ=0 |

**U 型只能说明全能隙打开，不一定等于 s 波。** 配对对称性需要 QPI/ARPES 的动量分辨来确认。

### 各配对对称性的典型态密度形状
- s 波 / s± 波：U 型（全能隙）
- d 波（铜氧化物）：V 型（四个线节点，N(E) ∝ |E|）
- p 波（三重态）：抛物线型（点节点，N(E) ∝ E²）
- d + ig（Sr₂RuO₄ 候选）：接近 U 型但有多余低能态密度（节点被虚部分量撑成微小能隙）

## 三、QPI（准粒子干涉成像）—— "穷人的 ARPES"

### 基本原理
材料表面的杂质/缺陷散射准粒子。散射前后的干涉在实空间形成驻波图案。

### 操作步骤
1. 在某个能量 V 下，把实空间的 dI/dV(x, y) 做二维傅里叶变换 → 动量空间的 dI/dV(q, V)
2. 特定角度方向（如沿 k_x、沿 45° 对角）积分 dI/dV
3. 找出各方向"QPI 信号开始出现"的阈值能量 = 该方向的 Δ
4. 所有方向的 Δ 连线 → Δ(θ) → 配对对称性

### 意义
对 ARPES 无法测的材料（如 CeCoIn₅ 等重费米子，f 电子谱重弱），QPI 是目前唯一能从实验上给出 Δ(k) 角度依赖的方法。

| | ARPES | STM (QPI) |
|:---|:---|:---|
| 测什么 | 动量分辨的 A(k, ω) | 实空间 LDOS → 动量空间散射 |
| 能否给 Δ(k) 角度依赖 | 是（核心优势） | 是（间接，但有效） |
| 温度 | 几 K（费米分布模糊限制） | mK 级 |
| 对 ARPES 做不了的材料 | — | CeCoIn₅（重费米子）等 |

## 四、ARPES 能隙 vs STM 总态密度的互补关系

```
ARPES：Δ(k) 在费米面上的角度依赖 → d 波节点/CeCoIn₅ d_{x²−y²} 等
STM 总态密度：N(E) 的低能形状 → U/V/E² 判断节点类型
QPI：Δ(θ) 的角度依赖 → 无法做 ARPES 的材料也能定对称性
```
