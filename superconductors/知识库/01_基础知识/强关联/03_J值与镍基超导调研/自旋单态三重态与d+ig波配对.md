# 自旋单态与三重态的区分 & d+ig 波配对

## 一、自旋单态 vs 自旋三重态

### 基本概念

| | 自旋单态 (singlet) | 自旋三重态 (triplet) |
|:---|:---|:---|
| 库珀对自旋 | ↑↓（相反） | ↑↑ 或 ↓↓（相同） |
| 总自旋 S | 0 | 1 |
| 对外磁矩 | 无 | 有净自旋 |
| 典型配对对称性 | s, d, s± | p 波（p+ip） |
| 代表材料 | 铜氧化物、铁基、镍基、BCS | UTe₂, UGe₂（曾被认为 Sr₂RuO₄） |

### 用磁化率区分

**原理**：进入超导态后，巡游电子配对成库珀对。库珀对的性质决定磁化率变化。

- **自旋单态**（↑↓）：库珀对自旋抵消 → 不再响应外部磁场 → 原先对磁化率有贡献的单身电子消失 → **各方向磁场下磁化率都随温度下降而下降**
- **自旋三重态**（↑↑）：库珀对有净自旋 → 如果磁场方向和库珀对自旋方向一致，库珀对仍能响应 → **该方向的磁化率不随温度下降**

**判断规则**：
- 三个正交方向磁场下磁化率**都降** → 自旋单态
- **某个方向不降** → 自旋三重态（该方向是库珀对自旋的朝向）

### 类比

自旋单态 = 两个人手拉手，一个 N 极一个 S 极 → 对外不显磁性，外面磁铁从哪个方向来都不响应。

自旋三重态 = 两个人手拉手，两个都举 N 极 → 这对人自己就是小磁铁。外面磁铁从同样方向来 → 他们能贴合着转 → 该方向磁化率不降。

## 二、Sr₂RuO₄ 的反转故事

### 旧结论
早年 NMR 测 Knight 位移（等价于自旋磁化率），发现 Tc 以下某方向磁化率不降 → 推定自旋三重态 + p+ip 波配对。教科书里存在了二十多年。

### 新结论
近几年更高精度的 NMR 重测 → **所有方向磁化率都降了** → 原来的实验因精度不够出错 → Sr₂RuO₄ 是**自旋单态**。

### 新的配对对称性候选
自旋单态 + 磁激发色散二维 + 可能有的时间反演对称性破缺 → **d + ig 波**

## 三、d + ig 波配对

### 符号拆解

| 符号 | 含义 |
|:---|:---|
| **d 波分量** | Δ(k) ∝ cos(k_x) − cos(k_y)，四个线节点，象限交替 ± |
| **g 波分量** | 角动量 L=4，八个瓣，多节点 |
| **i** | 两个分量以 90° 相位差叠加 → 复数能隙函数 → 时间反演对称性破缺 |
| **+** | 同一超导态的两个分量，不是两种竞争配对 |

\[
\Delta(\mathbf{k}) = \Delta_d \cdot (\cos k_x - \cos k_y) + i \Delta_g \cdot (\text{g 波基函数})
\]

### 为什么是 d + ig 而不是纯 d 波

纯 d 波的 Δ(k) 是纯实数（或纯虚数），保持时间反演对称。

但 Sr₂RuO₄ 有迹象破缺时间反演对称性（μSR 看到微弱内部场、Kerr 效应等）。**单独 d 波做不到这一点。** 需要两个不同对称性的配对通道以 i 相位叠加 → d + ig 是正方晶格中满足自旋单态 + 破缺时间反演的最低阶组合。

### 费米面上的表现

d 波节点在 k_x = ±k_y，g 波节点在别处 → 两个分量的零点**不重合** → d 波原来的四处线节点被 g 波的虚部分量**撑成微小能隙** → 节点不完全为零，而是接近零的小能隙。

实验后果：低温比热/穿透深度测到的既不是纯 d 波节点的幂律（T²），也不是标准的激活型（e^{−Δ/T}），而是介于两者之间——"几乎有节点但不是真节点"。

## 四、所有配对对称性统一对比

| 配对对称性 | 自旋 | 能隙节点 | 时间反演 | 晶格 | 代表材料 |
|:---|:---|:---|:---|:---|:---|
| s++ (BCS) | 单态 | 无 | 保持 | 任意 | MgB₂, 常规 BCS |
| s± | 单态 | 无（偶然节点可能） | 保持 | 多口袋 | 铁基, La₃Ni₂O₇ |
| d 波 | 单态 | 4 线节点 | 保持 | 正方 | 铜氧化物 |
| p 波 | **三重态** | 点节点 | 保持/破缺 | 不敏感 | UTe₂, UGe₂ |
| d + ig | **单态** | 节点被撑开（近零微能隙） | **破缺** | 正方 | Sr₂RuO₄ 候选 |
