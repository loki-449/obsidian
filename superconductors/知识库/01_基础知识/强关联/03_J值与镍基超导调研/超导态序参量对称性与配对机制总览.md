# 超导态中的序参量对称性、实验探针与配对机制

> 从 INS 自旋共振、时间反演破缺（μSR/Kerr）、有限动量配对（PDW/FFLO）、奇频配对，到配对机制的理论流派（玻色子媒介/模型展开/RG/数值/GL），系统梳理这段绪论覆盖的所有问题对象和分析角度。

---

## 一、全文地图：这段文字在说什么

这段绪论覆盖了**五个层次**的内容，从实验探针一路拉到理论方法论：

```
实验探针（INS, μSR, Kerr, STM, 比热）
  → 探测的物理对象（自旋磁化率 χ″, 时间反演破缺, PDW 调制, 双重转变）
    → 对应的超导态类型（s± 共振, 手性超导, 向列超导, FFLO, 奇频配对）
      → 配对机制的两条理论路线（玻色子媒介 vs 模型展开）
        → 具体理论工具（Eliashberg, RG, QMC/DMRG, GL）
```

## 二、INS 与自旋共振峰——探测能隙符号反转

### 2.1 物理对象：自旋磁化率虚部 χ″(q, ω)

- INS 测量的是**自旋结构因子** S(q, ω)
- 通过**涨落-耗散定理**转化为**自旋磁化率虚部** χ″(q, ω)：
  
  $$S(\mathbf{q}, \omega) \propto \frac{1}{1 - e^{-\hbar\omega/k_B T}} \, \chi''(\mathbf{q}, \omega)$$

- 正常态：χ″(q, ω) 在磁特征波矢 Q 处呈现**宽峰**，峰值能量 = 磁特征能量
- 超导态：如果 Δ(k) = −Δ(k + Q)（被 Q 连接的能隙符号相反），则在 Q 处 χ″ 中出现**尖锐共振峰**

### 2.2 自旋共振峰的物理图像

能隙符号反转 → 在 Q 处的粒子-空穴激发（从 k 到 k+Q 的散射）经历了**能隙的符号变化** → 准粒子相干增强 → 磁化率虚部在 ω ≈ Δ(k) + Δ(k+Q) 处出现尖锐峰。

**关键定量关系**：

$$E_{res} \approx 1.28 \times 2\Delta$$

其中 E_res 是共振峰能量，2Δ 是超导能隙。这个比例已被铜基、铁基、重费米子等多个体系验证。

### 2.3 为什么共振峰是 s± 波的"指纹"

s± 波：Γ 口袋的 Δ > 0，M 口袋的 Δ < 0，连接它们的波矢恰好是 AFM 波矢 Q = (π, π)。所以 INS 共振峰是 s± 配对（有能隙符号反转）的**直接证据**。

没有符号反转的配对（如纯 s 波，处处 Δ > 0）→ 无共振峰或共振峰极弱。

## 三、超导态中的进一步对称性破缺

### 3.1 手性超导：时间反演对称性破缺

- **物理对象**：超导序参量是两分量（两个不可约表示）的复数组合，如 d + ig
- **条件**：d 波和 g 波两个不可约表示的本征值**偶然简并**
- **结果**：两个分量之间出现 90° 相位差 → **时间反演对称性破缺**
- **典型材料**：Sr₂RuO₄（从 p+ip 翻转为 d+ig）

### 3.2 向列超导：空间旋转对称性破缺

- **物理对象**：序参量在 x 和 y 方向不等价
- **表现**：C₄ → C₂，能隙大小依赖方向
- **探测**：角分辨热力学（比热、热导的 C₂ 而非 C₄ 振荡）

### 3.3 PDW / FFLO：空间平移对称性破缺

- **物理对象**：配对总动量不为零
- **FFLO 态**（Fulde–Ferrell–Larkin–Ovchinnikov）：强磁场下 Zeeman 效应使 ↑ 和 ↓ 费米面失配 → 配对获得有限总动量 Q
- **配对密度波 PDW**（Pair Density Wave）：序参量在实空间中周期调制，Δ(r) = Δ₀ cos(Q·r)
- **与常规超导的区别**：常规超导 Δ(k, −k)，PDW/FFLO 是 Δ(k, Q−k)，总动量 Q ≠ 0

### 3.4 GL 自由能视角的统一

从 GL 理论出发，自由能写为序参量的泛函：

$$F = \int d^d r \left[ a|\Psi|^2 + b|\Psi|^4 + c|\nabla\Psi|^2 + \cdots \right]$$

在参数空间的某些区域，自由能极小的解可能出现**时间或空间旋转对称性破缺**——即超导相内部自发产生额外的对称性破缺。

**一个开放问题**：铁基超导体中有些实验推断时间反演破缺发生在 Tc **以上**（不在超导态内部），这挑战了"TRSB 是超导序参量的次级对称性破缺"的传统理解。

## 四、时间反演对称性破缺的实验探测

### 4.1 μSR（缪子自旋旋转/弛豫）

- **测量对象**：μ 子的不对称因子 → 扣除背景和温度效应 → 得到**弛豫率**
- **判据**：温度降低，弛豫率**逐步提升** → 时间反演对称性破缺（内部出现自发磁矩或超流）
- **应用案例**：
  - 铁基超导中 s + is′ 态的确立
  - Sr₂RuO₄ 可能的 d + ig 态

**物理直觉**：时间反演破缺伴随自发电流或自旋极化 → 产生局域磁场 → μ 子自旋进动被额外退相干 → 弛豫率增加。

### 4.2 极向 Kerr 效应

- **测量对象**：线偏振光反射后偏振面旋转的**极向 Kerr 角** θ_K
- **判据**：θ_K 随温度降低出现非零值 → 时间反演对称性破缺
- **优势**：可以精确确定 TRSB 转变温度 T_TRSB

### 4.3 比热双重转变

- **测量对象**：比热系数 C/T 随温度的变化
- **判据**：如果 T_TRSB ≠ T_c（TRSB 和超导转变不同时发生），比热曲线上出现**两个峰**
- **案例**：UTe₂ 的压力测量中观测到 C/T 双峰 → T_TRSB < T_c 或 T_TRSB > T_c 两种可能

**三种探针的对照**：

| 探针 | 测量量 | 判据 | 优势 |
|:---|:---|:---|:---|
| μSR | 弛豫率随 T 的变化 | 降温时弛豫率上升 | 对自发磁场极敏感 |
| 极向 Kerr | θ_K 随 T 的变化 | 出现非零 Kerr 角 | 精确确定 T_TRSB |
| 比热双重转变 | C/T 的两个峰 | T_TRSB ≠ T_c | 区分两个转变温度 |

## 五、PDW / FFLO 的实验探测

### 5.1 STM 的两种探测模式

**模式一：实空间调制**

- 看能隙或局域态密度 dI/dV(x, y) 的实空间分布
- 抽取调制周期 → 得到配对总动量 Q

**模式二：动量空间**

- 对 dI/dV(x, y) 做傅里叶变换（QPI）→ dI/dV(q)
- 看峰的波矢位置 → 直接读出 Q

### 5.2 已发现的 PDW 候选体系

| 材料 | 调制特征 | 探测手段 |
|:---|:---|:---|
| 铜氧化物（Bi₂Sr₂CaCu₂O₈₊δ） | 周期 8a₀ 的 PDW | STM 实空间调制 |
| 铁基超导体 | PDW 迹象 | STM QPI |
| CsV₃Sb₅ | 电荷序+PDW | STM |
| UTe₂ | PDW/FFLO 候选 | 多重探针 |

### 5.3 低温高场上临界场的反常上扬 → FFLO 信号

很多非常规超导体在低温高场下 H_c2(T) 偏离 Werthamer-Helfand-Hohenberg (WHH) 理论 → 暗示**低场下的超导态 ≠ 高场下的超导态**。

CeCoIn₅ 是经典例子：低温高场区域被推测为 FFLO 态（配对获得有限动量以对抗 Zeeman 效应）。

## 六、自旋三态配对与拓扑超导

- 常规超导：自旋单态（↑↓ − ↓↑），总自旋 S = 0
- 自旋三态：配对电子的总自旋 S = 1，波函数在交换自旋时对称
- **与拓扑超导的关系**：自旋三态 + 强自旋轨道耦合 → 可能支持 Majorana 零模 → **拓扑量子计算的基础**

**为什么人们拼命找自旋三态超导体**：不是为了超导本身，是为了拓扑量子计算。

---

## 七、奇频配对——频率维度的对称性

- 常规（偶频）超导：Δ(ω) = Δ(−ω)，能隙是频率的偶函数
- **奇频超导**：Δ(ω) = −Δ(−ω)，能隙是频率的奇函数
- 在时间域：偶频配对 = 同时配对（等时配对），奇频配对 = 不同时配对（不等时配对）
- 奇频配对给出许多新奇性质，但实验上还未最终确认

## 八、超导配对机制的两条理论路线

### 8.1 路线一：玻色子媒介（"胶水"路线）

**核心思想**：存在某种玻色型集体激发作为配对媒介，电子通过交换玻色子产生有效吸引。

**各类涨落及其媒介**：

| 涨落类型 | 媒介 | 典型体系 |
|:---|:---|:---|
| 反铁磁涨落 | 自旋波 | 铜氧化物、重费米子、铁基、镍基 |
| 铁磁涨落 | 自旋波（q≈0） | UCoGe, UTe₂ |
| 电极化涨落 | 软声子 | SrTiO₃ |
| Valley 涨落 | 谷间激发 | 扭角石墨烯 |
| 电荷涨落 | 电荷密度波 | CsV₃Sb₅ |
| 向列涨落 | 向列序涨落 | 铁基超导 |
| 多涨落混合 | 自旋+电荷+声子 | FeSe |

**处理步骤**：
1. 确定有效相互作用 V_eff（正比于相应的磁化率，如自旋涨落 V ∝ χ_spin、电荷涨落 V ∝ χ_charge）
2. 取磁化率形式：无相互作用 Lindhard、RPA、或实验抽取的 MMP 磁化率
3. 代入 Eliashberg 理论或平均场能隙方程
4. 求解能隙对称性和 T_c

### 8.2 路线二：模型哈密顿量 + 圈图展开

**起点**：从具体模型出发（如铜氧化物的单带 Hubbard 模型）

**步骤**：
1. 圈图展开 → 分离出电荷涨落和自旋涨落的贡献
2. 通过格林函数计算 → 正常自能 Σ_n 和反常自能 Σ_an 的自洽方程
3. 从反常自能中抽取能隙函数 Δ
4. 分析 Δ 的对称性、T_c 的影响因素（相互作用、掺杂、磁场）

**两条路线的区别**：

| | 玻色子媒介 | 模型展开 |
|:---|:---|:---|
| 出发点 | 实验提取的磁化率 | 微观哈密顿量 |
| 相互作用 | 输入（来自实验或 RPA） | 从模型推导 |
| 关键近似 | 哪种玻色子主导 | 保留哪些费曼图，是否忽略顶角修正 |
| 共同终点 | 求解自能/能隙方程，分析对称性和 T_c | ← 相同 |

**一句话**：两条路线的区别在**前半段**（如何处理有效相互作用），**后半段**（求解能隙方程、分析对称性）大同小异。

## 九、重整化群（RG）——第三种视角

### 9.1 RG 方法的核心不同

传统 Eliashberg/平均场是分析**哪个对称性在给定相互作用下解最高 T_c**。

RG 是问：当不断积分掉高能自由度后，**哪种配对通道的配对磁化率（粒子-粒子 channel）最先发散** → 该通道主导超导。

### 9.2 粒子-空穴 vs 粒子-粒子

RG 的独特优势：**同时处理粒子-空穴 channel（电荷序、自旋序、轨道序等）和粒子-粒子 channel（超导配对）**。

结果不是"超导对称性是什么"，而是"低能到底出现哪种序"——可能是超导，也可能是电荷序、自旋序等竞争序。

### 9.3 材料应用

RG 已成功应用于铜基、铁基、镍基超导的对称性分析。

## 十、数值方法——从第一性原理出发

### 10.1 SAF-MC（静态辅助场蒙特卡洛）

- 分析**平衡态时配对场分布**的特征
- 通过考察哪种配对场的分布最集中/最有序 → 判断配对对称性

### 10.2 QMC / DMRG

- 计算不同配对对称性的**配对关联函数** P_α(r) = ⟨Δ_α†(r) Δ_α(0)⟩
- 比较不同通道的关联函数大小 → 哪个通道占主导
- **T_c 的提取**：配对关联函数发散（其逆 → 0）的温度

### 10.3 数值方法的对比

| 方法 | 输入 | 分析对象 | 优势 | 局限 |
|:---|:---|:---|:---|:---|
| SAF-MC | 模型哈密顿量 | 配对场分布 | 可处理较大系统 | 静态近似 |
| QMC | 模型哈密顿量 | 配对关联函数 | 精确（无近似） | 符号问题 |
| DMRG | 模型哈密顿量 | 配对关联函数 | 一维/准一维极精确 | 二维受限 |

## 十一、GL 理论——对称性分析的顶层框架

### 11.1 基本思路

1. 根据体系的**对称性**，写出以序参量为变量的自由能泛函
2. 自由能展开到序参量的适当阶数
3. 求自由能极小 → 给出不同条件下序参量的具体形式

### 11.2 优势与局限

**优势**：
- 处理**向列超导、手性超导**方面特别有优势（对称性语言天然）
- 不依赖微观模型细节

**局限**：
- 自由能展开系数与实验参数/微观参数的对应关系不清晰
- 不能预测 T_c——只能分析 T_c 以下序参量的对称性结构

### 11.3 应用案例

双层扭角铜氧化物（45° 扭角附近）：GL 自由能分析发现，在某些参数范围内超导可能存在时间反演对称性破缺。
