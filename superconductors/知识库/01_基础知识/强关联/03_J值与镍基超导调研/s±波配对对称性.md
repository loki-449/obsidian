# s± 波超导配对对称性

> 每个费米面口袋上的能隙是各向同性的（s 波），但不同口袋之间的能隙符号翻转——"s"指各向同性，"±"指口袋间反号。这是 bilayer 镍氧化物区别于单层铜氧化物在对称性层面最深刻的签名。

---

## 一、配对对称性的基本分类

配对对称性 = 能隙函数 Δ(k) 在费米面上的符号分布。

| 类型 | Δ(k) 符号 | 费米面上节点 | 胶水来源 |
|:---|:---|:---|:---|
| 常规 s++ | 全正、同号 | 无 | 声子（实空间局域吸引） |
| d 波 | 四个象限交替 +/− | 4 个线节点 (k_x=±k_y) | 面内 AFM 涨落 Q=(π,π) |
| **s± 波** | **不同口袋之间反号，口袋内同号** | **无（对称性强制），可能有偶然节点** | **层间 AFM 涨落** |

---

## 二、s± 的物理来源——为什么层间反铁磁涨落天然给出 s±

### 铜氧化物（d 波）的对比

铜氧化物是单层、纯 d_x²−y²、面内 Néel 自旋涨落 Q=(π, π)。

两个电子交换一个 Q=(π, π) 自旋涨落时：
- V_eff 在 q=(π, π) 处是**排斥性**的（胶水排斥）
- Δ(k) 和 Δ(k+(π, π)) 必须**反号**才能自洽
- 由于都是同一个费米面口袋，（π, π）连接的是口袋上的两个点
- 这两点在同一条费米面上 → 反号的路径上必然经过 Δ=0 的节点

这就是 d 波的节点来源。

### La₃Ni₂O₇ 的 s±

Ni327 的配对驱动力来自**层间**d_z² AFM 涨落，波矢 Q=(π, π, π)（含 c 轴分量）。

- Γ 点附近：电子型口袋（d_z² 和 d_x²−y² 杂化形成）
- M 点附近：空穴型口袋（d_x²−y² 主导）
- Γ 和 M 之间在倒空间正好差 Q=(π, π) → 配对胶水连接两个**不同**口袋

反铁磁胶水是排斥性的 → Γ 和 M 两个口袋的 Δ 符号必须相反。
**但 Γ 和 M 是两个分离的口袋，不接触 → 反号发生在口袋之间的"无人区" → 没有对称性强制节点。**

---

## 三、费米面上的具体体现

```
布里渊区（2D 正方格子）：

    M(+)     M(+)        ← M 点口袋，Δ 为正（或负）
      ○       ○

           ●               ← Γ 点口袋（中心），Δ 为负（或正）

      ○       ○
    M(+)     M(+)

波矢 Q=(π,π) 连接 Γ 和 M → 两者配对
排斥性胶水 → 两者 Δ 符号相反 → s±
```

**"s" = 每个口袋内部 Δ 各向同性**
**"±" = 口袋之间符号翻转**

---

## 四、什么时候 s± 会有节点？

如果 Γ 口袋和 M 口袋的 Δ 反号幅度不完全匹配，或存在第三个口袋——在某中间动量处 Δ 可能**意外过零**——这叫"偶然节点"（accidental nodes），不是对称性强制要求的。

实验判断：穿透深度、比热、NMR 的低温幂律行为（T^n）。有节点 → 幂律 T^α（α≈1–2），无节点 → 激活型 e^{−Δ/T}。

---

## 五、s± 和 d 波的区别一览

| | s± (La₃Ni₂O₇ 可能) | d 波 (铜氧化物) |
|:---|:---|:---|
| **胶水源** | 层间 d_z² AFM 涨落 | 面内 d_x²−y² AFM 涨落 |
| **配对口袋** | Γ 和 M 之间（两个分离口袋） | 同一口袋内的两个点 |
| **节点** | 无（可能有偶然节点） | 有（k_x=±k_y，对称性强制） |
| **实空间配对位置** | 两层之间（interlayer） | 面内最近邻（intralayer） |
| **结构根源** | bilayer + apical 氧桥 | 单层 CuO₂ 面 |

## 六、为什么 s± 在能带图上看不到

两个原因：

1. **尺度**：常规 DFT 能带图纵轴是 eV，超导能隙 Δ 只有几个 meV → 千分之一到百分之一，肉眼不可能分辨
2. **符号**：能带图画的是能量本征值 E(k)，标量，无法编码相位符号

s± 留下的痕迹在**进入超导态后的谱函数 A(k, ω)**才能看到——且只能看 gap 的绝对值，不能直接看符号。符号需要通过 QPI 散射波矢对称性或相位敏感实验（Josephson 干涉）推断。
