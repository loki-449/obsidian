# 向列相的起源：晶格、自旋还是轨道？

> 向列相 = x 和 y 方向变得不等价。三个嫌疑人：晶格先歪了（结构）、自旋先乱了（磁）、轨道占据先不对称（轨道）。最合理的图景——结构设定了初始不对称的"种子"，自旋涨落将其放大，轨道占据承载具体的各向异性信号。

---

## 一、什么是向列相

一块四方格子材料（x 和 y 本来等价，转 90 度不变）降温后：
- 电阻沿 x 方向是沿 y 方向的两倍
- 光偏振沿不同方向吸收不一样
- 但**晶格差异只有千分之一**

**千分之一的几何差不可能直接造成两倍的电阻差。** 电子自由度自己把不对称**放大**了。

---

## 二、三个嫌疑人

### 嫌疑人一：晶格扭曲

- **主张**：晶格从四方（C₄）畸变到正交（C₂），a ≠ b → 电子跟着歪
- **问题**：正交畸变 δ = (a−b)/(a+b) ≈ 10⁻⁴–10⁻³，电阻各向异性 ρ_a/ρ_b 可达 2–3 倍——比例完全不对
- **结论**：晶格畸变大概率不是起源，是跟随者（电子先把对称性破了，晶格在电子自由能里选一个方向跟着歪）

### 嫌疑人二：磁性起源——自旋向列序

- **主张**：磁序波矢 (π, 0) 和 (0, π) 是两个等价的条纹磁序基态
- 体系选其中一个 → C₄ 天然破缺
- 即使在磁有序温度**以上**，磁涨落仍带有各向异性 → Ising 型向列序参量：

$$\Phi_{nem} = \langle S_i·S_{i+\hat{x}} \rangle - \langle S_i·S_{i+\hat{y}} \rangle$$

- **只需要自旋涨落不对称，不需要长程磁序 → 向列相先于磁有序出现**
- **判断证据**：在铁基超导中已观测到 T_nem > T_mag

### 嫌疑人三：轨道驱动

- **主张**：d_xz 和 d_yz 占据数不对称（n_xz ≠ n_yz）→ C₄ 直接破缺
- **问题**：占据数为什么不对称？很可能不是轨道自己想这样——是自旋先偏心后，通过 Hund 耦合把轨道占据"拽偏了"
- **结论**：轨道很可能是从犯，不是主谋

## 三、铁基超导的共识——三者的层级关系

从铁基超导多年研究建立的共识：

```
           电子向列不稳定性
          (all-electronic)
          /       |       \
         /        |        \
   自旋涨落     轨道占据     晶格畸变
   各向异性     不对称       (共生/跟随)
   (主导源)     (通过自旋-    (二次效应)
               轨道耦合)
```

- **自旋驱动**最有竞争力（磁交换能标 J ~ 50–100 meV 远大于晶格弹性能）
- **轨道占据偏差**是自旋通过 Hund 耦合诱导的
- **晶格畸变**是电子效应都定调后的跟随响应

## 四、结构不是"受害者"，是"初始条件提供者"

更准确的图景：

```
结构的天生各向异性（层状 + 正交 + 八面体倾转）
          │ 设定了电子哈密顿量的"初始不对称"
          │ （t_x ≠ t_y 天生有微小差异）
          ▼
电子自由度在这个不对称舞台上运动
          │ 通过关联效应（Hund + 超交换 + 费米面嵌套）
          │ 将初始微小不对称放大 100–1000 倍
          ▼
电子各向异性显著（电阻、磁化率差 2–3 倍）
          │ 通过电子-声子耦合反馈
          ▼
晶格进一步畸变（但幅度远小于电子响应）
```

**结构不是受害者——它设定了方向选择的"种子"。就像一个微斜的旗杆——倾斜本身是初始条件，倒下（电子各向异性大幅发展）的动力来自重力（电子关联能），但初始倾斜**选择了方向**。**

## 五、镍基超导的现状

- 铁基超导中，T_nem > T_mag 这个判断已被多体系验证
- 镍基超导目前**还没有干净的 T_nem vs T_mag 分离实验**
- 如果能测到独立的向列顺磁相 → 确定自旋驱动 → 镍基向列起源与铁基同源
- 如果 T_nem = T_mag 且轨道占据不对称先行出现 → 镍基可能和铁基分岔

**这个空白也是你调研中可以标注的开放科学问题。**
