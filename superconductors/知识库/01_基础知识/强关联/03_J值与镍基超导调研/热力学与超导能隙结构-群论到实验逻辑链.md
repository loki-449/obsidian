# 超导能隙结构与热力学性质：从群论到实验的逻辑链

> 能隙的动量空间对称性（群论规定）→ 低能态密度 N(E) 的能量依赖 → 比热/热导/穿透深度的温度依赖和角依赖。整条逻辑链环环相扣。

---

## 一、总逻辑链

```
群论（晶格点群 D₄）
  → 允许哪些配对对称性（s, dₓ²₋ᵧ², dₓᵧ, g, ...）
  → 每种对称性的能隙 Δ(k) 在费米面上的空间分布
    → 节点类型：无节点 / 线节点 / 点节点
      → 低能态密度 N(E) 的能量依赖：指数 vs 幂律
        → 热力学量（比热、热导、穿透深度）的温度依赖
    → Δ(k) 的角度依赖 → 磁场下热力学量的角度依赖
      → 热导极大方向 = 节点方向
      → 比热极小方向 = 节点方向（低温、低场极限下）
```

---

## 二、第一步：群论规定配对对称性

### 2.1 晶格点群 D₄ 的不可约表示

正方格子（如 CeCoIn₅ 的 CeIn₃ 层）具有 D₄ₕ 点群对称性。在超导配对中，能隙函数 Δ(k) 必须按 D₄ 的一个不可约表示（irrep）变换。

D₄ 的不可约表示和各通道的最低阶基函数：

| 表示 | 名称 | 基函数（k 空间） | 节点情况 |
|:---|:---|:---|:---|
| A₁g | s 波 | 1（或 cos(kₓa)+cos(kᵧa) 的延展 s） | 无节点 |
| A₂g | g 波 | (cos(kₓa)−cos(kᵧa))·sin(kₓa)·sin(kᵧa) | 多节点 |
| B₁g | dₓ²₋ᵧ² 波 | cos(kₓa) − cos(kᵧa) | 4 条线节点（kₓ=±kᵧ） |
| B₂g | dₓᵧ 波 | sin(kₓa)·sin(kᵧa) | 4 条线节点（kₓ=0 或 kᵧ=0） |
| E | p 波 | (sin(kₓa), sin(kᵧa))（二重简并） | 可能有点节点 |

**群论不告诉你哪个表示会被选中——它只告诉你有这些候选。** 实际哪个通道胜出，由配对胶水的波矢结构决定（AFM 涨落 Q=(π, π) 倾向 A₁g s± 或 B₁g dₓ²₋ᵧ²）。

### 2.2 B₁g vs B₂g 的区别

```
B₁g (dₓ²₋ᵧ²):            B₂g (dₓᵧ):
    kᵧ ↑                      kᵧ ↑
       │                         │
   + · │ · −                 + · │ · +
   ────┼──── kₓ             ────┼──── kₓ
   − · │ · +                 − · │ · −
       │                         │

节点在 kₓ = ±kᵧ          节点在 kₓ = 0 和 kᵧ = 0
(45° 对角线方向)          (沿 x 轴和 y 轴方向)
```

**这是全文最关键的一点**：B₁g 和 B₂g 的区别就是节点的位置不同。B₁g 节点在对角线方向（45°），B₂g 节点在轴方向（0° 和 90°）。用角分辨热力学测量找到节点方向 → 直接区分 dₓ²₋ᵧ² 和 dₓᵧ。

## 三、第二步：节点类型决定低能态密度的能量依赖

### 3.1 为什么节点决定一切

超导态的低能准粒子激发来自**能隙为零（Δ=0）的动量**附近的态。如果 Δ(k) 在费米面上某处为零，该处的准粒子不需要克服能隙就能被激发——它们在低温下主导所有热力学响应。

### 3.2 三种节点 → 三种态密度

| 费米面上 Δ=0 的形态 | N(E→0) 行为 | 物理原因 |
|:---|:---|:---|
| 无节点（全能隙） | N(E) ≈ 0（有硬 gap）→ **指数** e^{−Δ/k_B T} | 需要克服有限的最小能隙才能激发准粒子 |
| 线节点 | N(E) ∝ \|E\| → **T 线性** | 节点附近沿垂直方向 Δ 线性打开，动量积分给出 \|E\| |
| 点节点 | N(E) ∝ E² → **T²** | 节点附近沿两个方向 Δ 都线性打开，多出一个 E 因子 |

**直观理解**：想象费米面是二维的。线节点是一维的（一条线），点节点是零维的（一个点）。节点的维数越低，N(E) 在低能的上升越慢（E² 比 \|E\| 更慢）。全能隙则是硬墙——在 E < Δ_min 时完全无声。

---

## 四、第三步：态密度 → 热力学量的温度依赖

### 4.1 比热（电子贡献）

超导态的电子比热：

$$
C_{el} \propto \frac{d}{dT} \int_0^\infty E \cdot N(E) \cdot f(E,T) \, dE
$$

其中 f(E,T) 是费米分布，N(E) 是超导态态密度。

代入不同类型 N(E) 的低能行为：

| 能隙类型 | C_{el}(T→0) | 在 log C vs 1/T 图上 |
|:---|:---|:---|
| 全能隙 | ∝ T^{−2}·e^{−Δ/T}（指数） | 直线（斜率 = −Δ） |
| 线节点 | ∝ T² | 弯曲 |
| 点节点 | ∝ T³ | 更弯曲 |

**CeCu₂Si₂ 案例**：早期较高温测量看到 C ∝ T²，推测线节点 → d 波。后来更低温（< 0.1 K）测量发现 C 偏离 T²，在极低温下转为指数行为 → 推翻了 d 波→ 确认无节点 s 波。

**教训**：线节点的 T² 行为和全能隙的指数行为在**不够低的温度范围**难以区分。线节点的 C ∝ T² 包含一个前因子（节点的数目和斜率），如果节点少/斜率大，T² 行为只在很低温度才明显。

### 4.2 穿透深度

伦敦穿透深度 λ(T) 反映超流密度 ρ_s ∝ 1/λ²。

低温下 Δλ(T) = λ(T) − λ(0) 的行为：

| 能隙类型 | Δλ(T→0) |
|:---|:---|
| 全能隙 | ∝ e^{−Δ/T}（指数） → λ(T) 快速饱和到 λ(0) |
| 线节点 | ∝ T（线性） → λ(T) 线性趋近 λ(0)，不饱和 |
| 点节点 | ∝ T² → 缓慢饱和 |

CeCu₂Si₂ 的穿透深度在低温下**饱和**——支持 s 波（无节点），不支持 d 波（有节点的线性下降）。

### 4.3 热导

电子热导 κ/T 在低温下：

| 能隙类型 | κ/T (T→0, 零场) |
|:---|:---|
| 全能隙 | → 0（无准粒子导热） |
| 线节点 | → 有限常数（节点处残余准粒子导热） |
| 点节点 | → 0（点节点贡献不够） |

**热导的另一个关键功能**：加磁场后，超流被抑制，准粒子恢复。热导的有无变化直接反映能隙的有无。

## 五、第四步：磁场与角分辨——为什么低温低场是关键

### 5.1 外加磁场的双重角色

在超导态下加磁场：

- **激发准粒子**：磁场抑制超流密度（破坏配对），释放被"冻住"的准粒子
- **方向探针**：磁场方向对准节点时 → 准粒子被效率最高地激发 → 比热大、热导大

但磁场太强 → 超导被严重破坏 → 角分辨信息被模糊。

**低温（T ≪ Tc）和低磁场（H ≪ H_c2）是角分辨测量有效的两个必要条件。**

### 5.2 为什么"比热极小 = 节点方向"

外加磁场 H 沿角度 θ 时，产生的准粒子态密度（DOS）正比于：

$$
N_{qp}(H, \theta) \propto H \cdot \sqrt{\frac{v_F}{v_\Delta(\theta)}}
$$

其中 v_F 是费米速度，**v_Δ(θ) 是沿角度 θ 方向能隙的斜率**。

- 在**波腹方向**（Δ 最大）：v_Δ 大 → N_qp 小 → 比热极小
- 在**节点方向**（Δ=0）：v_Δ 小（趋近零）→ N_qp 大 → 比热极大？不对——

**实际上低温低场下 Volovik 效应给出**：比热随角度的振荡中，**N_qp 在节点方向实际上是最小的**。

为什么？因为磁场沿节点方向时，超流绕节点的循环电流能"避开"磁场 → 准粒子产生效率最低 → 比热最小。磁场沿波腹方向时，能隙各向同性、没有方向可以躲 → 准粒子被最大程度激发 → 比热最大。

**完整结论**：

| 低温低场极限 | | |
|:---|:---|:---|
| 比热 | 极小 | = 节点方向 |
| 热导 | 极大 | = 节点方向 |
| 穿透深度 Δλ | 极大 | = 节点方向（更多准粒子 → 超流更弱） |

### 5.3 CeCoIn₅ 中的"反转"——温度/磁场不够低的悲剧

你原文里的关键教训：

> "早期发现比热系数沿 x 或 y 方向极小，推断为 dₓᵧ 波。但后来发现，随着温度上升和磁场增大，比热系数在不同角度的相对大小发生了反转。只有低温低场下值的极小方向才表示节点方向。"

**为什么会反转？**

低温低场下，节点处的准粒子态密度由**能隙的梯度 v_Δ** 决定（Volovik 效应 → 比热极小在节点）。

高温（或高场）下，节点附近更多的准粒子被热激发/场激发到节点外 → 非节点的区域也开始贡献 → 振荡的相位可能反转。

**所以原文里说：早期以为是 dₓᵧ（节点在 x,y 轴方向），但真正低温低场的测量发现对角线方向才是比热极小 → 节点在对角线 → 不是 dₓᵧ → 而是 dₓ²₋ᵧ²。**

## 六、整个逻辑链重述（CeCoIn₅ 为例）

```
1. 群论：D₄ 点群 → 允许 B₁g(dₓ²₋ᵧ²) 或 B₂g(dₓᵧ)
          ↓
2. 两种配对的区别：节点在哪个方向
   B₁g: 节点在 kₓ=±kᵧ（对角线 45° 方向）
   B₂g: 节点在 kₓ=0 或 kᵧ=0（轴方向 0°/90°）
          ↓
3. 比热的角分辨测量（低温 + 低磁场）：
   比热极小方向 = 节点方向
          ↓
4. 实验发现对角线方向比热极小
          ↓
5. 排除 B₂g(dₓᵧ)，确定 B₁g(dₓ²₋ᵧ²)
```

**一句话总结：热力学的角分辨测量，本质上就是让你"看到"Δ(k) 极小值在费米面上的位置。低温低场是看清这个位置的必要条件。搞错温度和磁场，看到的可能是反转后的假象。**

## 七、四种探针的对照

| 探针 | 测量内容 | 判断"无节点 vs 有线节点" | 判断"节点在哪" | 关键限制 |
|:---|:---|:---|:---|:---|
| **比热 C** | 体积准粒子态密度积分 | T²(线节点) vs 指数(无节点) | 角分辨：极小=节点 | 需很低 T 区分 T² 和指数 |
| **穿透深度 Δλ** | 超流密度 → 准粒子数 | 线性(线节点) vs 指数(无节点) | 弱 | 线性 vs T² 在极低 T 难区分 |
| **热导 κ** | 准粒子输运 | κ/T→0(无节点) vs →有限(线节点) | 极大=节点 | 需单晶+低温 |
| **STM/ARPES** | 直接 Δ(k) 动量分布 | 可见 gap 大小 | 直接看到节点位置 | ARPES 需干净表面，STM 需低 T |
