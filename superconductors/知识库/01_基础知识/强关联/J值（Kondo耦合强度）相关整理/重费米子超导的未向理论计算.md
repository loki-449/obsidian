## round 1 基础知识总结
### 1. 奇异的超导相（Unconventional Superconductivity）

要理解"奇异"在哪，先回顾一下常规超导。

**常规超导（BCS 理论）**：两个电子通过交换晶格振动（声子）产生微弱的吸引力，形成库珀对，凝聚成超导态。这个库珀对的波函数是各向同性的 s 波——就像一个圆球，朝各个方向"看"都一样。所有常规超导体的 Tc 都被"麦克米兰极限"（约 30-40 K）束缚住了。
	**库珀对波函数（Cooper Pair Wavefunction）**，通常被称为**配对序参量（Pairing Order Parameter）**，是描述超导态的核心量子力学概念。
### 1. 字面意义：衡量“有序”程度的指标

“序”指的是系统的有序程度，“参量”指一个可以测量的变量。

- **高温（无序态）：** 当系统处于高温（高于临界温度 $T_c$）时，系统处于对称性高的状态，内部往往杂乱无章，此时序参量为 **0**。
    
- **低温（有序态）：** 当系统降温穿过临界点，系统发生相变，自发破缺了对称性，变得更加“有序”。此时序参量从 0 变成一个非零的值。
    

**名字的哲学：** 它就像一个“开关探测器”，用来量化系统从一种物理状态跨越到另一种状态的“有序度”。

### 2. 物理学中的核心价值：描述“对称性破缺”

在物理学中，物质的状态往往由其对称性决定。序参量的名字之所以重要，是因为它精确地刻画了对称性破缺（Symmetry Breaking）的过程：

| **系统示例**  | **序参量**                       | **有序态的意义**      |
| --------- | ----------------------------- | --------------- |
| **超导体**   | 库珀对波函数 $\Psi$                 | 电子相位锁定，实现宏观量子相干 |
| **铁磁体**   | 自旋磁化强度 $M$                    | 电子自旋方向趋于一致，产生磁矩 |
| **液-气相变** | 密度差 $\rho_{liq} - \rho_{gas}$ | 分子空间分布从均匀变为凝结   |
|           |                               |                 |

- **以超导为例：** 在高于 $T_c$ 时，电子系统在相位上是随机的（高度对称/无序）；一旦低于 $T_c$，库珀对形成并集体选择了一个固定的相位，导致对称性破缺。序参量 $\Psi$ 就是那个“告诉”我们系统已经选择了一个特定状态的数学对象。
    

### 3. 为什么称其为“参量”？

因为它不仅是一个定性的标志，还是一个**定量的描述符**：

- **反应剧烈程度：** 序参量的大小（模长）通常直接决定了物理性质的强弱（例如，超导能隙的大小决定了需要多少能量才能破坏超导态）。
    
- **参与动力学：** 在许多物理方程（如金兹堡-朗道方程）中，序参量本身就是方程里的一个**变量**，它的变化决定了系统如何响应外部磁场或电流。
    

### 总结：它是一把“度量衡”

你可以把“序参量”理解为**系统相变的“温度计”或“标尺”**。

在物理学家眼中，**相变就是序参量从零到非零的演化过程**。当你看到“序参量”这个词，它就在提醒你：这个系统正在经历某种对称性的改变，从一种混乱、高度对称的状态，进入了一种结构明确、秩序井然的新状态。
简单来说，它描述了超导体中电子如何通过相互吸引形成“对”（库珀对），并凝聚到同一个量子态的过程。

### 1. 核心定义：什么是库珀对？

在常规超导体（如金属铝或铅）中，虽然电子带有同种电荷相互排斥，但通过**晶格振动（声子）**的媒介，两个电子之间会产生一种微弱的吸引力。这种相互作用使得两个动量相反（$\mathbf{k}$ 和 $-\mathbf{k}$）、自旋相反（$\uparrow$ 和 $\downarrow$）的电子结合在一起，形成一个复合粒子，即**库珀对**。

### 2. 波函数与序参量：它的物理含义

库珀对波函数 $\Psi(\mathbf{r}_1, \mathbf{r}_2)$ 是描述这两个电子处于配对状态的概率振幅。

- **作为“序参量”：** 在统计物理中，序参量用于描述相变。当温度低于超导临界温度 $T_c$ 时，电子系统发生相变，产生一个宏观的、相干的波函数：
    
    $$\Psi(\mathbf{r}) = |\Delta(\mathbf{r})| e^{i\phi(\mathbf{r})}$$
    
    - **$|\Delta(\mathbf{r})|$ (振幅)：** 代表了超导电子对的密度或超导能隙的大小。
        
    - **$\phi(\mathbf{r})$ (相位)：** 这是超导最神奇的地方。所有库珀对都处于同一个量子力学相干状态。这种全局的相位一致性，导致了**零电阻**和**迈斯纳效应**（完全抗磁性）。
        

### 3. 为什么它如此重要？

库珀对波函数揭示了超导体的本质，主要体现在以下三个方面：

- **宏观量子现象：** 由于所有库珀对共享同一个波函数，超导体表现得像一个巨大的“原子”。这意味着微观的量子效应（如相位干涉）被放大到了宏观尺度。
    
- **玻色-爱因斯坦凝聚（BEC）的类比：** 虽然库珀对本身是费米子组成的，但它们在低温下表现得像玻色子。它们倾向于占据能量最低的相同能态，形成一种“超流体”。
    
- **对称性分类：** 配对序参量不仅有大小，还有对称性。例如，传统的 BCS 超导体是“s-波”配对（波函数各向同性）；而高温超导体（如铜氧化物）通常表现为“d-波”配对（波函数具有方向性）。

**非常规超导**：配对"胶水"不再是简单的声子交换。最典型的替代者是**反铁磁自旋涨落**——电子不是靠晶格振动吸引，而是靠周围的磁矩涨落来"粘合"。这带来的后果是：

- **配对对称性不再是 s 波**。比如铜氧化物高温超导体是 **d 波**（像一个四叶草，有节点的方向库珀对波函数为零），钌酸锶可能是 **p 波**（奇宇称配对）。
- **Tc 可以远超麦克米兰极限**（铜氧化物达到 160 K 以上）。
- **超导态和磁性有序态往往彼此相邻**——暗示磁性和超导共享同一个配对机制。

在重费米子体系里，非常规超导通常出现在**反铁磁量子临界点的附近**——调压力或掺杂压制掉磁有序，超导就从量子临界涨落中"长"出来。这是一个非常普遍的图像。

### 2. Q 相（Q Phase）

Q 相是目前争议很大、物理学上极有意思的一个相，最早是在 CeCoIn₅（一种重费米子超导体）中被明确观测到的。

**物理图像**：在一个常规的超导体里，库珀对的总动量为零——两个电子动量大小相等、方向相反。但在强磁场下，塞曼效应会让一个自旋朝上的电子和自旋朝下的电子有不同的费米面大小，如果配对仍然发生在相同大小的费米面上，库珀对就会获得一个**非零的总动量 Q**。

这叫做 **FFLO 态**（Fulde-Ferrell-Larkin-Ovchinnikov，1964 年预言）：超导序参量在空间上**周期性地振荡**，波长就是 ( 2\pi/Q )。

**Q 相的实验特征**：

- 在 CeCoIn₅ 的 ( H )-( T ) 相图中，Q 相出现在高场、低温区域——它是在超导穹顶的"内部"出现的一个**嵌套的新相**。
- NMR 实验看到超导态内的某个区域出现了新的内部磁场分布，暗示序参量空间调制。
- 它很可能是 FFLO 态的第一个明确实验证明，但也有一些观点认为它可能是自旋密度波（SDW）和超导的共存相。

**为什么"奇异"**：FFLO 态在理论上被预言了六十多年，但实验确认极难——它需要非常干净的材料、极低温、强磁场。CeCoIn₅ 的 Q 相是目前最接近 FFLO 的实验证据之一。

### 3. 电四极矩相（Electric Quadrupole Phase）

这个概念来自**轨道物理**，而非电荷或自旋。

**基础图像**：在含有 f 电子的稀土或锕系化合物中，f 轨道的电子云有复杂的空间形状（不像 s 轨道是球形的）。这些轨道带有**高阶电多极矩**——偶极矩（有正负电荷分离）、四极矩（像一个橄榄球，对称拉伸）、八极矩等。

- **电偶极矩**：正负电荷中心不重合 → 有极化 → 会耦合到电场。
- **电四极矩**：电荷分布有椭球形变，但正负电荷中心重合。它不响应均匀电场，但响应**电场梯度**。

当温度降低，这些轨道自由度可以自发地**有序排列**——如同一排橄榄球都沿同一方向排列。这就是**电四极矩有序相**（也叫轨道有序相）。

**为什么重要**：在重费米子体系中，局域 f 电子的轨道自由度可以通过近藤效应与传导电子耦合，驱动非平凡的量子相变。电四极矩序本身破缺的是**空间旋转对称性**（立方 → 四方/正交）而不破缺时间反演对称性，所以它和有磁性的相是有本质区别的。电四极矩量子临界点是近年来的一个活跃研究方向。

一个经典例子是 **CeB₆**（六硼化铈）：它的相图里有一个著名的"II 相"长期被认为是反铁四极矩有序相——电四极矩在其中以交替方向排列。

### 4. 非常规量子临界行为（Unconventional Quantum Criticality）

这个可能是四个概念里最核心、也最深刻的一个。

**量子相变与量子临界点**：经典的相变由温度驱动（比如冰融化）。但如果把温度降到绝对零度，用**非热力学参数**（压力、磁场、掺杂浓度）来调制系统，从一种基态到另一种基态的转变就是**量子相变**。相变发生的那个参数值叫做**量子临界点（QCP）**。

**常规的量子临界理论（Hertz-Millis 理论）**：

- 核心思想：只有序参量的涨落是"慢"的、临界的；传导电子（巡游费米子）只是旁观者，提供阻尼。
- 理论可以"积掉"电子自由度，得到一个只含序参量涨落的有效理论（(\phi^4) 理论）。
- 预测了特定的临界指数（比如比热、磁化率随温度/参数的幂律行为）。

**非常规量子临界行为**：实验发现很多重费米子体系的量子临界行为**不符合 Hertz-Millis 理论**。具体偏差包括：

| 实验观测  | Hertz-Millis 预测 | 实际看到的         |
| ----- | --------------- | ------------- |
| 有效质量  | 有限              | 发散            |
| 费米面   | 连续演化            | 在 QCP 处突变（重构） |
| 动力学标度 | (\omega/T) 不标度  | (\omega/T) 标度 |
| 磁化率   | 特定幂律            | 反常幂律          |
- **HM 理论世界：** 电子是流动的、背景式的集体行为（阻尼项，微扰）。
    
- **非常规 QCP 世界：** 电子是离散的、局部化的、强烈散射的（尖锐点、发散、个体化特征）。

**物理核心**：非常规量子临界的本质是——在 QCP 处，**整个费米面都参与了临界行为**，而不是只有"热点"。近藤效应（局域磁矩被传导电子屏蔽）在 QCP 处瓦解，局域 f 电子从"被屏蔽"变成"自由的"，导致费米面体积突变——这就是**近藤崩坏（Kondo breakdown）**图像。

还有一种观点是**自旋密度波 QCP 中的非常规性**来自序参量涨落和费米子激发的强耦合，必须同时处理二者。

你在氢化物超导里熟悉的图像是：电子-声子耦合 → 库珀对（s 波）→ BCS / Eliashberg → Tc 由声子谱和电声耦合 λ 决定。电子本身是**好费米液体**——准粒子图像成立，有效质量接近裸质量。

现在进入强关联世界，一切出发点变成：**电子自己之间的库仑相互作用大到不能忽略**。这在 f 电子体系里尤其严重——f 轨道局域、能带很窄、库仑 U 很大。

下面用你熟悉的概念做桥梁。

### 1. 从常规超导到非常规超导

**你已知道的**：氢化物里 Tc 由 Eliashberg 方程给出，配对胶水是声子，超导能隙在动量空间上没有节点（s 波）。

**新的物理**：

- 胶水不再是声子，而是**自旋涨落**（反铁磁自旋波）。近邻磁矩反向排列的涨落，把一个电子"push"给另一个电子。
- 这种自旋涨落配对天然倾向于**各向异性的库珀对**。最经典的是 d(x²-y²) 波——在费米面上，能隙有四个节点（像四叶草），在节点方向配对消失。原因是反铁磁涨落在 (π,π) 波矢附近最强，它倾向于连接费米面上不同方向的电子，而库仑排斥在 s 波通道上被抑制，d 波通道反而有净吸引。
- 一个关键实验特征：氢化物超导的 ( 2\Delta/k_BT_c ) 约 3.5-4.5（接近 BCS 值）；铜氧化物能到 8-10，因为配对机制完全不一样。

### 2. Q 相——FFLO 态的实验投射

**你已知道的**：在氢化物（如 H₃S）里，强磁场破坏超导——塞曼劈裂或轨道效应导致库珀对拆散。超导体要么是迈斯纳态（完全抗磁），要么是正常态。

**Q 相的特殊之处**：在 CeCoIn₅ 中，强磁场不直接破坏超导进入正常态，而是进入一个**库珀对带有非零总动量的超导态**（FFLO 态）。

物理图像：想像费米面分成两个——自旋↑和自旋↓的费米面。在强磁场下塞曼效应使它们大小不等。如果按常规的零动量配对（k↑ + (-k)↓ = 0），两个费米面的失配会使配对变得"费力"。但如果允许库珀对有一个净动量 Q，配对可以从 **k↑ + (-k+Q)↓** 产生——这样两个费米面的失配被 Q 弥补了。

结果：超导序参量 (\Delta(r) = \Delta_0 \cos(Q \cdot r)) 或 (\Delta_0 e^{iQ\cdot r})，在实空间上周期性地振荡。这就是 Q 相——名字里的 Q 就是库珀对的总动量。

**这对你从氢化物转过来的意义**：在氢化物里这个效应几乎看不到，因为：

1. 氢化物超导是 s 波，塞曼失配更容易直接破坏配对；
2. 需要极干净的材料（杂质散射会杀死 FFLO 态）；
3. 轨道效应（涡旋）往往先于 FFLO 态出现。

CeCoIn₅ 能出现 Q 相是因为：d 波配对、极干净单晶、强二维性（有天然的轨道效应抑制平面内轨道退配对）、以及重费米子本身的强关联使有效 g 因子很大。

### 3. 电四极矩相——轨道自由度的有序

这个和你之前做的东西距离最远。氢化物超导里你处理的电子自由度基本上是**电荷和自旋**两个自由度（而且自旋在 s 波配对里不重要）。

**新概念**：f 电子有**轨道自由度**——5 个 d 轨道或 7 个 f 轨道，它们在晶体场下分裂。这些轨道的空间形状可以自发地排成有序结构。电四极矩序就是轨道序的一种——破缺的是空间旋转对称性（例如从立方对称 → 四方对称），但不破坏时间反演对称性（所以它不是磁性的）。

**为什么这和超导有关**：如果轨道涨落很强，它也可以作为配对"胶水"——类似于自旋涨落配对，但胶水的来源是**轨道（四极矩）涨落**。这在某些 Pr 基材料（如 PrTi₂Al₂₀）中被认为可能驱动超导。这是杨老师组也关注的方向之一——多极矩物理和超导配对。

**和氢化物的对比**：氢化物里你不需要考虑轨道自由度——H 的 1s 轨道基本没有轨道简并。但进入含 4f/5f 电子的体系，轨道物理是逃不掉的。

### 4. 非常规量子临界——近藤崩坏与费米面重构

**你已知道的**：在氢化物超导中，正常态是标准的费米液体——电阻 ( \rho \propto T^2 )，比热 ( C/T = \text{const} )，准粒子寿命 ( \tau \propto 1/T^2 )。
**重费米子体系的核心矛盾**：有两种基本能量尺度在竞争：
- **近藤效应**（RKKY 互作用）：局域 f 磁矩被传导电子屏蔽 → 形成重的准粒子 → **费米液体**
- **RKKY 相互作用**：局域磁矩之间通过传导电子间接耦合 → 倾向于**磁有序**（反铁磁）
	**RKKY 相互作用**（全称 Ruderman-Kittel-Kasuya-Yosida 相互作用）是固体物理中，描述**两个局域磁矩之间通过传导电子产生长程磁耦合**的理论模型。

这是理解稀土金属、磁性合金以及强关联电子系统（如重费米子系统）中磁有序排列的核心机制。

### 1. 物理图像：传导电子作为“信使”

在一个金属基底中，存在两个距离为 $R$ 的局域磁矩（比如两个 $4f$ 电子占据的稀土离子）。由于它们之间距离很远，直接的交换相互作用几乎为零。

RKKY 相互作用的发生过程如下：

1. **极化源：** 第一个局域磁矩（磁性杂质）通过交换作用影响其周围的传导电子，使得电子自旋在杂质周围产生**自旋密度极化**（即自旋向上和向下的电子密度不再相等）。
    
2. **长程传递：** 这种自旋极化不仅局限在杂质附近，由于费米面的存在，它会以**振荡波**的形式在晶格中向外传播（类似于水波在池塘中的传播）。
    
3. **磁耦合：** 第二个磁性杂质感受到了这种振荡的自旋密度波，从而调整自己的方向，以最小化总能量。
    

### 2. 数学特征：振荡的本质

RKKY 相互作用的强度 $J(R)$ 随距离 $R$ 的变化具有非常显著的特征：

$$J(R) \propto \frac{\cos(2k_F R)}{R^3}$$

- **振荡性：** 相互作用随距离呈现正弦/余弦振荡。这意味着：
    
    - 当 $R$ 处于某些距离时，两个磁矩倾向于**铁磁排列**（平行）。
        
    - 当 $R$ 处于另一些距离时，它们倾向于**反铁磁排列**（反平行）。
        
- **衰减性：** 随距离 $R$ 的三次方衰减。这是一种长程相互作用（相比于直接交换作用，后者随距离指数衰减）。
    
- **$k_F$ 的角色：** 这里 $k_F$ 是费米波矢量。振荡的周期直接取决于费米面的大小，这再次说明了**传导电子是这种相互作用的媒介**。
    

### 3. 在固体物理中的重要性

#### A. 解释磁有序

RKKY 作用解释了为什么许多稀土金属（如钆、铽）即便磁性离子间距很大，也能在低温下展现出复杂的螺旋磁结构或反铁磁结构。晶格结构决定了磁矩的相对位置 $R$，而 RKKY 振荡决定了磁结构是铁磁还是反铁磁。

#### B. 竞争效应：Doniach 相图

这是重费米子物理中的核心内容。存在两种相互竞争的效应：

1. **近藤效应 (Kondo Effect)：** 倾向于将局域磁矩“屏蔽”掉，形成非磁性的费米液体（导致 $T_K$）。
    
2. **RKKY 相互作用：** 倾向于将局域磁矩“锁定”成磁有序态（导致 $T_{RKKY}$）。
    

- 如果 **近藤效应强 ($J$ 大)**：系统呈现费米液体行为，局域磁矩被“抹平”。
    
- 如果 **RKKY 作用强 ($J$ 小)**：系统呈现磁有序行为。
    
- 在两者的临界点附近，往往会产生**量子临界现象**或**非常规超导**。
这两个能量的相对大小决定基态。当通过压力或掺杂把反铁磁序压制到绝对零度时，就到达**反铁磁量子临界点（QCP）**。
### 1. 费米液体理论 (Landau Fermi Liquid Theory)

费米液体理论由朗道（Landau）提出，它解释了为什么金属中的电子虽然存在强库仑排斥，却依然表现得像理想气体。
- **物理图像：准粒子 (Quasiparticles)**
    朗道的关键假设是：尽管真实的电子间有强相互作用，但随着相互作用缓慢开启，每一个电子被“重整化”为带有屏蔽云的**准粒子**。
    - **一一对应：** 准粒子携带与电子相同的电荷和自旋，并遵循泡利不相容原理。
    - **寿命：** 费米面附近的准粒子寿命很长（衰减率 $\Gamma \sim T^2$），因此它们表现出良好的粒子特性。
- **显著特征：**
    1. **热容：** 电子比热容 $C_v \propto T$（线性依赖）。
    2. **电阻：** 电阻率 $\rho \propto T^2$（源于准粒子间的散射）。
    3. **磁化率：** 泡利顺磁性磁化率 $\chi$ 随温度变化极小（常数）。
### 2. 近藤效应 (Kondo Effect)

近藤效应描述的是：当一个具有**局域磁矩的磁性杂质**（如铁原子）被掺杂到非磁性金属（如铜）中时，在极低温度下会发生什么。
- **物理图像：**
    - **高温阶段：** 杂质磁矩和传导电子散射，电阻随温度降低而减小（符合常规金属行为）。
    - **近藤温度 ($T_K$)：** 当温度降至 $T_K$ 以下时，杂质磁矩被传导电子的自旋云“屏蔽”了。
    - **低温阶段：** 传导电子与杂质磁矩形成了非磁性的单重态（Singlet）。此时散射反而增强，导致电阻出现**极小值**，并随温度降低而上升。
- **物理意义：** 这是典型的“强相关”现象，它展示了局域磁矩如何从“个体”转变为与传导电子纠缠在一起的“集体态”。
### 3. 两者的深度关联：从费米液体到重费米子

近藤效应不仅是杂质现象，它也是理解重费米子系统（Heavy Fermion Systems）的关键：
- **晶格近藤效应：** 如果每一个晶格点上都有一个磁性离子（如铈 $Ce$ 或铀 $U$），每一个离子都会发生近藤效应。    
- **重费米子的形成：** 在极低温度下，这些杂质不再是“散射中心”，而是参与构成了费米面。此时，准粒子的有效质量变得极大（甚至可达自由电子质量的千倍），被称为“重电子”。
- **统一图景：** 此时，整个固体变成了“近藤费米液体”。尽管质量很大，它们仍然满足费米液体的特征，只是其参数（如有效质量 $m^*$ 和比热系数 $\gamma$）被近藤效应重整化到了巨大的数值。

以下是为什么“看不出来”以及“如何才能看出来”的物理逻辑：

### 1. 为什么常规能带图“看不出来”？

当你用常规 DFT 进行能带计算时，你实际上是在求解一个单电子哈密顿量，其中多体相互作用被简化为了一个**平均势场（Effective Potential）**。

- **静态背景：** 在这种近似下，所有电子（包括 $f$ 电子）都被处理为在这个“平均场”中运动的独立粒子。
    
- **简并度处理：** 能带图只会显示 $f$ 能级与导带的杂化，表现为能带交叉或排斥（Anti-crossing）。但它**无法展示电子的“纠缠性”和“动态关联”**。
    
- **缺失的关键：** 常规能带图无法展示：
    
    - **电子的寿命（散射率）：** 能带图中的线只是能量 $\varepsilon(k)$，看不出准粒子是否因强相关而“展宽”了。
        
    - **费米面体积的拓扑变化：** 虽然能带图能计算出费米面，但除非你手动调节关联参数，否则常规 DFT 往往默认电子行为是“完全巡游的”，从而无法捕捉到局域态到巡游态的**量子相变（Quantum Phase Transition）**。
        

### 2. 能带图中的“隐形”线索

如果你用更高级的计算方法（如 **DFT+DMFT**，即动力学平均场论），能带图就开始“说话”了，你会看到以下现象：

- **准粒子峰的演化：** 在费米能级附近，你会看到一个非常尖锐的峰（Kondo Resonance）。这是“局域态正在解除、试图变为巡游态”的直接证据。
    
- **能带的“非相干”特征：** 真正的强关联能带，其谱函数（Spectral Function）在费米面外会有大量的“卫星峰（Hubbard Bands）”。常规能带图是一条完美的线，而强关联能带图中，那条线是模糊的，周围充斥着背景噪声。
    
- **费米面“消失”：** 当电子从巡游态变回高度局域态时，费米面在该方向上会断裂或消失。这在常规计算中体现为能带完全平坦且远离费米能级。
    

### 3. 如何“看到”转变？（实验与高级计算）

要证明“局域态解除了”，你不能只看 $E(k)$ 曲线，你必须看**谱函数 $A(k, \omega)$**：

1. **角分辨光电子能谱 (ARPES)：** 这是“看”到费米面转变的最直接实验手段。如果 $f$ 电子局域，你在费米面上找不到对应的能带；如果 $f$ 电子参与了巡游，你会看到平坦的 $f$-带跨越费米能级。
    
2. **动力学平均场论 (DMFT)：** 这是理论上的“照妖镜”。它通过引入频率依赖的自能 $\Sigma(\omega)$，将关联效应放进能带图里。只有在 DMFT 的能带计算中，你才能看到：
    
    - **库仑劈裂：** 上下 Hubbard 带的出现。
        
    - **近藤峰的生长：** 随着参数调节，费米能级处的能带如何逐渐“成形”。
        

### 总结

你说得对，如果你仅仅画一个常规的 DFT 能带色散图，它们看起来就像是一些线交织在一起，根本无法区分这到底是简单的金属，还是复杂的强关联系统。

**能带图只给出了“能量位置”，却没有给出“关联强度”。** 要理解局域-巡游转变，必须关注**谱权重（Spectral Weight）的转移**和**准粒子的寿命（自能项）**。
**"非常规"是什么意思**：
Hertz-Millis 理论（常规的量子临界理论）假设量子临界涨落只涉及序参量自由度，费米子只是背景。这个理论预测了特定的临界指数。
但实验（最早在 CeCu₆₋ₓAuₓ 和 YbRh₂Si₂ 中）发现：

- **费米液体准粒子有效质量在 QCP 处发散**——电子变得越来越"重"，直至无限重
- **费米面在 QCP 处发生突变（重构）**——不是连续演化

这背后是**近藤崩坏（Kondo breakdown）图像：在 QCP 处，近藤屏蔽不再能束缚局域磁矩，f 电子从"被屏蔽、参与费米面"变成"解禁闭、局部磁矩自由"，导致费米面体积跳变。

**和氢化物超导的本质区别**：在氢化物里，正常态性质不"临界"——你不会看到有效质量随某个控制参数（如压力）急剧发散。但在重费米子体系里，QCP 附近的整个物理是"临界"的——包括正常态和超导态。

### 1. 稀磁极限：近藤效应的单体涌现

当杂质浓度极低（稀磁极限）时，各个磁性杂质之间互不相干。

- **物理图像：** 传导电子如同海洋，杂质是海洋中的孤立岛屿。单个电子在遇到磁性杂质时，通过自旋反转散射，在低温下形成“近藤云”（Kondo Cloud）。
    
- **特征：** 此时 RKKY 效应可以忽略，因为杂质间距离太远。这完全遵循经典的 **单杂质近藤效应**。
### 2. 中间浓度：RKKY 与近藤效应的“热身”竞争

当你开始增加浓度，杂质间的距离缩短，RKKY 相互作用开始进入舞台。

- **RKKY 的干扰：** RKKY 是基于费米海的远程介导，它倾向于让两个磁矩“看对眼”（形成铁磁或反铁磁排列）。如果 RKKY 强于近藤屏蔽，磁矩就会被“锁死”成磁序，从而**扼杀**近藤屏蔽的形成（因为磁矩已经被锁死，无法参与动态的电子纠缠）。
    
- **博弈开始：** 此时，系统在“形成动态纠缠的近藤态”与“形成静态有序的磁阵列”之间摇摆。
### 3. 高浓度极限：近藤晶格与巡游态的诞生

当你将杂质浓度提升到每一个晶格点都是一个磁性离子（即“近藤晶格”系统）时，物理图像发生了本质的突变：

- **集体效应（Coherence）：** 这不再是杂质与电子的竞争，而是整个晶格的集体行为。近藤屏蔽不再是个体行为，而是演化成了**相干的近藤晶格态**。
    
- **重费米子的出现：** 正如你所言，此时巡游电子和局域磁矩的“纠缠”最剧烈。局域的 $f$ 电子通过近藤杂化，“进入”了导带，参与构成费米面。
    
- **剧烈的反馈：** 此时的 RKKY 相互作用不再仅仅是“干扰”近藤效应，而是作为一种背景，与近藤杂化共同塑造了系统的基态。如果 RKKY 稍占上风，系统就会进入**反铁磁长程有序态**；如果近藤杂化占优，系统则进入**重费米液体态**
### 为什么这一演化过程如此重要？

你的观察引出了凝聚态物理中的一个“圣杯”问题——**量子临界点（Quantum Critical Point, QCP）**：

1. **Doniach 相图的精髓：** 随着相互作用强度（通常通过压力、磁场或浓度调控）的变化，系统会在“反铁磁有序（RKKY 驱动）”和“费米液体（近藤驱动）”之间剧烈切换。
    
2. **费米面突变：** 在这两者的边界处，费米面的体积会发生从“小”到“大”的突变。
    
    - **小费米面：** $f$ 电子被困在磁序中（RKKY 胜出）。
        
    - **大费米面：** $f$ 电子被解离并纳入巡游（近藤胜出）。
        
在重费米子（近藤晶格）系统中，**相干温度 ($T^*$ 或 $T_{coh}$)** 是一个至关重要的物理分界点。如果把近藤效应看作是从“无序杂质”到“集体态”的演化过程，那么相干温度就是“个体行为”向“集体量子相干态”转变的温度阈值。

我们可以从以下三个物理维度来理解这个分界点：

### 1. 物理图像：从“散射中心”到“能带组成部分”

- **$T > T^*$（非相干态）：**
    
    - 在高于相干温度时，每一个磁性离子（$f$ 电子）仅仅扮演一个**散射中心**的角色。传导电子在晶格中运动时，会不断地随机碰到这些磁性杂质并发生散射。
        
    - **物理表现：** 电阻表现出类似“单杂质近藤效应”的行为，电阻率随温度降低而上升。电子并没有形成统一的集体波函数。
        
- **$T < T^*$（相干态）：**
    
    - 当温度降低至相干温度以下，周期性排列的磁性离子散射波开始发生**相干叠加（类似于布拉格衍射）**。
        
    - **物理表现：** 电子不再被看作是遇到一个个障碍，而是感受到一个周期性的有效势场。此时，$f$ 电子与传导电子杂化，形成了完整的能带结构。
        

### 2. 输运性质的“转折点”：电阻率的极小值与极大值

相干温度在实验观测中有一个非常显著的标志：

- **电阻率极大值（Resistivity Maximum）：** 随着温度从高温向低温下降，由于近藤散射增强，电阻率上升；但当温度降至相干温度 $T^*$ 附近时，电子运动开始变得“相干”且规则，电阻率反而急剧下降。
    
- **分界意义：** 这个极大值点通常被用作判断相干温度 $T^*$ 的直接实验依据。在这一分界点之后，准粒子变得“轻盈”且相干，系统进入费米液体行为（电阻率 $\rho \propto T^2$）。
    

### 3. 量子力学本质：能隙的“打开”与费米面的“重构”

从能带结构的演化来看，$T^*$ 是一个**费米面拓扑结构演变的开始点**：

- **能带杂化（Hybridization）：** 只有当 $T < T^*$ 时，局域的 $f$ 能级与传导带的杂化才足以在费米能级附近打开一个**杂化能隙（Hybridization Gap）**，并形成平坦的、具有重质量特征的准粒子能带。
    
- **有效质量的突变：** 在 $T^*$ 之上，准粒子尚未形成，谈不上“重费米子”；在 $T^*$ 之下，电子因为参与了近藤纠缠，有效质量 $m^*$ 迅速增大。

### 1. 高温下的物理图像：无序的“布朗”动力学

在高温下，系统的热能 $k_B T$ 远大于相互作用能或耦合能。粒子表现出极强的**统计无序性**。

- **运动模式：** 粒子呈现出经典的随机热运动。就像台球桌上的球，虽然它们之间有碰撞，但由于热动能极高，这种碰撞是瞬时的、随机的。
    
- **物理特征：**
    
    - **统计描述：** 遵循麦克斯韦-玻尔兹曼分布，粒子在相空间中均匀分布。
        
    - **相干性丧失：** 粒子之间没有相位锁定的长程联系。即便存在相互作用，也会被无处不在的热涨落瞬间“打断”。
        
    - **局域化视角：** 在固体中，此时的电子或自旋通常表现为**局域态**。它们并不参与形成宏观的集体能带，而是作为一个个独立的散射中心存在。
        

### 2. 低温下的物理图像：有序的“相干”纠缠

当温度降至相互作用能尺度之下（如 $T < T_c$ 或 $T < T^*$），量子效应开始统治系统，粒子运动从“随机”转向“集体”。

- **运动模式：** 粒子进入**集体激发态**。它们不再是独立的个体，而是通过量子纠缠或长程对称性破缺，表现出一致的相干行为（如同阅兵方阵）。
    
- **物理特征：**
    
    - **对称性破缺：** 粒子分布不再均匀，而是选择特定的排列方式（如铁磁中的自旋排列，或超导中的库珀对凝聚）。
        
    - **集体性（Collective Mode）：** 粒子不再表现为单一散射，而是表现为集体振荡（如声子、磁子或库珀对集体激发）。
        
    - **相干性：** 粒子波函数在长距离内保持相位关系。在固体物理中，这体现为费米面的形成、能带杂化，以及电子的“重费米子”巡游行为。

|**电子/粒子状态**|独立散射体 (个案)|准粒子 / 集体态 (群体)|

### 4. 深度洞察：温度作为“分辨率”的透镜

你可以把温度看作观察系统的“焦距”：

- **高温下：** 我们看的是微观个体的剧烈热撞击，此时系统的信息被热噪声掩盖，呈现出宏观平均性质（如普通的电阻率增长，顺磁性）。
    
- **低温下：** 热噪声逐渐退场，系统的量子力学本质（如能带拓扑、电子纠缠、量子相干）显露出来。此时，原本被局域的 $f/d$ 电子能够与传导电子发生有效的量子杂化，系统展现出宏观的拓扑性质或非常规物态。

在超导物理中，**能隙节点（Gap Nodes）**是指能隙函数 $\Delta(\mathbf{k})$ 在费米面上的某些动量点或区域上变为零的现象。这种节点的分布是超导体**序参量对称性**的直接体现，也是识别非常规超导体的关键特征。

能隙节点的分类主要依据它们在动量空间（$k$-空间）中的几何结构及拓扑特征。

### 1. 按几何维度分类

根据 $\Delta(\mathbf{k}) = 0$ 的集合在 $k$-空间中的维度，可分为：

- **点节点 (Point Nodes)：**
    
    - **定义：** 能隙仅在费米面上的特定孤立点处消失。
        
    - **物理表现：** 这些节点通常出现在具有轴对称性的晶体中（如轴向对称性下的 $p$-波或 $d$-波超导体）。例如，在某些重费米子材料的极轴处。
        
    - **态密度特征：** 低能准粒子态密度 $N(E)$ 随能量呈**二次方增加** ($N(E) \propto E^2$)。
        
- **线节点 (Line Nodes)：**
    
    - **定义：** 能隙沿费米面上的某一条闭合曲线消失。
        
    - **典型代表：** 高温超导铜氧化物（$d_{x^2-y^2}$ 波）。在 $k_x = \pm k_y$ 的布里渊区对角线方向上，能隙通过符号变换必经零点，形成线节点。
        
    - **态密度特征：** 低能态密度随能量呈**线性增加** ($N(E) \propto E$)。这是探测线节点最常用的实验手段（比热和热导率测量）。
        

### 2. 按序参量对称性分类

能隙节点的出现完全取决于库珀对波函数（序参量）的轨道对称性。根据晶体点群对称性，可以分为：

- **$s$-波配对（各向同性）：**
    
    - 通常没有节点（全能隙，Fully gapped）。如果存在节点（如 $s_\pm$ 波），通常是由多能带间的符号翻转引起的。
        
- **$d$-波配对（$d_{x^2-y^2}$）：**
    
    - 这是铜基超导体的特征，具有典型的**线节点**。在布里渊区中心附近的对角线方向，能隙相位翻转，导致四个线节点。
        
- **$p$-波配对：**
    
    - 常见于拓扑超导体或三重态超导体。由于其宇称奇性，能隙在费米面上必然存在节点（类似于点节点）。
        

### 3. 按拓扑稳定性分类

从拓扑物理的角度，节点可以分为：

- **稳定节点（Stable/Topological Nodes）：**
    
    - 这些节点受到晶体对称性（如镜面反射、转动对称性）的保护。即使系统受到微小的无序或杂质扰动，节点也不会消失。
        
- **偶然节点（Accidental Nodes）：**
    
    - 这些节点出现在能隙函数的一般位置，没有对称性保护。如果改变系统参数（如压力、化学掺杂）或引入杂质，这些节点可能会发生位移或湮灭。
        

### 4. 实验如何探测能隙节点？

判断一个超导体是否存在节点，物理学家通常使用以下方法：

1. **比热 $C(T)$：** 全能隙超导体在 $T \to 0$ 时比热呈指数衰减；有节点时，比热呈幂律行为（如 $T^2$ 或 $T^3$）。
    
2. **伦敦穿透深度 $\lambda(T)$：** 线节点会导致穿透深度随温度表现为线性关系 ($\Delta \lambda \propto T$)，而全能隙表现为平坦的指数行为。
    
3. **角分辨光电子能谱 (ARPES)：** 最直观的方法。可以直接在 $k$-空间“看到”能隙在费米面某些位置闭合。

朗道（Lev Landau）在1937年提出的二阶相变理论（Landau Theory of Phase Transitions）是凝聚态物理中描述相变最为经典且普适的理论框架。其核心思想在于：**相变可以通过对称性的破缺来描述，并引入一个宏观的“序参量（Order Parameter）”来刻画这种对称性的丧失。**

### 1. 核心理论框架：朗道自由能展开

朗道理论的核心是假设系统的自由能 $F$ 可以展开为序参量 $\eta$ 的幂级数。对于一个对称系统（即 $F(\eta) = F(-\eta)$），自由能只包含偶次项：

$$F(T, \eta) = F_0 + a(T-T_c)\eta^2 + \frac{1}{2}b\eta^4 + \dots$$

- **序参量 ($\eta$)：** 在相变前 $\eta=0$（对称相）；在相变后 $\eta \neq 0$（有序相）。例如：铁磁体中的磁化强度 $M$。
    
- **系数 $a$：** 假设 $a > 0$，这是一个控制相变的关键温度依赖项。
    
- **系数 $b$：** 通常假设 $b > 0$，以保证自由能在高阶项下是稳定的。
    

### 2. 物理图景：能量势阱的演化

通过分析 $F(\eta)$ 对 $\eta$ 的极小值点，我们可以清晰地看到相变发生的物理过程：

- **当 $T > T_c$ 时（对称相）：** $a(T-T_c) > 0$。自由能函数在 $\eta=0$ 处有一个极小值。系统处于无序状态。
    
- **当 $T < T_c$ 时（有序相）：** $a(T-T_c) < 0$。$\eta=0$ 变成了势能极大值（不稳定点），而极小值出现在 $\eta = \pm \sqrt{\frac{a(T_c-T)}{b}}$。系统“自发”选择一个非零的序参量值，从而导致对称性破缺。
    

### 3. 关键结论：朗道临界指数

朗道理论能够推导出相变点附近的物理量行为，这被称为“平均场行为”：

1. **序参量：** $\eta \propto (T_c - T)^{1/2}$，即临界指数 $\beta = 1/2$。
    
2. **磁化率（响应函数）：** $\chi \propto |T - T_c|^{-1}$，即临界指数 $\gamma = 1$。
    
3. **比热容：** 在 $T_c$ 处发生有限的跳变，即临界指数 $\alpha = 0$。
    

### 4. 朗道理论的局限性

朗道理论虽然极其简洁且成功，但它是一种**平均场理论（Mean-Field Theory）**，在以下情况下会失效：

- **忽略了涨落：** 朗道理论假设序参量在空间各处是均匀的，忽略了长波长的热涨落。在临界点附近，涨落会变得极其剧烈，导致上述临界指数与真实实验值（如三维伊辛模型）存在显著偏差。
    
- **Ginzburg 判据：** 当维度低于临界维度（对于典型的标量场系统是 $d=4$）时，涨落效应无法忽略，朗道理论的平均场指数不再准确。
    

### 5. 为什么它很重要？

尽管存在局限性，朗道理论提供了一套通用的语言：

1. **普遍性（Universality）：** 它指出无论系统的微观本质是什么（铁磁、超导还是液氦），只要它们的序参量对称性相同，它们的临界行为就服从相同的类（Universality Class）。
    
2. **对称性破缺范式：** 它是现代物理描述复杂有序态（如电四极矩序、超导序）的基石。每当我们发现一个新的物相，物理学家的第一反应就是：**“它的序参量是什么？它破缺了什么对称性？”**
