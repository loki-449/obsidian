# 本征值问题与谱分解

## 定义

对算符（矩阵）$A$，若存在非零向量 $\mathbf{v}$ 和标量 $\lambda$ 使得：
$$A\mathbf{v} = \lambda \mathbf{v}$$
则 $\lambda$ 是本征值，$\mathbf{v}$ 是本征矢量。

在物理中，含时薛定谔方程 $i\hbar\partial_t\vert\psi\rangle = H\vert\psi\rangle$ 通过定态分解 $H\vert\psi_n\rangle = E_n\vert\psi_n\rangle$ 化为本征值问题。**哈密顿量的本征值就是能级，本征矢量就是波函数**。

---

## 特征方程

本征值满足：
$$\det(A - \lambda I) = 0$$

这是 $n$ 次多项式方程（$n$ 是矩阵维数），给出 $n$ 个本征值（计入重根）。

---

## 厄米矩阵的谱分解（谱定理）

这是**整个量子力学计算的核心定理**。对厄米矩阵 $H = H^\dagger$：

1. **本征值全为实数** — $E_n \in \mathbb{R}$（能量可测量）
2. **不同本征值的本征矢量正交** — $\langle \psi_n \vert \psi_m \rangle = \delta_{nm}$
3. **本征矢量构成完备基** — 任一态可展开为 $\vert\Psi\rangle = \sum_n c_n \vert\psi_n\rangle$

### 谱分解（对角化）

$$H = \sum_{n=1}^{N} E_n \vert \psi_n \rangle \langle \psi_n \vert$$

在矩阵语言下：
$$H = U \Lambda U^\dagger$$

其中 $\Lambda = \operatorname{diag}(E_1, E_2, \ldots, E_N)$，$U$ 的列就是本征矢量，且 $U^\dagger U = I$（幺正）。

### 矩阵对角化的物理意义

- $U$ 是从"原始基"（如占据数基）到"能量本征基"的变换
- $H$ 在能量基下是对角的——$\langle \psi_n \vert H \vert \psi_m \rangle = E_n \delta_{nm}$
- $U^\dagger H U = \Lambda$ 就是"对角化 $H$"

---

## 简并

若 $\lambda$ 对应 $k$ ($k>1$) 个线性无关的本征矢量，则 $\lambda$ 是 $k$ 重简并的。

简并子空间的基可以任意选取——物理上常用对称性（如 $S_z$ 量子数）来固定。

---

## 重要定理

### Rayleigh-Ritz 变分原理

基态能量：
$$E_0 = \min_{\|\psi\|=1} \langle \psi \vert H \vert \psi \rangle$$

任意试探波函数给出的期望值 $\geq$ 真实基态能量。这是**变分法（如 DMRG 的基态优化）**的数学基础。

### 柯西交错定理（Cauchy Interlace Theorem）

$H$ 是 $N\times N$ 厄米矩阵，$H_{N-1}$ 是去掉第 $N$ 行第 $N$ 列的 $(N-1)\times(N-1)$ 主子矩阵。记本征值为 $E_1 \leq E_2 \leq \cdots \leq E_N$ 和 $\tilde{E}_1 \leq \cdots \leq \tilde{E}_{N-1}$，则：
$$E_k \leq \tilde{E}_k \leq E_{k+1}$$

**在 DMRG 截断中的应用**：截断（丢掉小的奇异值对应的态）相当于去掉密度矩阵的某些行和列——交错定理保证截断后的本征值不会跑到原谱外面去。

## 代码实现

### 小矩阵直接对角化

```python
import numpy as np
from scipy.linalg import eigh

# H 是厄米矩阵
E, U = eigh(H)  # 返回本征值（升序）和本征矢量矩阵

# 验证：U^† H U 应该等于 diag(E)
H_diag = U.conj().T @ H @ U
assert np.allclose(H_diag, np.diag(E))
```

### 大稀疏矩阵 → Lanczos

精确对角化 $O(N^3)$，$N=2^M$ 指数增长 → M=20 时 $N \approx 10^6$ 已经无法直接对角化。需要用 Lanczos 算法只求极端本征值。
