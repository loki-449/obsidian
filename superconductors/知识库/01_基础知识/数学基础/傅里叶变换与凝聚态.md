# 傅里叶变换与凝聚态

## 一句话定义

傅里叶变换是把"电子在哪里"（实空间 $f(\mathbf{r})$）和"电子具有怎样的动量/波长"（倒空间 $f(\mathbf{k})$）连接起来的字典——凝聚态里几乎所有"看起来很不一样"的理论对象（能带、衍射花样、磁化率、Green 函数）本质上都是同一个物理量在这两种语言之间来回翻译的结果。

---

## 为什么凝聚态离不开它：一个你已经用过的例子

回到你已经熟悉的 [[Mott绝缘体与Hubbard模型|Mott 绝缘体]] 笔记里那一段：半满 Hubbard 模型在强耦合下等效成 Heisenberg 反铁磁，实空间里"最近邻自旋反平行、次近邻自旋平行"这种交替排列，写成动量空间语言就是磁化率在布里渊区 M 点 $\mathbf{Q}=(\pi,\pi)$ 处出现一个峰。

这不是巧合，而是傅里叶变换的直接结果：

$$V(\mathbf{r})\propto e^{i\mathbf{Q}\cdot\mathbf{r}} = (-1)^{x+y}$$

一个**实空间里的交替符号图案**，傅里叶变换后就是**倒空间里一个尖锐的峰**。这是全书最常用的翻译规则之一：实空间的"周期性花纹"⟷ 倒空间的"δ函数峰"。你后面要做的 J 值实验测量（INS/RIXS 测自旋波色散，本质是测 $\chi(\mathbf{q},\omega)$）能不能测出干净的峰、峰在哪，全靠这个对应关系。

---

## 数学表述

### 连续傅里叶变换

$$f(\mathbf{k}) = \int d^d r\; f(\mathbf{r})\, e^{-i\mathbf{k}\cdot\mathbf{r}}, \qquad f(\mathbf{r}) = \frac{1}{(2\pi)^d}\int d^dk\; f(\mathbf{k})\, e^{i\mathbf{k}\cdot\mathbf{r}}$$

正变换把"位置的函数"拆成一堆平面波 $e^{i\mathbf{k}\cdot\mathbf{r}}$ 的叠加，$f(\mathbf{k})$ 是每个波矢分量的权重。逆变换是把这些平面波加回去，重建原来的实空间图像。

### 格点（离散）版本

凝聚态处理的通常不是连续空间，而是格点 $\mathbf{r}_i = i\mathbf{a}$（$\mathbf{a}$ 是晶格矢量）。离散傅里叶变换：

$$f(\mathbf{k}) = \sum_i f(\mathbf{r}_i)\, e^{-i\mathbf{k}\cdot\mathbf{r}_i}, \qquad f(\mathbf{r}_i) = \frac{1}{N}\sum_{\mathbf{k}} f(\mathbf{k})\, e^{i\mathbf{k}\cdot\mathbf{r}_i}$$

$N$ 是格点数。因为格点周期性，$\mathbf{k}$ 不再取遍所有实数，而是被限制在一个有限区域——**第一布里渊区**（下面细讲），这是离散版本和连续版本最本质的区别。

### 正交归一性：这是傅里叶变换"合法"的数学根基

平面波 $\{e^{i\mathbf{k}\cdot\mathbf{r}}\}$ 在格点上满足正交关系：

$$\frac{1}{N}\sum_i e^{i(\mathbf{k}-\mathbf{k}')\cdot\mathbf{r}_i} = \delta_{\mathbf{k}\mathbf{k}'}$$

这正是 [[向量空间与内积]] 里"正交归一基"的具体实现——傅里叶变换本质上是**换基**：把在占据数基/位置基下写的向量，改写到"平面波基"下。你在数学基础里学过的完备性关系 $\sum_i |e_i\rangle\langle e_i| = I$，这里就是 $\sum_{\mathbf{k}} |\mathbf{k}\rangle\langle \mathbf{k}| = I$，插入平面波的完备基是凝聚态推导里最常见的技巧之一。

## 凝聚态里的三个核心应用

### 1. Bloch 定理：为什么周期势场里会出现能带

晶格有周期性 $V(\mathbf{r}+\mathbf{a}) = V(\mathbf{r})$，把周期势场傅里叶展开成倒格矢 $\mathbf{G}$ 的求和，代入薛定谔方程会发现：波函数必须写成

$$\psi_{\mathbf{k}}(\mathbf{r}) = e^{i\mathbf{k}\cdot\mathbf{r}}\, u_{\mathbf{k}}(\mathbf{r})$$

一个平面波包络 $\times$ 一个和晶格同周期的调制函数。**能带的出现，本质上是"周期势场的傅里叶系数"和"平面波基下薛定谔方程"耦合的结果**——$\mathbf{k}$ 好的量子数，是因为平移对称性在傅里叶变换后变成了 $\mathbf{k}$ 守恒（布洛赫定理是空间平移群的表示论在傅里叶语言下的具体形式）。

### 2. 结构因子：为什么衍射实验能测出晶体结构

X 射线/中子打到晶体上，散射强度正比于电荷/自旋密度的傅里叶变换模方：

$$S(\mathbf{q}) = \left|\sum_i n_i\, e^{-i\mathbf{q}\cdot\mathbf{r}_i}\right|^2$$

晶体周期性 → 实空间密度是周期函数 → 傅里叶变换只在倒格矢 $\mathbf{q}=\mathbf{G}$ 处不为零 → 衍射花样是离散的亮点，不是连续的晕染。这就是为什么单晶衍射给出的是清晰的斑点阵列。

### 3. 磁化率 $\chi(\mathbf{q},\omega)$：你现在真正要用的那个

自旋关联函数 $\langle S_i(t) S_j(0)\rangle$ 傅里叶变换到动量-频率空间就是磁化率 $\chi(\mathbf{q},\omega)$。INS/RIXS 测的正是这个量——谱在某个 $\mathbf{q}$、某个 $\omega$ 处出峰，对应实空间里"相隔 $\mathbf{r}_i-\mathbf{r}_j$ 的两个自旋、以频率 $\omega$ 关联涨落"这件事。你在 J 值调研里看到的"层间磁激发信号"，就是 $\chi(\mathbf{q}_\perp,\omega)$ 在某个 $\mathbf{q}_\perp$ 附近的谱重——傅里叶变换是把"测到一个峰"翻译成"存在某种周期性关联"的唯一桥梁。这个磁化率的具体唯象形式见 [[MMP磁化率]]。

## 怎么算：从解析到数值

| 情形 | 方法 |
|---|---|
| 简单周期结构、少数几个 $\mathbf{k}$ 点 | 解析求和（如上面的结构因子） |
| 任意实空间数据（如 DFT 输出的电荷密度网格） | 快速傅里叶变换 FFT，$O(N\log N)$ |
| 连续谱、需要解析延拓 | 傅里叶变换 + [[Kramers-Kronig与解析延拓]]，把实频响应和虚频/虚时间数据联系起来（DMFT 计算里从虚时间格林函数反推实频谱函数就是这一步，这是你后面会撞上的一个真正的技术难点） |

### 代码实现

```python
import numpy as np

# 实空间格点数据 -> 动量空间
f_r = np.array([...])          # 长度 N 的实空间数据（比如某个方向上的电荷密度）
f_k = np.fft.fft(f_r) / len(f_r)   # 归一化卷积成傅里叶系数
k_grid = np.fft.fftfreq(len(f_r)) * 2 * np.pi   # 对应的 k 值（单位：1/格点间距）

# 验证 Parseval 定理：实空间能量 = 动量空间能量
assert np.allclose(np.sum(np.abs(f_r)**2), len(f_r) * np.sum(np.abs(f_k)**2))
```

## 尺度：数量级要有概念

| 量 | 典型数值 |
|---|---|
| 晶格常数 $a$ | 几个 Å（比如 La₃Ni₂O₇ 的面内 Ni-Ni 距离 ~3.9 Å） |
| 布里渊区边界 $\sim \pi/a$ | 约 $0.5$–$1$ Å⁻¹ |
| 磁化率谱峰的动量位置 $\mathbf{Q}$ | 反铁磁关联通常在 $(\pi,\pi)$ 附近，即布里渊区边界或角点 |
| 磁化率谱峰的能量位置 $\omega$ | 对应 $J$ 的量级，几十到上百 meV（见 [[J值与Tc关系跨体系调研]]） |
| DFT 电荷密度网格傅里叶变换 | 实空间网格几十到上百个点/方向，倒空间截断由平面波基组的能量截断（Ecut，通常几百 eV）决定 |

**一句话记忆**：实空间尺度越小（晶格常数越短），倒空间尺度就越大（布里渊区越大）——这是傅里叶变换"倒易"这个名字的来源，也是为什么高压下晶格收缩会让能带结构、磁化率峰位都发生系统性移动。
