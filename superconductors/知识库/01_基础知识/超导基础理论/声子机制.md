# 声子机制

## 物理图像
> 第一个电子经过晶格时使正离子发生位移，
> 形成局部正电荷积累，吸引第二个电子，
> 两个电子通过晶格形成间接吸引。

## 关键参数

### 电声耦合常数 λ
$$\lambda = 2\int_0^\infty \frac{\alpha^2F(\omega)}{\omega}d\omega$$

- λ < 0.3：弱耦合
- 0.3 < λ < 1.0：中等耦合  
- λ > 1.0：强耦合（氢化物通常在1.5~3.0）

### Eliashberg 谱函数
$$\alpha^2F(\omega)$$
- 描述声子态密度与电声耦合强度的乘积
- 是计算 Tc 的核心物理量
- 可通过 DFPT + EPW 计算获得

### 对数平均声子频率
$$\omega_{log} = \exp\left(\frac{2}{\lambda}\int_0^\infty \frac{d\omega}{\omega}\alpha^2F(\omega)\ln\omega\right)$$

## 氢化物中的特殊性
- H 原子质量极轻 → 声子频率极高
- 高频声子 → 高 ωlog → 有利于高 Tc
- 高压下 H-H 键活化 → λ 增大
