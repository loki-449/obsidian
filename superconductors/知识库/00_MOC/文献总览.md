# 文献总览

管道生成的卡片都落在 `03_文献笔记/` 根目录，一篇一个文件。下面的面板靠
frontmatter 里的正交轴查询：`role`（这篇对我有什么用）、`system`（材料体系）、
`method`（技术手段）、`stage`（读到哪了）、`relevance`（相关度 1-5）。

待裁决的新文献在 [[文献收件箱]]。

> [!tip] 改了读到哪一步，就改卡片 frontmatter 里的 `stage`
> 未读 → 略读 → 精读 → 已消化。下面所有面板都跟着这个字段走。

---

## 该读的：高相关且未读

```dataview
TABLE WITHOUT ID
  link(file.link, title) AS 标题,
  relevance AS 相关,
  system AS 体系,
  role AS 定位,
  year AS 年份
FROM "知识库/03_文献笔记"
WHERE stage = "未读" AND relevance >= 4
SORT relevance DESC, score DESC
LIMIT 25
```

## 在读：略读和精读中

```dataview
TABLE WITHOUT ID
  link(file.link, title) AS 标题,
  stage AS 状态,
  method AS 方法,
  relevance AS 相关
FROM "知识库/03_文献笔记"
WHERE stage = "略读" OR stage = "精读"
SORT stage ASC, relevance DESC
```

## 本周新增

```dataview
TABLE WITHOUT ID
  link(file.link, title) AS 标题,
  relevance AS 相关,
  score AS 打分,
  added AS 入库
FROM "知识库/03_文献笔记"
WHERE added AND date(added) >= date(today) - dur(7 days)
SORT added DESC, score DESC
```

## 按体系分布

```dataview
TABLE WITHOUT ID
  system AS 体系,
  length(rows) AS 篇数,
  sum(map(rows, (r) => choice(r.stage = "未读", 0, 1))) AS 已读
FROM "知识库/03_文献笔记"
WHERE stage
FLATTEN system
GROUP BY system
SORT length(rows) DESC
```

## 按定位分布

一篇文章可以同时是「方法」和「数据」，所以下面各行的篇数加起来会超过总数。

```dataview
TABLE WITHOUT ID
  role AS 定位,
  length(rows) AS 篇数
FROM "知识库/03_文献笔记"
WHERE stage
FLATTEN role
GROUP BY role
SORT length(rows) DESC
```

## 按方法分布

```dataview
TABLE WITHOUT ID
  method AS 方法,
  length(rows) AS 篇数
FROM "知识库/03_文献笔记"
WHERE stage
FLATTEN method
GROUP BY method
SORT length(rows) DESC
```

## 交叉查询模板

想问「所有讲 DMFT 的镍氧化物文章」，复制下面这段改条件就行。

```dataview
TABLE WITHOUT ID
  link(file.link, title) AS 标题,
  stage AS 状态,
  relevance AS 相关
FROM "知识库/03_文献笔记"
WHERE contains(method, "DMFT") AND contains(system, "镍氧化物")
SORT relevance DESC
```

常用条件：

- 按定位：`contains(role, "方法")` / `contains(role, "综述")` / `contains(role, "竞品")`
- 按体系：`contains(system, "重费米子")` / `contains(system, "铜氧化物")`
- 按方法：`contains(method, "ARPES")` / `contains(method, "DFT+U")`
- 按状态：`stage = "已消化"`
- 按打分：`score >= 8`

## 卡片健康度

没打上任何定位标签的卡片 —— 要么是打标签时模型拿不准，要么是跳过了 LLM。

```dataview
TABLE WITHOUT ID
  link(file.link, title) AS 标题,
  score AS 打分,
  added AS 入库
FROM "知识库/03_文献笔记"
WHERE stage AND (!role OR length(role) = 0)
SORT score DESC
LIMIT 20
```

没关联到 Zotero 的卡片 —— 多半是生成卡片时 Zotero 没开，重跑一次 `sync` 能补上。

```dataview
LIST
FROM "知识库/03_文献笔记"
WHERE stage AND (!zotero OR zotero = "")
LIMIT 20
```
