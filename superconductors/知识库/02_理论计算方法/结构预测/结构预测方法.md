# 结构预测方法

## 为什么需要结构预测
> 高压下氢化物的结构无法直接从实验确定，
> 需要通过理论预测候选结构，再与实验对比。

## 主流方法对比

| 方法 | 软件 | 算法 | 特点 |
|------|------|------|------|
| 粒子群优化 | CALYPSO | PSO | 国内开发，界面友好 |
| 进化算法 | USPEX | GA | 功能强大，应用广泛 |
| 随机搜索 | AIRSS | Random | 简单高效 |
| 贝叶斯优化 | BOA | Bayesian | 新兴方法 |

## CALYPSO 使用流程

### 输入文件 input.dat
## 体系设置

Type of Calc = crystal # 晶体搜索 
Atom Types = La H # 元素种类 
Atom Nums = 1 10 # 原子数目 
Formula Units = 1 2 3 4 # 搜索的化学计量比

## 搜索参数

Pop Size = 30 # 每代结构数 
Max Step = 50 # 最大代数 
Pso Ratio = 0.6 # PSO比例

## 压力设置

External Pressure = 200 # GPa

## VASP接口

TS Code = vasp
### 运行流程
```bash
# 1. 准备VASP赝势和模板INCAR
# 2. 运行CALYPSO
calypso.x > log &

# 3. 监控进度
tail -f log

# 4. 分析结果
# 查看 results.dat 中的最低能量结构
```

## USPEX 使用流程

### 关键输入 INPUT.txt
```matlab
% 计算类型
calculationType = 300        % 晶体结构预测

% 体系设置
numSpecies = [1 10]          % La H 各原子数
atomicNumbers = [57 1]       % 原子序数

% 搜索设置
populationSize = 30
numGenerations = 50
fracGene = 0.5
fracRand = 0.2
fracPerm = 0.1
fracAtomsMut = 0.1

% 压力
ExternalPressure = 200       % GPa
```

## 结果筛选流程
大量候选结构 
↓ 
按焓值排序（取前20~50个）
↓ 
去除重复结构（对称性分析） 
↓ 
精细结构优化
↓
计算声子（判断动力学稳定性） 
↓ 
无虚频的结构 → 计算电声耦合 
↓ 
筛选高Tc候选体系

## 凸包图分析

- 计算各化学计量比的形成焓
- 位于**凸包上**的结构热力学稳定
- 凸包上方的结构亚稳，但可能动力学稳定
- 氢化物在高压下凸包形状变化显著
