# La₃Ni₂O₇ 层间 vs 层内电子：多维度统计归类

> 体系：双层 Ruddlesden-Popper 镍氧化物 La₃Ni₂O₇ (n=2)
> 核心问题：层间反铁磁耦合 J⊥ ≫ 层内反铁磁耦合 J∥ 的物理根源

---

## 一、电子构型维度

### 1.1 Ni 价态与总电子占据

| 量 | 数值 |
|:---|:---|
| Ni 平均价态 | +2.5 |
| 每 Ni 的 d 电子数 | d^{7.5}（平均 7.5 个电子，2.5 个空穴）|
| 双层总计 | 5 个空穴分布在两个 Ni 原子上 |
| 名义电子构型 | 50% Ni²⁺(d⁸) + 50% Ni³⁺(d⁷) |

### 1.2 轨道填充（每 Ni 原子，八面体晶体场 + 四方畸变）

```
能级（低→高）        电子数        空穴数        填充状态
─────────────────────────────────────────────────
d_xy  (t₂g)            2            0          满
d_xz  (t₂g)            2            0          满
d_yz  (t₂g)            2            0          满
─────────────────────────────────────────────────
d_z²  (e_g, 下移)       ~1           ~1         半满
d_x²-y² (e_g, 上移)     ~0.5         ~1.5       近空
─────────────────────────────────────────────────
合计                    7.5          2.5
```

- **t₂g 三兄弟**：满占据 → 化学惰性，不贡献低能物理 → 可以"积分掉"
- **d_z²**：半满 → 局域磁矩的载体，决定层间磁性
- **d_x²-y²**：四分之一满 → 巡游载流子，决定面内输运

### 1.3 层间 vs 层内电子构型的本质区别

| 维度 | d_z²（层间耦合主导） | d_x²-y²（层内耦合主导） |
|:---|:---|:---|
| 占据数 | ~1 电子/Ni | ~0.5 电子/Ni |
| 空穴数 | ~1 | ~1.5 |
| 关联强度 | 极强（m*/m ≈ 5–8） | 中等（m*/m ≈ 2–3） |
| 局域/巡游 | 局域（近 Mott 转变） | 相对巡游 |
| 磁矩 | 明确局域磁矩 | 磁矩不完整 |
| 在 112 K CDW 转变中的角色 | 可能主导密度波不稳定性 | 提供费米面嵌套 |

## 二、d 电子空间分布与轨道指向维度

### 2.1 五个 d 轨道的实空间形状

```
轨道        空间指向               主要重叠方向      配体轨道
───────────────────────────────────────────────────────────
d_z²        沿 z 轴（层间 c 轴）   纵向 σ             O-2p_z
             赤道面环形分布         面内弱 π            O-2p_x/p_y

d_x²-y²     沿 x, y 轴四瓣        面内 σ             O-2p_x/p_y
             (在 NiO₂ 面内)        无 z 方向分量       无

d_xy        沿 xy 对角方向        面内 π             O-2p_x/p_y
             (面内)

d_xz        沿 xz 平面            面间 π + 斜向      O-2p_x/p_z
             (含 z 分量)

d_yz        沿 yz 平面            面间 π + 斜向      O-2p_y/p_z
             (含 z 分量)
```

### 2.2 关键洞察：d_z² 的"双重人格"

d_z² 是唯一同时具有**强面外指向**和**面内分量**的 e_g 轨道：

- **沿 c 轴（层间）**：伸向上下两层的 apical 氧 → Ni–O–Ni 直线 σ 型通路 → 最强超交换
- **赤道面成分（面内）**：环形分布在 NiO₂ 面内 → 与面内 O-2p 有弱的 π 型重叠 → 贡献少量面内耦合

**d_x²-y² 则纯粹在面内**：四瓣全部指向 x, y 方向的面内氧原子 → 纯粹的面内 σ 型通路，无 z 分量。

### 2.3 轨道重叠积分对比

```
通路                        轨道组合              重叠类型    强度评级
─────────────────────────────────────────────────────────────────
层间 Ni–O(apical)–Ni        d_z²–p_z–d_z²         σ          ★★★★★
层间 Ni–O(apical)–Ni        d_xz–p_x–d_xz         π          ★★
层间 Ni–O(apical)–Ni        d_yz–p_y–d_yz         π          ★★
面内 Ni–O(planar)–Ni        d_x²-y²–p_x/p_y–d_x²-y²  σ       ★★★
面内 Ni–O(planar)–Ni        d_z²–p_x/p_y–d_z²     π          ★
面内 Ni–O(planar)–Ni        d_xy–p–d_xy            π          ★★
─────────────────────────────────────────────────────────────────
```

σ 型重叠 >> π 型重叠（σ 的直接 lobe-to-lobe 重叠积分远大于 π 的侧向重叠）

## 三、相互作用维度

### 3.1 超交换（Superexchange）— AFM 主导机制

**层间 J⊥**：
- 机制：d_z²–O–d_z²，σ 通路，Ni–O–Ni 键角在高压下趋近 180°
- 来源：d_z² 电子高度局域（近 Mott），形成良好的局域自旋 S = 1/2
- 大小估计：J⊥ ~ 60–100 meV（高压相）

**层内 J∥**：
- 机制：d_x²-y²–O–d_x²-y²，σ 通路，Ni–O–Ni 键角 ~165–170°（受八面体倾转影响）
- 来源：d_x²-y² 电子相对巡游，局域磁矩不够完整
- 大小估计：J∥ ~ 10–30 meV

**J⊥/J∥ ~ 3–10**

### 3.2 双交换（Double Exchange）— FM 竞争机制

- 仅作用于**混合价态**且**电子可跳跃**的通路
- 在 La₃Ni₂O₇ 中：d_x²-y² 巡游性强 → 面内双交换（倾向 FM）与面内超交换（倾向 AFM）**竞争 → 削弱净 J∥**
- d_z² 局域性强 → 电子跳跃积 t 小 → 层间双交换效应**可忽略 → J⊥ 不被削弱**

### 3.3 Hund 耦合 — 轨道间的铁磁关联

```
同一 Ni 位点上：
   d_z² 自旋 ↑↑↑ Hund 耦合 ↑↑↑ d_x²-y² 自旋

→ 迫使 d_z² 和 d_x²-y² 的自旋方向在同一位点一致
→ 间接地将面内和面间的磁序耦合在一起
```

Hund 耦合 J_H ~ 0.7–0.9 eV，远大于超交换能标。这意味着局域的 d_z² 磁矩通过 Hund 耦合"钉扎"了巡游 d_x²-y² 的自旋取向。

### 3.4 三种相互作用对照

| 相互作用 | 符号/倾向 | 作用方向 | 主导轨道 | 能标 | 对 J⊥/J∥ 不对称的贡献 |
|:---|:---|:---|:---|:---|:---|
| 超交换 SE | AFM（反铁磁）| 层间 ≫ 层内 | d_z² ≫ d_x²-y² | J⊥ ~60–100 meV<br> J∥ ~10–30 meV | **主要原因** |
| 双交换 DE | FM（铁磁）| 层内 ≫ 层间 | d_x²-y² ≫ d_z² | ~t (hopping) | 削弱 J∥ |
| Hund 耦合 J_H | FM（铁磁）| 同一位点 | d_z² ↔ d_x²-y² | ~0.7–0.9 eV | 连接层间与面内磁序 |

## 四、关联效应维度：轨道选择的 Mott 物理

### 4.1 什么是轨道选择的 Mott 相（OSMP）？

在同一材料中，不同轨道呈现**不同的关联强度**：

```
         d_xy, d_xz, d_yz → 满占据 → 绝缘（无低能自由度）
         
         d_z² → 极强关联（重整化 5–8）→ 接近 Mott 转变
                 → 电子高度局域 → 好的局域磁矩
                 → 类似铜氧化物中 Cu-d_x²-y² 的角色
         
         d_x²-y² → 中等关联（重整化 2–3）→ 金属态
                   → 电子相对巡游 → 磁矩被屏蔽
                   → 类似 Hund 金属中的巡游带
```

### 4.2 关联强度差异的后果

| 后果 | d_z²（局域） | d_x²-y²（巡游） |
|:---|:---|:---|
| 准粒子残权重 Z | 极小 (~0.1–0.2) | 中等 (~0.3–0.5) |
| 有效质量 m*/m | 5–8 | 2–3 |
| 自旋涨落 | 明确、低频 | 被屏蔽、宽频 |
| 磁序稳定性 | 高 | 低 |
| 对超导的贡献 | 提供配对胶水（磁涨落） | 提供配对电子 |

## 五、晶体场与键角维度

### 5.1 压力效应：结构→电子→磁性

```
加压 ~14 GPa
   │
   ▼
八面体倾转被压制
   │
   ▼
Ni–O(apical)–Ni 键角 → 180°（层间）
Ni–O(planar)–Ni 键角 → 180°（面内）
   │
   ▼
层间 σ 重叠 ↑↑↑（对 J⊥ 增益大）
面内 σ 重叠 ↑  （对 J∥ 增益小，因本身关联弱）
   │
   ▼
J⊥/J∥ 比例进一步增大
```

### 5.2 层分辨的八面体环境

双层 La₃Ni₂O₇ 中两层 Ni 是**对称等价的**（都有一侧是 LaO 岩盐层，一侧是共用的 apical 氧），因此没有 4310 中的内层/外层分化问题。但局域八面体畸变仍然影响晶体场能级顺序。

## 六、综合对照总表

| 维度 | 层间（Interlayer） | 层内（Intralayer） |
|:---|:---|:---|
| **主导轨道** | d_z² | d_x²-y² |
| **轨道空间指向** | 沿 c 轴，指向相邻层 | 面内 x-y 平面 |
| **与 O 的重叠类型** | σ 型（d_z²–p_z） | σ 型（d_x²-y²–p_x/p_y） |
| **电子占据** | ~1 电子/Ni（半满） | ~0.5 电子/Ni（近空） |
| **关联强度** | 极强（m*/m = 5–8） | 中等（m*/m = 2–3） |
| **电子特性** | 局域（近 Mott） | 相对巡游（金属性） |
| **磁矩** | 明确局域 S=1/2 | 磁矩被巡游屏蔽 |
| **主导交换机制** | 超交换（AFM） | 超交换（AFM）+ 双交换竞争（FM） |
| **净耦合强度** | J⊥ 大（~60–100 meV） | J∥ 小（~10–30 meV） |
| **配对中的角色** | 提供配对胶水（磁涨落媒介） | 提供配对载流子 |
| **对超导的贡献** | 层间 s± 配对通道 | 面内 d 波配对通道（可能共存） |
| **压力响应** | 极大（键角→180°，J⊥ ↑↑） | 中等（键角改善，但受限于弱关联） |
| **CDW 中的角色** | 密度波序参量的可能来源 | 费米面嵌套驱动 |

---

## 七、一句话总结

> **d_z² 沿 c 轴的 σ 型超交换通路**（强重叠 + 局域磁矩 + 近 180° 键角）赋予层间反铁磁耦合压倒性优势；**d_x²-y² 的面内 σ 通路**虽然同样存在，但因其**较弱的关联性（巡游特征）+ 双交换 FM 竞争**，面内净反铁磁耦合被大幅削弱。两者差异的根源在于**轨道选择的 Mott 物理**——同一材料中两个轨道走向了截然不同的电子命运。
