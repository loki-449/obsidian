## 放置规则

- 知识笔记（理论、公式、方法、文献卡片、主题学习笔记）只进 `知识库/`。
- 用户记录（每日研究日志、周/月计划、当前任务状态、Agent 学习日志）只进 `记录/`。
- 网页剪辑等未整理材料先放 `收件箱/Clippings/`，整理后移到对应知识目录。
- 一次性文件或废弃草稿放 `_待删除/`，确认后删除。
- `Templates/`、`_litpipe/`、`_系统/`、`.obsidian/` 是系统资产，不混入知识库。
- 工作台推送文档（每日日志、当前任务状态、学习笔记、周/月/年计划）统一契约见 `_系统/工作台推送约定.md`。
- science_chat 工作日志目录：`E:\claude_work\science_chat\07_每日工作\`，日志链接约定见 `_系统/工作台推送约定.md`。
