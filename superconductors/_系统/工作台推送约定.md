# 工作台推送约定

> 本文档是 Obsidian 与工作台之间四类推送文档的唯一契约。模板结构或必填字段变化时，按“版本递增规则”人工递增 `template_version`。

## 1. 文档类型与路径映射

| doc_type | 路径 | 模板 |
| --- | --- | --- |
| `daily_log` | `记录/每日研究日志/YYYY/YYYY-MM-DD.md` | `Templates/daily-note-template.md` |
| `current_task` | `记录/我的研究/未来课题规划/当前任务状态.md` | `Templates/current-task-template.md` |
| `learning_note` | `知识库/04_学习笔记/*.md` | `Templates/learning-note-template.md` |
| `plan_tree` | `记录/科研计划/{周计划\|月计划\|年计划}/{period}.md` | `Templates/plan-tree-template.md` |

## 2. 公共 frontmatter 字段

| 字段 | 必填 | 取值域 |
| --- | --- | --- |
| `doc_type` | 是 | `daily_log` / `current_task` / `learning_note` / `plan_tree` |
| `template_version` | 是 | 正整数；当前统一为 `1` |
| `source` | 是 | 工作台新写入文档使用 `workbench`；存量文档保留原值 |
| `updated_at` | 是 | `YYYY-MM-DD` |
| `tags` | 是 | YAML 数组或内联列表 |

## 3. 类型专属字段

- `daily_log` 追加 `date`（`YYYY-MM-DD`）、`week`（ISO 周数，如 `33`）。
- `learning_note` 追加 `read`（`true` / `false`）、`read_date`（`YYYY-MM-DD`，未读时为空）。
- `plan_tree` 追加 `scope`（`week` / `month` / `year`）、`period`（如 `2026-W33` / `2026-08` / `2026`）。
- `current_task` 无额外必填字段。

## 4. 关键标题兼容点

- `daily_log`：`## 🎯 今日目标`、`## 🔧 计算/实验进展` 是工作台任务同步与进展写入锚点。
- `current_task`：`## 当前进行中` 必须原样保留，工作台只替换该节下第一条列表项。
- `plan_tree`：`## 母计划` 必须原样保留，工作台只重写该节下的计划树。
- `learning_note`：新建文档固定使用 `## 核心知识点`、`## 关键问题`、`## 与我研究的关联`、`## 参考资料`；存量文档以 `## 模板章节映射` 声明现有章节归位，正文不切碎。

## 5. 版本递增规则

- 模板结构或必填字段变化时，人工递增 `template_version`。
- 旧文档不自动升级；由 `_系统/脚本/check_workbench_docs.py` 输出缺失清单，按新版本补齐。
- `pushed_at` 等推送时间字段暂不作为必填项，待工作台代码支持后启用。

## 6. 校验

运行只读校验脚本：

```powershell
python _系统/脚本/check_workbench_docs.py
```

脚本检查四类文档的路径、必填 frontmatter 与关键标题，缺失项会列出清单，全部通过时退出码为 0。

## 7. science_chat 工作日志链接约定

- science_chat 不是 Obsidian vault，`[[science_chat 今日工作]]` 这类 wikilink 无法解析，禁止写入模板与日志。
- science_chat 每日工作文件位于 `E:\claude_work\science_chat\07_每日工作\`，命名为 `YYYY-MM-DD_周X.md`（如 `2026-08-14_周五.md`）。
- 每日日志模板的 `## 🔗 关联` 按以下格式写预期路径与目录链接；`<% tp.date.now("YYYY-MM-DD") %>` 由工作台适配器替换为日期，`周X` 由人工按当天星期补全：
  - `今日 science_chat 工作日志：E:\claude_work\science_chat\07_每日工作\<% tp.date.now("YYYY-MM-DD") %>_周X.md`
  - `打开目录：[science_chat 每日工作](E:/claude_work/science_chat/07_每日工作/)`
- 已生成的日志按同格式维护：文件存在时使用 `[当日工作日志](E:/claude_work/science_chat/07_每日工作/YYYY-MM-DD_周X.md)`，文件未生成时只保留路径说明。
