# 费米液体 + 近藤 + RKKY 体系中输运、热学、磁学的完整行为总结

## 一、标准费米液体行为

| 物理量 | 温度依赖 | 关系式 |
|--------|---------|--------|
| 电阻率 | $\rho(T) = \rho_0 + A T^2$ | 准粒子间散射（Umklapp），$A \propto (m^*)^2$ 越大电子越"重" |
| 电子比热 | $C / T = \gamma = \text{const}$ | $\gamma \propto m^*$，重费米子 $\gamma$ 可达 $10^3$ mJ/mol·K² 量级 |
| 磁化率 | $\chi = \text{const}$（泡利顺磁） | 与温度无关，$\chi \propto m^*$ |
| 热导率 | $\kappa / T = \text{const}$ | Wiedemann-Franz 定律成立，$\kappa/(\sigma T) = L_0 = 2.44\times10^{-8}$ W·Ω/K² |
| 准粒子寿命 | $\tau^{-1} \propto T^2$ | 相空间约束：只有 $k_B T$ 范围内的电子参与散射 |
| 谱权重 | 费米面处准粒子峰尖锐，$Z > 0$ | ARPES 看到明确的能带色散 |

**标度关系**：$A / \gamma^2 \approx \text{const}$（Kadowaki-Woods 比）——强关联体系中电阻系数和比热系数的比值是普适的，证明两个量都源于同一个 $m^*$ 的重整化。

## 二、近藤效应的不同阶段

### 阶段 1：高温（$T \gg T_K$）—— 自由局域磁矩

| 物理量 | 行为 |
|--------|------|
| 磁化率 | $\chi \propto 1/T$（居里定律），每个 f 磁矩自由翻转 |
| 电阻率 | 随降温**减小**（声子被冻住），正常金属行为 |
| 比热 | 声子贡献为主，$C \propto T^3$ |
| 磁性杂质熵 | $R \ln(2J+1)$ 未被释放 |

### 阶段 2：$T_K < T < T^*$ —— 非相干近藤散射

| 物理量 | 行为 |
|--------|------|
| 电阻率 | **随降温上升** $\rho \propto -\ln T$，自旋翻转散射截面增大 |
| 磁化率 | 偏离居里定律，开始有近藤屏蔽迹象 |
| 比热 | 杂质贡献开始出现，$C/T$ 逐渐增大 |
| 磁性杂质熵 | 开始释放，但远未完成 |

### 阶段 3：$T < T_K$（单杂质极限）—— 近藤单重态

| 物理量 | 行为 |
|--------|------|
| 电阻率 | 达到饱和（幺正极限 $\sigma_{\text{max}} = 4\pi/k_F^2$），然后趋于常数 |
| 磁化率 | $\chi(T \rightarrow 0) \propto 1/T_K$（有限常数），有效磁矩消失 |
| 比热 | $C/T \propto 1/T_K$，杂质熵 $R\ln 2$ 在 $T_K$ 附近全部释放 |
| 基态 | 总自旋 S=0 的非磁性单重态，传导电子云包裹杂质磁矩 |

### 阶段 4：$T < T^*$（晶格极限）—— 近藤晶格相干态 = 重费米液体

| 物理量 | 行为 |
|--------|------|
| 电阻率 | 急剧下降 $\rho \propto T^2$，与费米液体一致但 $A$ 巨大 |
| 比热 | $C/T = \gamma$ 巨大（$10^2$–$10^3$ mJ/mol·K²），$\gamma \propto 1/T_K \propto m^*$ |
| 磁化率 | 增强的泡利顺磁常数 $\chi \propto m^*$ |
| 能带 | 杂化能隙打开，近藤共振峰在 $E_F$ 处出现，f 电子进入费米面（大费米面） |
| Hall 系数 | 在 $T^*$ 附近变号或出现峰——费米面重构的标志 |

## 三、RKKY 主导体系（磁有序侧）

| 物理量 | 行为 |
|--------|------|
| 电阻率 | 在磁有序温度 $T_N$ 处出现**拐点或峰**——磁超晶格导致能隙打开部分费米面 |
| 比热 | $T_N$ 处出现 λ 形尖峰（二级相变特征），有序相内 $C \propto T^3$（磁振子贡献） |
| 磁化率 | 高温 $\chi \propto 1/(T - \theta_{CW})$（居里-外斯），$T_N$ 处出现拐点，有序相内磁化率各向异性 |
| 磁结构 | 反铁磁 Bragg 峰出现于中子散射——磁矩排列长程有序 |
| 熵释放 | 主要在 $T_N$ 处释放（磁有序化熵），远高于单杂质 $T_K$ 尺度 |
| 费米面 | **小费米面**——f 电子被锁定在磁有序中，不参与费米面；Hall 系数与近藤侧不同 |
| 热导 | 磁有序态中磁振子导热通道存在，$\kappa_{\text{mag}} \propto T^3$ |

## 四、RKKY 与近藤竞争区域（QCP 附近）

| 物理量 | 行为 |
|--------|------|
| 电阻率 | $\rho \propto T^n$，$n$ 偏离 2（非费米液体），常见 $n \approx 1.5$–$1.8$ |
| 比热 | $C/T \propto -\ln T$ 或 $C/T \propto T^{-p}$（幂律发散），$\gamma$ 不是常数 |
| 磁化率 | $\chi \propto T^{-\alpha}$ 发散，有效磁矩在 QCP 处不趋于零 |
| 热导 | Wiedemann-Franz 定律**失效**——$\kappa/T$ 的行为与 $\sigma/T$ 不一致，说明电荷和热由不同元激发携带 |
| 有效质量 | $m^*$ 在 QCP 处发散，准粒子权重 $Z \rightarrow 0$ |
| 费米面 | 在 QCP 处体积**突变**——小费米面（局域）↔ 大费米面（巡游）的 Lifshitz 转变 |
| 超导 | SC 穹顶出现在 $T=0$ 附近的 QCP 上方，配对胶水来自 QCP 的量子临界涨落 |

## 五、对比总表

| 体系类型 | $\rho(T)$ 低温 | $C/T$ | $\chi$ | 费米面 | 基态 |
|---------|---------------|-------|--------|--------|------|
| 标准费米液体 | $\rho_0 + AT^2$ | const | const (Pauli) | 正常 | 准粒子 |
| 单杂质近藤 ($T < T_K$) | 常数（幺正极限） | $C/T$ ∝ $1/T_K$ | const (Pauli) | — | S=0 单重态 |
| 近藤晶格 ($T < T^*$) | $\rho_0 + AT^2$（$A$ 巨大） | $\gamma$ 巨大 | 增强 Pauli | 大费米面 | 重费米液体 |
| RKKY 磁有序 | $T_N$ 处拐点/峰 | $T_N$ 处 λ 尖峰 | Curie-Weiss | 小费米面 | 反铁磁 |
| QCP 附近 | $\rho$ ∝ $T^n$ ($n \neq 2$) | 发散 (log 或幂律) | 发散 | 突变 | 非费米液体 |
