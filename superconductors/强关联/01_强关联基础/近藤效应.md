# 近藤效应（Kondo Effect）

近藤效应描述的是：当一个具有**局域磁矩的磁性杂质**掺杂到非磁性金属中时，在极低温度下发生的物理现象。

## 物理图像

**高温阶段**：杂质磁矩和传导电子散射，电阻随温度降低而减小（常规金属行为）。

**近藤温度 $T_K$**：当温度降至 $T_K$ 以下时，杂质磁矩被传导电子的自旋云"屏蔽"。

**低温阶段**：传导电子与杂质磁矩形成非磁性的**单重态（Singlet）**。此时散射反而增强，电阻出现**极小值**并随温度降低而上升。

## 物理意义

这是典型的"强关联"现象，展示了局域磁矩如何从"个体"转变为与传导电子纠缠在一起的"集体态"。

## 晶格近藤效应 → 重费米子

如果每个晶格点上都有一个磁性离子（如 Ce 或 U），每个离子都会发生近藤效应。在极低温度下，这些"杂质"不再是散射中心，而是参与构成费米面。准粒子的有效质量变得极大（可达自由电子质量的千倍），称为"重费米子"。

此时整个固体变成"近藤费米液体"——尽管质量极大，仍满足费米液体特征，只是参数（$m^*$、$\gamma$）被近藤效应重整化到了巨大数值。

## 对比总结

| 概念 | 核心载体 | 低温行为 | 物理本质 |
|------|---------|---------|---------|
| 费米液体 | 准粒子（集体化电子） | $\rho \propto T^2$, $C \propto T$ | 相互作用电子的绝热演化 |
| 近藤效应 | 局域磁矩 + 传导电子 | 电阻率上升（极小值） | 局域矩被传导电子自旋屏蔽 |
| 重费米子 | 晶格化近藤态 | 巨大的线性比热系数 $\gamma$ | 近藤效应参与形成费米面 |

## 自旋翻转散射的微观机制

### s-d 交换哈密顿量（Kondo Hamiltonian）

$$H = \sum_{k\sigma} \varepsilon_k c^{\dagger}_{k\sigma} c_{k\sigma} + J\,\mathbf{S}_{\text{杂质}} \cdot \mathbf{s}_{\text{传导电子}}(0)$$

第一项是传导电子动能。第二项是局域磁矩 $\mathbf{S}$ 与传导电子自旋密度 $\mathbf{s}(0) = \sum_{kk'} c^{\dagger}_{k\alpha} \boldsymbol{\sigma}_{\alpha\beta} c_{k'\beta}$ 的交换耦合。$J > 0$ 代表反铁磁耦合。

展开 $\mathbf{S} \cdot \mathbf{s} = S_z s_z + \frac{1}{2}(S_+ s_- + S_- s_+)$：
- $S_z s_z$：自旋不翻转——电子感受到磁矩方向势场
- $S_+ s_-$ 和 $S_- s_+$：**自旋翻转散射**——升降算符使杂质和电子自旋同时翻转

### 二阶微扰 → 对数发散

散射矩阵元 $T_{kk'}$ 来自 $J\mathbf{S}\cdot\mathbf{s}$ 的二阶 Born 近似：

$$T_{kk'} = J + 2J^2\rho \ln\frac{D}{T} + \cdots$$

其中 $\rho = N(E_F)$ 是态密度，$D$ 是带宽。电阻 $\rho_R \propto |T_{kk'}|^2$：

$$\rho_R(T) \propto J^2\left[1 + 4J\rho \ln\frac{D}{T} + \cdots\right]$$

$T \downarrow$ → $\ln(D/T) \uparrow$ → 电阻上升。**这就是 $-\ln T$ 行为。**

### 微扰论失效 → 近藤温度

第 $n$ 阶贡献 $\propto J^{n+1}[\rho\ln(D/T)]^n$。当 $J\rho\ln(D/T) \sim 1$ 时所有阶同等重要→发散级数。

对最发散项求和（leading-log / Abrikosov-Suhl 重求和）：

$$J_{\text{eff}}(T) = \frac{J}{1 - 2J\rho\ln(D/T)}$$

分母在某个温度趋近于零→定义近藤温度：

$$T_K = D\,e^{-1/(2J\rho)}$$

**$T_K$ 是 $J\rho$ 的指数函数**——Doniach 相图中 $T_K$ 对 J 的指数依赖的核心公式。

### $T < T_K$ → 单重态基态

Wilson NRG 证明基态是总自旋 S=0 的单重态：

$$|\Psi_{\text{基态}}\rangle = \frac{1}{\sqrt{2}}\left(|\uparrow_{\text{杂质}}\rangle|\downarrow_{\text{屏蔽云}}\rangle - |\downarrow_{\text{杂质}}\rangle|\uparrow_{\text{屏蔽云}}\rangle\right)$$

实验证据：
- 磁化率：$\chi(T \rightarrow 0) \propto 1/T_K$（有限常数←有效磁矩消失）
- 比热：$C/T \propto 1/T_K$（杂质熵 $k_B \ln 2$ 在温度穿过 $T_K$ 时释放，$T \rightarrow 0$ 趋于零）

## 实验验证：CeₓLa₁₋ₓCu₆ 系列

这个体系在重费米子物理中具有极重要的地位——通过用非磁性的 La 替换磁性的 Ce，可以连续调控磁性离子的浓度 x，观测从"孤立近藤杂质"到"近藤晶格相干"的完整演化。

### 各浓度的电阻行为

**x ≈ 0.094（稀磁极限）**：曲线随温度降低单调上升并在低温饱和。这是最接近理想"单近藤杂质"的极限：每个 Ce 离子作为孤立散射中心，$\rho \propto -\ln T$ 直到 $T_K$ 以下屏蔽完成，散射进入幺正极限而饱和。没有 RKKY 排队，没有集体相干效应。

**x ≈ 0.5（中间浓度）**：电阻极大值还在但变宽变弱。磁矩之间开始有 RKKY 间接耦合，部分格点可能形成局部的磁有序团簇，但整体上还未建立完全的相干能带结构。

**x = 1.0（纯 CeCu₆，近藤晶格极限）**：这是重费米子物理最经典的电阻曲线之一。中间温度区出现一个宽的极大值，低温下电阻反而急剧下降。这不是单杂质行为——这是**近藤晶格相干效应**：磁性 Ce 离子周期性排列后，各个格点上形成的近藤屏蔽云彼此"对齐"，产生相干散射（类比 Bloch 定理让周期性势场里的电子获得良好定义的动量），导致低温下电子在这个周期性重费米子能带里几乎无耗散地运动，电阻大幅下降。

### 物理意义

从 x=0.094 → x=1.0 的演化展示了：
- 近藤效应本身是**单杂质现象**——只要有一个磁矩 + 传导电子海就会发生
- 近藤晶格相干需要**周期性**——高浓度下 Ce 在晶格上规则排列，散射波才能相干叠加
- 电阻极大值的位置就是相干温度 T* 的对应标志

这与 Doniach 相图（图 b）的关系：Doniach 相图给出的是"同一个材料（固定浓度）在不同 J（不同压力）下基态是磁有序还是重费米液体"的理论框架，而 CeₓLa₁₋ₓCu₆ 系列展示的是"固定 J、变化浓度"时体系从单杂质到集体相干的演化——两个视角互补，都源于近藤效应和 RKKY 相互作用的同一套物理。
