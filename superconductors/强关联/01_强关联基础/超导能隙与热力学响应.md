# 超导能隙与热力学响应

## 能隙为什么存在

超导态中电子配成库珀对形成玻色凝聚体。拆散一个库珀对需要至少 $2\Delta$ 的能量——$\Delta$ 是每个电子的结合能。$E_F$ 附近没有可用的单电子态——态密度在 $E_F \pm \Delta$ 内为零。所以需要 $2\Delta$ 才能激发一个准粒子。

## 从 BCS 理论到指数衰减

超导态准粒子能量色散：

$$E_k = \sqrt{\xi_k^2 + \Delta^2},\quad \xi_k = \varepsilon_k - E_F$$

态密度变换（$N_n(\xi) \approx N(0)$ 常数近似）：

$$N_s(E) = N(0)\frac{E}{\sqrt{E^2 - \Delta^2}}\quad(E > \Delta),\qquad N_s(E) = 0\quad(E < \Delta)$$

热激发准粒子数密度（低温 $k_B T \ll \Delta$，费米-狄拉克→玻尔兹曼 $f(E) \approx e^{-E/k_B T}$）：

$$n_{\text{qp}} \propto \int_{\Delta}^{\infty} \frac{E}{\sqrt{E^2 - \Delta^2}} e^{-E/k_B T} dE \propto \sqrt{T}\,e^{-\Delta/k_B T}$$

比热 $C = dU/dT$ 同样带 $e^{-\Delta/k_B T}$ 因子。

**核心结论**：所有依赖准粒子激发数的热力学量在低温下都以指数形式衰减——因为态密度在 $E < \Delta$ 处为零，玻尔兹曼因子只在 $E \gtrsim \Delta$ 处有可观权重。

## 幂律行为 vs 指数行为

| 体系 | 热力学量温度依赖 | 物理原因 |
|------|----------------|---------|
| 正常金属 | $C \propto T$（幂律 n=1） | 无能隙，费米面附近态密度连续 |
| 费米液体 | $\rho \propto T^2$（幂律 n=2） | 准粒子散射 |
| s 波超导 | $C \propto e^{-\Delta/T}$（指数） | 全能隙，无能隙激发需跨 $\Delta$ |
| d 波超导 | $C \propto T^2$（幂律） | 线节点处能隙为零，低能准粒子激发存在 |

幂律 vs 指数是区分超导能隙是否有节点的核心实验手段：全能隙 → 指数衰减；有节点 → 幂律行为。画在双对数坐标上，幂律是直线，指数是指数弯曲。

## 单重态、三重态与多重态

两个自旋-1/2 的体系总自旋：$\frac{1}{2} \otimes \frac{1}{2} = 0 \oplus 1$

- **S = 0（单重态）**：$\frac{1}{\sqrt{2}}(|\uparrow\downarrow\rangle - |\downarrow\uparrow\rangle)$，无净磁矩。常规库珀对、近藤屏蔽后的基态都是单重态。
- **S = 1（三重态）**：$|\uparrow\uparrow\rangle$、$|\downarrow\downarrow\rangle$、$\frac{1}{\sqrt{2}}(|\uparrow\downarrow\rangle + |\downarrow\uparrow\rangle)$，有净磁矩。p 波奇宇称配对（如 Sr₂RuO₄ 候选），Hund 规则下的自旋平行排列。
- **更大的 S（高自旋态）**：Hund 规则使多个 d/f 电子自旋平行→ $S = 5/2$（如 Fe³⁺ d⁵）。

| 总自旋 S | 物理表现 |
|----------|---------|
| 0 | 非磁性，磁化率常数（范弗莱克/抗磁），重费米子基态、库珀对 |
| 1/2 | 局域磁矩，$\chi \propto 1/T$，$T > T_K$ 的杂质磁矩 |
| 1 | 更大磁矩，三重态配对、磁有序、激发态 |
