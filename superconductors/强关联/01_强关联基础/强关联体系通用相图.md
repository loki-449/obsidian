# 强关联体系的通用相图

## 一句话定义

铜氧化物、重费米子、铁基超导体、有机超导体的相图共享同一个结构——从反铁磁序出发，经掺杂/压力调控后 $T_N \to 0$，在量子临界点附近出现**超导穹顶**，穹顶上方是**奇异金属**，远 QCP 处恢复**费米液体**。这不是巧合，是反铁磁量子临界涨落驱动配对机制的共同结果。

---

## 四段式结构

```
 T ↑
   │
   │  奇异金属 (ρ ∝ T)
   │  ┌─────────────┐
   │  │  超导穹顶    │
   │  │  (最高Tc在   │     费米液体
 AF│  │   QCP附近)   │    (ρ ∝ T²)
   │  └─────┬───────┘
   │        │
   │   反铁磁序      │
   │   (T_N)         │
   └────────┼────────┴────────→ 掺杂/压力/J
         QCP (T_N → 0)
```

---

## 逐段解析

### 反铁磁序（左侧母体）

母体化合物都带有反铁磁长程序。形成机制因体系而异但同归于局域电子物理：

- **铜氧化物**：半满 Hubbard 模型 → $U/t \gg 1$ → Mott 绝缘体 → 超交换 $J = 4t^2/U$ → Néel 反铁磁序
- **重费米子**：局域 $f$ 电子 → RKKY 相互作用 $T_{\text{RKKY}} \sim J^2\rho$ → 磁有序
- **铁基超导体**：母体反铁磁序是自旋密度波（SDW），条状反铁磁 + 向列相
- **有机超导体**：二聚化形成的半满能带 → Mott 绝缘体 → AFM

共同点：**电荷自由度被冻结（绝缘或很差的金属），自旋自由度有序。**

### 掺杂/压力调控 → 磁有序被压制

引入载流子（掺杂）或改变交换耦合（压力/化学替代）：

- 铜氧化物：空穴掺杂打破超交换路径
- 重费米子：压力增强 $J$ → 近藤屏蔽增强 → 局域磁矩被"吃掉"
- $T_N$ 单调下降 → 在某个临界参数 $x_c$ 或 $J_c$ 处归零

### 量子临界点（QCP）

$T_N \to 0$ 的临界参数处存在**连续量子相变**。这一点的物理极其丰富：

- 没有任何温度驱动的热涨落（$T=0$），相变由量子涨落驱动
- 反铁磁序参量涨落发散 → **临界自旋涨落**
- 这些自旋涨落就是超导配对的"胶水"——替代 BCS 理论里声子的角色
- 铜氧化物的 $d_{x^2-y^2}$、重费米子的磁中介配对、铁基的 $s^\pm$ 全都和这个 QCP 附近的临界涨落有关

### 超导穹顶

超导出现在磁有序被压制之后。$T_c$ 曲线呈穹顶状（dome），在 QCP 附近达到最大值。对称性：

- **铜氧化物**：$d_{x^2-y^2}$，穹顶位于空穴掺杂 ~0.15
- **重费米子**：$d$ 波或 $s^\pm$，峰值 $T_c$ 在 QCP 附近
- **铁基**：$s^\pm$，穹顶覆盖较大的掺杂范围
- **有机超导体**：$d$ 波，与反铁磁序竞争的窄 QCP 区域

核心结论：**超导不是磁有序消失后的"附带现象"——临界自旋涨落本身就是配对机制。** QCP 太左涨落不够（磁有序主导），QCP 太右涨落太弱（费米液体主导），中间刚好——这就是穹顶。

### 奇异金属（Strange Metal）

超导穹顶上方的正常态。电阻率 $\rho \propto T$（线性），违反费米液体的 $\rho \propto T^2$ 预言。

- 准粒子图像彻底失效——没有良好定义的准粒子激发
- 在铜氧化物中表现为 $T$-线性电阻延伸到远高于 $T_c$
- 奇异金属的温度-掺杂范围和超导穹顶高度重合 → 超导态就是从奇异金属态（而非费米液体）里"凝结"出来的
- 这对 BCS 理论是根本挑战：BCS 假设正常态是费米液体，但强关联体系的正常态本身已经不是了

### 费米液体（右侧远 QCP 区）

掺杂/压力足够大后，远离 QCP，临界涨落衰减。体系恢复朗道准粒子描述：

- $\rho \propto T^2$（准粒子间散射）
- $C/T \sim const$（线性比热）
- 准粒子有效质量增强（"重"费米子），但概念结构回归费米液体

## Doniach 相图——重费米子的统一框架

在重费米子体系中，横轴不是掺杂而是 $J\rho$（$J$ 是近藤交换耦合、$\rho$ 是传导电子态密度）。

两条特征能量尺度：

$$T_K \sim D e^{-1/(2J\rho)} \quad \text{（近藤温度）}$$

$$T_{\text{RKKY}} \sim J^2\rho \quad \text{（RKKY 温度）}$$

- $J\rho$ 小：$T_{\text{RKKY}} > T_K$ → RKKY 胜出 → 基态磁有序
- $J\rho$ 大：$T_K > T_{\text{RKKY}}$ → 近藤屏蔽胜出 → 基态顺磁（重费米液体）
- 中间量子临界点：$T_{\text{RKKY}} \approx T_K$ → 超导穹顶

Doniach 相图把"掺杂/压力 → 磁有序抑制 → QCP → 超导"的整个逻辑统一在 $J$ 这一个参数下，是理解强关联超导体"为什么都长这样"的最基本框架。

## 跨体系对比

| 体系 | 母体 | 配对对称性 | 调控参数 | $T_c^{\max}$ |
|------|:----:|:----------:|:--------:|:------------:|
| 铜氧化物 | Mott-AFM | $d_{x^2-y^2}$ | 掺杂 x | ~135 K (Hg系) |
| 重费米子 | 反铁磁 | $d$ / $s^\pm$ | 压力/J | ~2 K (Ce系) |
| 铁基 | SDW-AFM | $s^\pm$ | 掺杂/压力 | ~56 K |
| 有机 | Mott-AFM | $d$ | 压力 | ~12 K |

母体不同、配对对称性不完全相同、$T_c$ 跨越三个量级——但**相图的拓扑结构完全一致**。
