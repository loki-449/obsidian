# 重整化群（Renormalization Group, RG）概念讲解

> RG 不是一个具体的计算技巧——它是一种**思维方式**。理解 RG 相当于理解"为什么物理世界有层次结构"、"为什么微观细节在某些尺度上消失、又在另一些尺度上变得致命"。这份文档从物理直觉出发，逐步建立数学结构，最后落回你在强关联电子体系中会反复遇到的量子临界现象。

## 1. RG 要解决什么问题

### 1.1 一个直观的悖论

考虑一杯水在气-液临界点（T = 374°C, P = 218 atm）附近。实验发现：
- 密度涨落的关联长度 ξ 发散（ξ → ∞）
- 比热、压缩率、密度差等物理量都表现出普适的幂律行为
- 而且——不同流体（水、CO₂、Xe、甚至铁磁体在居里点附近）的临界指数**完全相同**

这个普适性非常反直觉：水分子有偶极矩和氢键，CO₂ 没有，Xe 是单原子分子——微观哈密顿量完全不同，为什么临界行为一模一样？

**答案**：在临界点，关联长度 ξ 趋向无穷大。当 ξ 远大于微观尺度（分子间距 ~Å），所有微观细节都被"洗掉了"——系统只记得少数几个宏观特征（空间维数 d、序参量分量数 n、相互作用是短程还是长程）。RG 提供了严格的数学语言来描述这种"洗掉微观细节"的过程。

### 1.2 为什么微扰论不够

在量子场论或多体理论中，当你计算 Feynman 图的高阶修正时会遇到发散。传统重整化（比如 QED 中处理电子自能）通过重定义裸参数（电荷 e₀、质量 m₀）来吸收发散。

但这个做法的物理图像很模糊——为什么一个依赖于截断 Λ 的裸参数，经过"人為"的重定义后就能给出有限的结果？

RG 回答了这个"为什么"：当你改变观察尺度，物理系统的有效描述会发生**连续演化**。裸参数在 UV（高能/小尺度）有一组值，在 IR（低能/大尺度）有效参数变成另一组值，这个演化由 RG 方程描述。吸掉发散的过程，本质上是追踪这个演化的逆过程。

### 1.3 "群"在哪里

RG 是一个**半群**（没有逆元）。操作是：
```
R_b : 哈密顿量（或作用量）在尺度 a 上的描述
      →
      哈密顿量在尺度 b×a 上的等效描述（b > 1）
```

- 封闭性：两次粗粒化等价于一次更大的粗粒化，R_{b1} ∘ R_{b2} = R_{b1·b2}
- 结合律：显然成立
- 恒等元：b = 1
- 没有逆元：粗粒化丢失了短距离信息，你无法从大尺度描述唯一恢复小尺度细节

## 2. 核心操作：粗粒化和重标度

以实空间中的 Ising 模型为例来理解 RG 的两个基本步骤。

### 2.1 原始模型

在 d 维超立方晶格上，Ising 模型的哈密顿量（作用量）：

```
H = -J  Σ    s_i s_j  -  h  Σ  s_i
       ⟨ij⟩               i
     （近邻耦合）        （外场）
```

其中 s_i = ±1。配分函数：

```
Z =  Σ    exp( -βH )
    {s_i}
```

我们定义约化哈密顿量 K = -βH，K = Σ_i K_i(s)，使 Z = Σ exp(K)。

### 2.2 步骤一：粗粒化（Decimation / Block spin）

将晶格分成大小为 b^d 的块（block）。每个块定义一个"块自旋" S_I，它是块内原自选的某种平均或多数表决。

最关键的操作：**积掉（trace out）短波长的自由度**。

```
exp(K_eff[S_I]) =  Σ     exp(K[s, S_I])
                  {s_i}
                  (保持 S_I 固定的约束下对所有内部 s_i 求和)
```

这给出了块自旋 S_I 之间的有效相互作用 K_eff。此时有效哈密顿量描述了同样的物理，但**最小空间尺度从 a 变成了 ba**。

### 2.3 步骤二：重标度（Rescaling）

把晶格常数重新缩回 a：

```
x' = x / b
```

同时重标度自旋变量（以及温度、外场等参数）：

```
s'(x') = b^{-Δ_s} · S_I(x)
```

其中 Δ_s 是自旋场的标度维数（scaling dimension），需要通过物理要求来确定（例如要求两点关联函数的渐近形式在重标度下自洽）。

### 2.4 参数空间的流

一次 RG 变换可以用参数空间中一个映射来表示：

```
K_{n+1} = R_b(K_n)
```

这里 K = (K₁, K₂, K₃, ...) 是耦合常数空间中的一个矢量——不仅包含原始哈密顿量里的 J 和 h，还包含粗粒化过程中**生成的所有新的耦合项**（次近邻耦合、四自旋相互作用等）。

即使原始哈密顿量只有近邻耦合，一次 RG 变换后，K_eff 中会出现一切被对称性允许的项。耦合常数空间是**无穷维**的。

这就引出了 RG 最核心的概念：不动点和算符分类。

## 3. 不动点、相关方向、无关方向

### 3.1 不动点（Fixed Point）

不动点 K* 定义为：

```
K* = R_b(K*)
```

即 RG 变换下不变的耦合常数集合。在不动点附近，系统是**标度不变的**（scale invariant）——这是临界点的标志。

两种最重要的不动点：

| 不动点 | 物理含义 | 关联长度 ξ |
|-------|---------|-----------|
| 高斯不动点 | 自由理论（无相互作用） | ξ = 0（平庸） |
| Wilson-Fisher 不动点 | 相互作用的临界理论 | ξ = ∞ |

### 3.2 线性化 RG：算符分类

在不动点 K* 附近做线性展开：

```
δK_{n+1} =  M · δK_n
```

其中 δK = K - K* 是偏离不动点的矢量，M 是 RG 变换的线性化矩阵：

```
M_{αβ} = ∂R_α / ∂K_β  （在 K=K* 处取值）
```

把 M 对角化：

```
M · v_i = λ_i · v_i    其中 λ_i = b^{y_i}
```

这里的 y_i 叫做**RG 本征值指数**，v_i 是对应的**标度算符**（scaling operator）。

按照 y_i 的符号分类：

**y_i > 0 → λ_i > 1 → 相关算符（relevant）**
在 RG 流下被放大。对应参数必须精细调节到零才能到达临界点。例子：约化温度 t = (T-Tc)/Tc。

**y_i < 0 → λ_i < 1 → 无关算符（irrelevant）**
在 RG 流下被衰减到零。它们不影响临界行为。例子：次次近邻耦合、高阶多自旋项。**绝大多数微观细节都是无关的** → 普适性！

**y_i = 0 → 边缘算符（marginal）**
需要看高阶（二次）修正才能决定是 marginally relevant 还是 marginally irrelevant。

### 3.3 普适性的 RG 解释

为什么水和磁铁的临界指数一样？

因为在 RG 流中，无论微观哈密顿量的细节如何（几百个无关算符的不同初值），在流向不动点的过程中，所有无关算符都被衰减掉了。到达临界区域时，只有少数几个相关算符（t, h 等）非零。而相关算符的数量和性质完全由**不动点本身**决定（不动点属于哪个普适类），与微观起点无关。

这就是普适性的数学来源。

## 4. β 函数与流图

### 4.1 连续 RG 与 β 函数

在实际计算中，通常取 b = e^ℓ，ℓ ≪ 1 的无穷小 RG 变换，连续化成微分方程：

```
dg_i
──── = β_i(g₁, g₂, ..., g_N)
dℓ
```

其中 g_i 是耦合常数，ℓ = ln(b) 是 RG "时间"（ℓ 增大对应流向红外/大尺度）。{β_i} 统称 β 函数。

### 4.2 β 函数的零点和不动点

不动点 g* 满足：

```
β_i(g*) = 0    对所有 i
```

在不动点附近的线性化：

```
d(δg_i)
─────── =  Σ  (∂β_i/∂g_j)(g*) · δg_j
  dℓ       j
```

矩阵 ∂β_i/∂g_j 的本征值给出标度维数 y_i。

### 4.3 流向图

以二维耦合常数空间 (g₁, g₂) 为例：

```
        g₂
        │
        │    ← ← ← ← ← ← ← ←
        │    ↗           ↖
        │   ↗             ↖
        │  ↗  ·不动点      ↖
        │ ↗  （红外稳定）     ↖
        │↗                   ↖
        └────────────────────────→ g₁
```

箭头方向是 ℓ 增加的方向（流向红外）。

## 5. 一个完全手算的例子：一维 Ising 链的实空间 RG

这是能完整追踪 RG 步骤的最简单例子。

### 5.1 原始模型

一维 Ising 链（N 个自旋，周期性边界条件）：

```
Z =  Σ     exp( K Σ_i s_i s_{i+1} )
    {s_i=±1}
```

其中 K = βJ。不存在外场。

### 5.2 退耦（Decimation）：隔一个积掉一个

对偶数位自旋 s₂, s₄, s₆, ... 求和：

```
对于三个相邻的自旋 s₁, s₂, s₃:

 Σ     exp( K s₁ s₂ + K s₂ s₃ )
s₂=±1

= exp(K(s₁ + s₃)) + exp(-K(s₁ + s₃))

= 2 cosh( K(s₁ + s₃) )
```

因为 s₁ 和 s₃ 各取 ±1，s₁ + s₃ 只可能是 -2, 0, 或 +2。

我们需要把结果写成 exp(K' s₁ s₃ + C) 的形式，其中 C 是常数。

- 当 s₁ = s₃：原始和 = 2 cosh(2K) = exp(ln 2 + ln cosh(2K))
- 当 s₁ ≠ s₃：原始和 = 2 cosh(0) = 2 = exp(ln 2)

要求对两种情形都成立：

```
s₁ = s₃:  K' + C = ln 2 + ln cosh(2K)
s₁ = -s₃: -K' + C = ln 2
```

解得：

```
C = ln 2 + (1/2) ln cosh(2K)
K' = (1/2) ln cosh(2K)
```

### 5.3 RG 方程

```
K' = R(K) = (1/2) · ln cosh(2K)
```

这就是一维 Ising 模型（无外场）的精确 RG 递推关系。

不动点：
- K = 0 (T → ∞)：R(0) = 0，平庸高温不动点
- K → ∞ (T → 0)：R(K) ≈ K - (1/2) ln 2，强耦合不动点（但不是真正的不动点，因为每一步都在减小）

线性化在 K=0 附近：cosh(2K) ≈ 1 + 2K²，ln(1+2K²) ≈ 2K²

```
K' ≈ (1/2)·2K² = K²
```

所以从任何 K ≪ 1 出发，K 在 RG 流下迅速变小 → 流到 K=0 不动点。**结论：一维 Ising 模型没有有限温度的相变**，铁磁序只在 T=0 时存在。

这个精确的结果用 RG 自然地推导出来，展示了 RG 的威力。

## 6. 动量壳层 RG：从路径积分出发

在连续场论（ϕ⁴ 理论）中，实空间的退耦不方便。更常用的做法是在动量空间中对高能动量模式积分。

### 6.1 路径积分表示

以 d 维标量场 ϕ(x) 为例，作用量：

```
               ⌠
S[ϕ] =  ½      │  d^d x  [ (∇ϕ)² + r ϕ² + (u/12) ϕ⁴ ]
               ⌡
```

配分函数：

```
Z = ⌠ Dϕ  exp( -S[ϕ] )
    ⌡
```

### 6.2 将场分解为快模和慢模

引入动量截断 Λ（倒晶格尺度，来自晶格常数 a）：

```
ϕ(k) = 0  当 |k| > Λ
```

将场分成：

```
ϕ(k) = ϕ_<(k) + ϕ_>(k)

ϕ_<(k):  0 < |k| < Λ/b    （慢模，保留）
ϕ_>(k):  Λ/b < |k| < Λ    （快模，积分掉）
```

### 6.3 积掉快模

```
exp(-S_eff[ϕ_<]) = ⌠ Dϕ_>  exp( -S[ϕ_< + ϕ_>] )
                    ⌡
```

当 ϕ⁴ 耦合 u 很小时（在 d > 4 或接近上临界维数），可以用微扰论逐阶积分快模，得到有效作用量 S_eff。

### 6.4 重标度

定义新的动量和场：

```
k' = b k

ϕ'(k') = b^{-Δ_ϕ} · ϕ_<(k)
```

其中 Δ_ϕ 通过要求动能项 (∇ϕ)² 在重标度下保持不变来确定。

在 d 维空间中：

```
(∇ϕ)² 项:  d^d x (∇ϕ)² ∼ Λ^{d-2} ϕ²

在重标度 k' = b k 下:
d^d x → b^{-d} d^d x'
∇ → b ∇'
```

为使动能项在重标度下系数不变：

```
Δ_ϕ = (d - 2) / 2
```

### 6.5 微扰 RG：ϕ⁴ 理论的最低阶（单圈）

经过快模积分和重标度，耦合常数的 RG 方程在最低阶（单圈）下为：

```
dr
── = 2r + c₁ u Λ²            (c₁ 是正的常数)
dℓ

du
── = (4 - d) u - c₂ u²        (c₂ 是正的常数)
dℓ
```

其中 ℓ = ln b。

**第一个方程**：即使裸质量 r₀ = 0，快模的积分也会产生一个质量修正（c₁ u Λ² 项）。这就是著名的"二次发散"——必须精细调节裸 r₀（以 Λ² 的精度）才能保证在远低于 Λ 的尺度上 r 是小量。这是"自然性问题"（hierarchy problem）在凝聚态物理中的表现。

**第二个方程**：这是 ϕ⁴ 理论 RG 分析中的核心方程。

## 7. ϕ⁴ 理论的 RG 分析（Wilson-Fisher 不动点）

### 7.1 上临界维数

从 du/dℓ 方程看：

```
du
── = (4 - d) u - c₂ u²
dℓ
```

- **d > 4**：(4-d) < 0。对于小 u，线性项为负 → u 在 RG 流下衰减到零。高斯不动点（u=0）是稳定的。**上临界维数 d_c = 4。**
- **d < 4**：(4-d) > 0。小 u 在 RG 流下增长，直到非线性项 c₂ u² 与之平衡 → 出现非平凡的不动点。

### 7.2 Wilson-Fisher 不动点

在 d < 4 时，du/dℓ = 0 给出：

```
0 = (4-d) u* - c₂ (u*)²
→  u* = (4-d) / c₂
```

**u* ∝ ε（小量）！** 这正是 Wilson ε 展开的精髓：在 d = 4 - ε 维（ε ≪ 1）下，非平凡不动点的耦合常数是 ε 阶的小量，可以系统地微扰计算。

### 7.3 临界指数

在不动点 (r*, u*) 附近线性化，RG 矩阵的本征值给出两个相关指数：

**y_t**（温度方向，对应约化温度 t = (T-Tc)/Tc）：

```
y_t ≈ 2 - ε/3 + O(ε²)
```

关联长度指数 ν = 1/y_t ≈ 1/2 + ε/12 ≈ 0.58 + ...

**y_h**（外场方向）：

```
y_h ≈ 3 - ε/2 + O(ε²)   (在 d=3, ε=1: y_h ≈ 2.5)
```

然后所有其他临界指数都可以通过标度假定（scaling hypothesis）从 y_t 和 y_h 算出来：

```
α = 2 - d/y_t         (比热指数)
β = (d - y_h)/y_t     (序参量指数)
γ = (2y_h - d)/y_t    (磁化率指数)
δ = y_h/(d - y_h)     (临界等温线指数)
η = 2 + d - 2y_h      (反常维数)
```

这些就是你在量子临界文献中反复看到的临界指数。它们完全由 d、n、对称性决定——和微观哈密顿量（是否含氢键、是否有偶极矩）无关。

## 8. RG 如何解释量子临界现象

这是 RG 概念和你正在学的内容（非常规量子临界）最直接的连接。

### 8.1 量子相变的 RG 视角

量子相变发生在 T = 0，由非热力学参数 g（压力、掺杂等）驱动。量子-经典对应：

**d 维量子系统（T = 0） ⇔ (d+z) 维经典系统（T > 0）**

这里 z 是动力学临界指数：在量子临界点，空间关联长度 ξ 和时间关联长度 ξ_τ 的关系是 ξ_τ ∝ ξ^z。

这意味着你可以把一个 d 维的量子临界问题映射为一个 (d+z) 维的经典统计力学问题，而**温度 T 扮演了 (d+z) 维经典系统中有限尺寸的角色**。

### 8.2 Hertz-Millis 理论的 RG 分析

Hertz 的量子临界理论从巡游费米子耦合到序参量玻色场 φ 的模型出发：

```
S = S_fermion[ψ] + S_boson[φ] + S_coupling[ψ, φ]
```

核心操作：**积掉费米子**，得到一个只含玻色序参量的有效作用量：

```
S_eff[φ] =  Σ    ⌠ d^d q dω  (q² + |ω|/q^{z-2} + r) |φ(q,ω)|²
             α    ⌡
                   +  u ∫ φ⁴ + ...
```

关键：费米子被积掉后，其唯一作用是给玻色传播子提供了一个 Landau 阻尼项 |ω|/q^{z-2}。这就是为什么在 Hertz-Millis 理论中，量子临界点附近的行为只由序参量涨落决定——费米子是"沉默的旁观者"。

在 Hertz-Millis 框架下做 RG 分析：

- 有效维数（因为 Landau 阻尼）：d_eff = d + z
- 上临界维数变为 d_c = 4 - z（而不是经典 Ising 的 d_c = 4）
- 在 d=2、z=2（反铁磁 QCP）时，d_eff = 4，恰好处于上临界维数 → 高斯不动点稳定 → 对数修正

**预测的比热/温度指数**：C/T ∝ -ln T（对数发散，来自有效维数恰好=4）。

### 8.3 非常规量子临界：RG 给出完全不同的答案

但实验在 YbRh₂Si₂ 等材料中看到：C/T ∝ T^{-0.3}（幂律发散，不是对数），费米面在 QCP 处突变（不是连续）。

从 RG 视角看，这意味着一件事：**你不能直接把费米子"积掉"**。在 QCP 处，费米子本身变成了临界的——它的有效质量发散，准粒子权重 Z → 0。费米子和玻色子的 RG 流是**耦合**的。

一个推广的有效理论是：

```
S = S_fermion + S_boson + g ∫ ψ† ψ φ

加上一个动力学条件：
当 g 增大时，费米子的准粒子权重 Z(g) 流向零（近藤崩坏）
```

在这种情况下，RG 的 β 函数对于费米子-玻色子耦合 g 会出现一个非平凡的红外不动点——**相互作用的不动点（interacting fixed point）**——而不是高斯不动点。这个相互作用不动点属于一个全新的普适类，其临界指数与 Hertz-Millis 完全不同。

这就是"非常规量子临界"的 RG 本质：不动点的性质变了。

## 9. RG 和你已学内容的关系

### 9.1 BCS 超导的 RG 解读（你已知的）

BCS 理论中的能隙方程：

```
         ω_D
Δ = 2 ω_D exp( -1 / (N(0) V) )
```

从 RG 的角度看，电声相互作用耦合常数 λ = N(0) V 在 RG 流下有一个微小的正 β 函数——它在低能（低 ℓ）下流向更强的耦合（这个来自声子交换在低频下提供的有效吸引）。

更有启发的是 Polchinski / Shankar 的费米液体 RG：费米面的每个点附近，电子-电子散射有四种可能的动量结构（BCS 通道、零声通道、直接通道、交换通道）。在低能极限下，只有 BCS 通道的耦合常数是**边际相关（marginally relevant）**的——即使裸的 λ 非常小，在 RG 流下它会被对数增强：

```
λ(ℓ) ≈ λ₀ / (1 - λ₀ ℓ)
```

当 λ(ℓ) → ∞ 时（即 ℓ → 1/λ₀），超导不稳定性发生。这和 BCS 能隙方程给出的 Tc ∝ ω_D e^{-1/λ₀} 等价。

**RG 解释了为什么只要存在任意微弱的有效吸引，费米液体就是不稳定的**——这是 BCS 理论最深层的物理。

### 9.2 Eliashberg 理论和 RG

你熟悉的 Eliashberg 方程本质上是**在特定近似下（Migdal 定理：顶角修正正比于 √(m/M) ≪ 1）对电声耦合的 RG 流的自洽求和**。

Migdal 定理本身就是 RG 的一个实例——它告诉你电声耦合常数 g 的顶角修正（vertex correction）是**无关的**（被小参数 m/M 压制），所以你不需要对顶点做 RG 改进，直接解 Dyson 方程就够了。

对比之下，在强关联电子体系中，**Migdal 定理不成立**——因为配对胶水来自电子自身（自旋涨落），没有任何小参数压制顶角修正。这就是为什么你需要 DMFT（非微扰地处理局域顶角）而不是简单的 Eliashberg。

### 9.3 DMFT 和 RG

DMFT 可以看作一种**局域 RG**：
- 普通的 RG 在动量空间中做——依次积掉高能动量壳层
- DMFT 在**实空间局域性**上做文章——它精确处理了一个格点上的全部局域关联（所有的 Feynman 图在局域近似下都被保留了），而空间涨落作为"无关算符"在无穷维极限（d → ∞）下恰好消失

在有限维（d=2, 3）的真实材料中，DMFT 需要被拓展（cluster-DMFT, DΓA, DMF²RG 等），把空间涨落作为 RG 流中的"相关修正"加回来。这正是杨义峰老师组工作的方法论核心之一——用 cluster-DMFT 捕捉短程空间关联（在 RG 意义上——那些在 d=∞ 下是"无关"但在 d=2,3 下可能变成"相关"的算符）。

## 10. 总结：RG 的三种读法

RG 不是一套公式，而是一种**组织物理知识的方式**。你可以从三个角度"读"它：

### 读法一：计算工具
给一个微观哈密顿量 → 写出 β 函数 → 找不动点 → 线性化 → 得到临界指数。这是做具体计算时的操作流程。

### 读法二：分类体系
不动点 → 相关算符（决定普适类） → 临界指数（普适类内的普适量）。RG 把无穷多的微观哈密顿量归类到有限多个普适类。这是理解"为什么不同体系会有相同临界行为"的框架。

### 读法三：物理世界观
物理学的层次结构来源于 RG 流——高能的微观细节是"无关"的，在不同能标下被"洗掉"。留下的只有少数"相关"自由度。从原子核 → 原子 → 分子 → 凝聚态 → 流体力学，每一层都是上一层 RG 流的红外不动点附近的有效理论。

**在强关联电子体系中，RG 的第三种读法最为重要**：QCP 处，传统的"无关算符洗掉"逻辑被打破——费米子不再是旁观者，它自己也变成了临界自由度。理解这种新的"不动点"是什么、属于哪个普适类、用什么方法计算——这正是当前凝聚态物理最核心的问题之一，也是你进入杨老师组后将直接面对的问题。
