## 1. 紧束缚模型：从原子轨道到 Bloch 态

### 1.1 原子轨道基

考虑一个晶格，每个原胞中有多个原子轨道。以 CuO₂ 平面为例，我们关心的轨道有 Cu 的 3d(x²-y²) 轨道、O 的 2pₓ 和 2p_y 轨道。在实空间中，第 i 个原胞中轨道 α 的 Wannier 函数记为：

```
φ_{iα}(r) = φ_α(r - R_i)
```

这里 α 是轨道指标，不仅标记原子位置，也标记轨道角动量。比如 α = 1 可能对应 Cu 3d(x²-y²)，α = 2 对应 O(1) 2pₓ，等等。

### 1.2 Bloch 和

对 Wannier 函数做傅里叶变换，构造具有晶格平移对称性的 Bloch 和：

```
                    1
ψ_{kα}(r) = ───────────  Σ   e^{ik·R}  φ_{α}(r - R)
              √(N_cell)   R
```

这个 ψ_{kα}(r) 本身已经是 Bloch 波函数——它满足 Bloch 定理：平移一个晶格矢量 R' 后，ψ(kα)(r + R') = e^{ik·R'} ψ(kα)(r)。

### 1.3 紧束缚哈密顿量在 k 空间的矩阵形式

在基 {|kα⟩} 下，单电子哈密顿量是一个矩阵：

```
H_{αβ}(k) = ⟨kα| Ĥ₀ |kβ⟩

          =  Σ   e^{ik·(R_j - R_i)}  t_{αβ}(R_j - R_i)
            R_j

          =  Σ   e^{ik·δ}  t_{αβ}(δ)
             δ
```

其中 t_{αβ}(δ) 是实空间的 hopping 积分：

```
t_{αβ}(δ) = ∫ d³r  φ*_α(r)  Ĥ₀  φ_β(r - δ)
```

它表示从位置为 0 的 β 轨道跳到一个晶格矢量 δ 外的 α 轨道的跃迁振幅。

### 1.4 对角化得到能带

H_{αβ}(k) 是一个 N_orb × N_orb 的厄米矩阵。在每个 k 点对角化：

```
H(k) · U(k) = U(k) · ε(k)
```

其中 ε(k) = diag(ε₁(k), ε₂(k), ..., ε_{N_orb}(k)) 是能带能量（本征值），U(k) 的列是本征矢。

对角化后的 Bloch 态（带指标 n）：

```
|ψ_{nk}⟩ =  Σ   C_{nα}(k)  |kα⟩
            α
```

C_{nα}(k) = U_{αn}(k) 是轨道 α 在第 n 条能带中的展开系数。

### 1.5 轨道权重

第 n 条能带在费米面上某个 k 点的"轨道特征"由轨道权重给出：

```
w_{nα}(k) = |C_{nα}(k)|²

Σ_α w_{nα}(k) = 1   （归一化）
```

**这是对称性信息第一次进入的地方**：每个 Bloch 态携带了原子轨道的对称性信息。例如，如果在某个 k 区间，费米面附近的 Bloch 态主要由 Cu 3d(x²-y²) 轨道构成（w ≈ 1），那这个 Bloch 态就"继承"了 3d(x²-y²) 轨道的空间各向异性——在 kx/ky 平面内高度各向异性，沿 kx 和 ky 轴方向延伸最强。

## 2. Bloch 态的对称性分类：点群与不可约表示

### 2.1 点群操作对 Bloch 态的作用

设 g 为晶格点群的一个操作（例如绕 z 轴旋转 90°，记为 C₄）。g 同时作用在实空间坐标 r 和动量 k 上：

```
g : |ψ_{nk}⟩  →  Σ   D_{mn}(g)  |ψ_{m, gk}⟩
                  m
```

D_{mn}(g) 是一个矩阵，表示在固定 k 下，点群操作 g 把 Bloch 态 |ψ_{nk}⟩ 变成同一 k 下其他 Bloch 态的线性组合。如果 k 在布里渊区的高对称点上（例如 Γ 点、M 点），那么 gk = k（或等价于 k），此时 D(g) 构成**小群（little group）**的一个表示。

### 2.2 不可约表示——分类工具

群论告诉我们：任何一个表示 D(g) 都可以分解为不可约表示的直和。对于四方点群 D₄h（铜氧化物平面所属的点群），不可约表示包括：

| 不可约表示 | 常用代称 | 特征：C₄ 旋转下的行为 | 典型基函数例子 |
|-----------|---------|---------------------|--------------|
| A₁g | s 波 | 不变（+1） | 1, cos kx + cos ky |
| A₂g | g 波 | 不变 | sin kx sin ky (cos kx - cos ky) |
| B₁g | d(x²-y²) 波 | 变号（-1） | cos kx - cos ky |
| B₂g | d(xy) 波 | 变号（-1） | sin kx sin ky |
| E_g | d 波二重简并 | 二维表示 | (sin kx sin kz, sin ky sin kz) |

注意：B₁g 和 B₂g 在 C₄ 下都变号（特征标都是 -1），但它们在"关于对角线的镜面反射"下行为不同——这正是区分两类 d 波的方式。

### 2.3 这部分的关键结论

单电子 Bloch 态的对称性可以通过其轨道成分的不可约表示来分类。如果一个 Bloch 态在费米面上主要由 B₁g 对称的 Cu 3d(x²-y²) 轨道构成，那这个 Bloch 态本身也携带了 B₁g 的对称性信息。这并不会自动使超导配对变成 B₁g（d 波），但它塑造了**费米面的几何形状**和**费米面上态密度的分布**——这两者随后会通过配对相互作用影响 Δ(k) 的对称性。

## 3. 多体相互作用：在轨道基下的 Hubbard-Kanamori 形式

### 3.1 为什么需要多体相互作用

目前为止我们只处理了单电子哈密顿量 H₀，它给出了能带结构。但电子之间的库仑排斥 U 在 d 电子和 f 电子体系中很大（U ~ 5-10 eV，而带宽 W ~ 1-3 eV），不能当微扰处理。U 的存在从根本上改变了低能物理——它导致莫特绝缘态、近藤效应、以及超导配对。

### 3.2 Hubbard-Kanamori 相互作用

在 Wannier 轨道基下，局域的多轨道库仑相互作用最一般的形式（Kanamori 形式）为：

```
Ĥ_int =      U    Σ    n_{iα↑} n_{iα↓}
                   i,α

          +   U'   Σ    n_{iα} n_{iβ}
                   i,α<β

          +   J    Σ    [ c†_{iα↑} c†_{iβ↓} c_{iα↓} c_{iβ↑}
                   i,α<β
                        +  c†_{iα↑} c†_{iα↓} c_{iβ↓} c_{iβ↑} + h.c. ]

          +   J'   Σ    c†_{iα↑} c†_{iβ↓} c_{iα↓} c_{iβ↑}
                   i,α≠β
```

四个参数的物理含义：

- **U**：同一轨道上的库仑排斥（同轨道、反自旋的两个电子互斥）
- **U'**：不同轨道之间的库仑排斥
- **J**：洪特耦合（倾向于对齐不同轨道的自旋，交换相互作用）
- **J'**：配对跳跃项（pair-hopping）

对于球对称的 d 轨道壳层，参数满足关系：U' = U - 2J，J' = J。

### 3.3 用产生湮灭算符表达多体哈密顿量

完整的哈密顿量：

```
Ĥ = Ĥ₀ + Ĥ_int

Ĥ₀ =  Σ    H_{αβ}(k)  c†_{kασ} c_{kβσ}
     k,αβ,σ

Ĥ_int = （上面那个四参数形式的傅里叶变换到 k 空间）
```

## 4. 从相互作用到配对顶点：RPA 自旋涨落

### 4.1 物理图像

两个电子怎么配对？需要一种有效的吸引力。在常规超导体（氢化物）里，吸引力来自声子交换——电子 A 经过时极化晶格（正离子被吸引靠近），这个极化被电子 B 感受到，形成 A 和 B 之间的有效吸引。

在强关联体系中，电子之间的有效吸引来自**自旋涨落交换**——电子 A 的库仑排斥推开周围的自旋↑电子（因为它们和 A 的自旋方向相同），形成一个局域的自旋极化"云"。电子 B（自旋↓）感受到这个自旋极化云，被吸引过来。净效果是 A 和 B 之间的有效吸引。

### 4.2 裸磁化率（Lindhard 函数）

首先计算没有相互作用的裸磁化率（bare susceptibility）。在多轨道体系中：

```
χ₀^{αβγδ}(q, iω) =  ─ T  Σ   G^{0}_{αγ}(k+q, iν+iω)  G^{0}_{βδ}(k, iν)
                     N_k  k,ν
```

其中 G⁰ 是裸的（无 U 的）单粒子 Green 函数：

```
G^{0}_{αβ}(k, iν) =  Σ   C_{nα}(k) C*_{nβ}(k)
                     n   ─────────────────────
                             iν - ε_n(k) + μ
```

### 4.3 RPA 自旋磁化率

考虑相互作用 U 后，自旋磁化率在 RPA（无规相近似）层面得到重整化：

```
                 χ₀(q, iω)
χ_s(q, iω) = ──────────────────
              1 - U_s · χ₀(q, iω)
```

这里 U_s 是自旋通道中的有效相互作用矩阵（包含洪特耦合 J 的贡献），"·"表示轨道空间中的矩阵乘法。

当分母趋近于零时——即当 1 - U_s χ₀ ≈ 0 时——χ_s 发散。这对应于**自旋密度波（SDW）不稳定性**。在量子临界点附近，即使还没有实际的磁有序，χ_s(q, iω) 在某个特征波矢 q = Q（通常是 (π,π)）处变得非常大。

### 4.4 有效配对相互作用

通过交换自旋涨落产生的有效配对相互作用（在自旋单态通道中）：

```
V_{αβγδ}(k, k')  =  一个包含 U 和 χ_s 的矩阵表达式
```

在物理上更透明的简化形式（单带近似，忽略轨道结构）：

```
V(k, k') =  U  +  ── U² χ_s(k - k', ω=0)
                   2
```

第一项是裸的库仑排斥（在 s 波通道上不利于配对），第二项来自自旋涨落交换（在特定通道上提供吸引）。

**这是对称性信息第二次（也是最关键一次）传递的地方**：χ_s(q) 在哪个 q 处最强，取决于费米面的几何。如果费米面在 (π,0) 和 (0,π) 区域有大的态密度（nesting 条件），χ_s 会在 q = (π,π) 处最强。这个 (π,π) 的散射倾向直接选择了 d(x²-y²) 配对通道——原因见下一节。

## 5. BCS 能隙方程：配对对称性的本征值问题

### 5.1 线性化的能隙方程

在 T = Tc 附近，Δ(k) 趋于零。BCS 能隙方程可以线性化：

```
Δ(k) = -  Σ   V(k, k')  ──────────────  Δ(k')
           k'              2ξ(k')
```

其中 ξ(k) = ε(k) - μ 是正常态能带相对于费米能的能量，f(ξ) 是费米-狄拉克分布函数。

简化写法（在费米面上积分）：

```
              ⌠  dk'      1
Δ(k) = - λ ·  │  ───  V(k, k')  ─────  tanh(───)  · Δ(k')
              ⌡  v_F(k')         2            2k_B T
```

### 5.2 本征值方程

这是一个**积分本征值方程**。将 V(k, k') 在对称性基函数上展开：

```
V(k, k') =  Σ   λ_Γ · g_Γ(k) · g_Γ(k')
            Γ
```

其中 Γ 遍历点群的所有不可约表示，g_Γ(k) 是属于第 Γ 个不可约表示的基函数（一组正交完备函数）。

代入能隙方程：

```
       ⌠  dk'      1
Δ_Γ(k) = λ_Γ · │  ───  g_Γ(k) g_Γ(k')  ───  Δ_Γ(k')
       ⌡  v_F(k')                      2
```

这意味着如果 Δ(k) 具有 g_Γ(k) 的对称性（即 Δ(k) ∝ g_Γ(k)），那么它是本征值 λ_Γ 对应的本征函数。

**λ_Γ 最大的那个通道就是超导不稳定性首先发生的配对通道**——也就是实验上观测到的配对对称性。

### 5.3 为什么 d(x²-y²) 经常赢

现在我们可以明确地回答"为什么 d 轨道参与的体系常常给出 d 波配对"：

- Cu 的 3d(x²-y²) 轨道在 k 空间中沿 kx 和 ky 方向延伸最强 → 费米面在这两个方向上态密度大
- 自旋涨落 χ_s(q) 在 q = (π,π) 处最强（因为费米面连接 (π,0) 和 (0,π) 区域时有 nesting）
- 对于散 q = (π,π) 的配对散射：V(k, k') 在 k 和 k' 分居费米面相邻象限时最大 → 这恰好对应 Δ(k) 在相邻象限反号的 d(x²-y²) 波
- 同时，裸库仑排斥 U 在 s 波通道上直接起排斥作用（因为 s 波在实空间上是 on-site 配对），在 d 波通道上被节点"躲开"
- 所以 d(x²-y²) 通道（B₁g）的 λ 最大 → d 波配对

## 6. 基函数的具体形式：s 波、d 波到底长什么样

### 6.1 二维正方晶格（D₄h 点群）

在最近邻 tight-binding 的费米面上（接近圆形或方形），不可约表示的基函数在 k 空间的具体形式：

**A₁g——s 波（全对称）**

```
g_{A1g}(k) 有以下几种常见形式（从最简单到更复杂）:

(0) 各向同性 s 波：    g(k) = 1

(1) 扩展 s 波（extended s-wave）：
    g(k) = cos(kx a) + cos(ky a)

(2) 次近邻 s 波：
    g(k) = cos(kx a) · cos(ky a)

所有这些在 C₄ 旋转下都不变号。
```

**B₁g——d(x²-y²) 波**

```
g_{B1g}(k) = cos(kx a) - cos(ky a)

在 C₄ 旋转下：k → (ky, -kx)
  cos(ky a) - cos(-kx a) = cos(ky a) - cos(kx a) = -g_{B1g}(k)
→ 变号 ✓

节点位置（g=0）：kx = ±ky 的对角线上。四个节点。
```

**B₂g——d(xy) 波**

```
g_{B2g}(k) = sin(kx a) · sin(ky a)

在 C₄ 旋转下同样变号，但在关于对角线的镜面反射下行为与 B₁g 不同。
节点位置：kx = 0 或 ky = 0 的轴上。四个节点在轴线上。
```

**A₂g——g 波**

```
g_{A2g}(k) = sin(kx a) · sin(ky a) · [cos(kx a) - cos(ky a)]
（或更高阶形式）

在 C₄ 下不变号，但在镜面反射下变号。
```

### 6.2 为什么 cos(kx) - cos(ky) "看起来像 d 轨道"

d(x²-y²) 的实空间角分布是 Y_{2,2} + Y_{2,-2} ∝ (x² - y²)/r²。在 k 空间的小 k 展开下：

```
cos(kx a) - cos(ky a)
≈ [1 - (kx a)²/2] - [1 - (ky a)²/2]
= (a²/2) (ky² - kx²)
∝ -(kx² - ky²)
```

这就是 k 空间的 "x² - y²" 形式——和实空间中 d(x²-y²) 轨道的角分布形式完全相同。这就是它被命名为 "d 波" 的数学原因。

## 7. 自旋涨落 Eliashberg 方程：与电声 Eliashberg 的对应

你之前在氢化物超导中熟悉的是电声 Eliashberg 方程。这里给出自旋涨落版本的对应关系。

### 7.1 电声 Eliashberg 方程（你已知的）

```
                     ∞
φ(iω_n) = πT  Σ     ⌠  α²F(ω')    2ω'
              m     │  ────────  ─────────  ·  φ(iω_m)
                     ⌡   ω'    ω'² + (ω_n - ω_m)²
                     0
```

输入：Eliashberg 谱函数 α²F(ω)——由声子态密度和电声耦合矩阵元构成。

### 7.2 自旋涨落 Eliashberg 方程（新的）

```
                     ∞
φ(k, iω_n) = πT  Σ   Σ   V_{sf}(k-k', iω_n-iω_m)  Γ(k', iω_m)  φ(k', iω_m)
                  m   k'
```

核心区别：

| | 电声 Eliashberg | 自旋涨落 Eliashberg |
|---|---|---|
| 配对胶水 | 声子 | 顺磁振子（paramagnon） |
| 谱函数 | α²F(ω)（由声子谱决定） | α²F_sf(ω)（由 Im χ_s(q,ω) 决定） |
| 动量依赖 | 近似 k 无关（s 波） | 强烈的 k 依赖（各向异性配对） |
| 特征能量 | 德拜频率 ω_D（~meV - tens meV） | 自旋涨落特征能量 ω_sf（可到 ~eV） |
| Tc 上限 | 麦克米兰极限 ~30-40 K | 无硬性上限（可达 100+K） |

### 7.3 自旋涨落 Eliashberg 谱函数

```
α²F_sf(ω)  ∝   Σ    Im χ_s(q, ω)
                q
```

在反铁磁量子临界点附近，Im χ_s(q=Q, ω) 在低频非常强（近藤屏蔽即将瓦解、磁涨落发散），导致 α²F_sf(ω) 在 ω → 0 时有巨大的权重。这驱动了高 Tc。

### 7.4 McMillan 公式的对应物

在电声超导中，Tc 可由 McMillan 公式估算：

```
          Θ_D          -1.04(1+λ)
Tc  ≈  ─────  exp( ────────────── )
         1.45         λ - μ*(1+0.62λ)
```

在自旋涨落配对中，一个类似的半经验公式（Monthoux 和 Pines）：

```
Tc  =  ω_sf · exp( ───────── )
                       λ_sf
```

其中 λ_sf 由 χ_s(q,ω) 决定。

## 8. 补遗：DMFT 确定配对对称性的思路

杨义峰老师的 DMFT 方法提供了比 RPA 更精确、非微扰的处理方式。

### 8.1 DMFT 的基本逻辑

1. 从 DFT 出发，用 Wannier 投影构造多轨道的紧束缚 H₀(k)
2. 加上局域的 Hubbard-Kanamori 相互作用 H_int
3. DMFT 自洽循环：将晶格问题映射到一个 Anderson 杂质模型
   ```
   H_lattice → H_impurity (有效)
   ```
   自洽条件：杂质的局域 Green 函数 = 晶格 Green 函数在对角元上的取值
   ```
   G_imp(iω) = Σ_k G_lattice(k, iω)
   ```

4. DMFT 收敛后，得到重整化的单粒子 Green 函数 G(k, iω) 和自能 Σ(iω)

### 8.2 配对不稳定性：Bethe-Salpeter 方程

超导配对不稳定性由**两粒子 Green 函数**的发散来判定。在粒子-粒子通道中，Bethe-Salpeter 方程为：

```
          T
Φ(k, k') = ─  Σ   Γ(k, k'', q=0)  G(k'')  G(-k'')  Φ(k'', k')
           N  k''
```

其中 Γ 是两粒子不可约顶角函数（由 DMFT 杂质求解器给出，包含所有局域的顶角修正——注意 DMFT 的 Γ 是 k 无关的，在 cluster-DMFT 中则有 k 依赖——杨老师组常用 cluster-DMFT/CDMFT）。

当归一化后的 Bethe-Salpeter 核的最大本征值 λ_max 趋近于 1 时，超导不稳定性发生。

本征函数 Φ(k) 的对称性就是 Δ(k) 的配对对称性。通过将 Φ(k) 投影到各不可约表示的基函数上：

```
λ_Γ = ∫ dk  g_Γ(k)  Φ(k)
```

找出 λ_Γ 最大的那个不可约表示 → 确定了配对对称性。

### 8.3 DMFT vs RPA 的优势

- RPA 只在弱耦合极限下可靠（U/W ≪ 1），但实际材料中 U/W ~ 1-2
- DMFT 非微扰地处理了局域关联（包括洪特耦合 J 的复杂效应）
- DMFT 能够描述近藤屏蔽、准粒子有效质量重整化、以及它们如何随温度和控制参数演化
- 特别是，杨老师组的工作表明：DMFT 可以自洽地给出从反铁磁量子临界点到 d 波超导的完整相图——不需要像 RPA 那样手动输入 χ_s(q) 作为"外部配对胶水"

## 9. 总结：对称性信息的完整传递链条

从原子轨道的角动量到超导配对对称性的完整因果链：

```
步骤 1: 原子轨道
  ├─ 输入: 孤立原子的电子轨道（s, p, d, f）
  ├─ 对称性: 球谐函数 Y_{lm}，角动量量子数 l
  └─ 输出: 轨道有特定的实空间各向异性
       ↓ (晶体场劈裂 → Wannier 投影 → tight-binding 哈密顿量)
步骤 2: Bloch 态（单电子）
  ├─ 输入: 原子轨道 + 晶格结构
  ├─ 对称性: 点群不可约表示（Bloch 态在给定 k 点属于哪个 irrep）
  └─ 输出: H_{αβ}(k) 矩阵 → 对角化得到能带 ε_n(k) 和轨道权重 w_{nα}(k)
       ↓
步骤 3: 费米面
  ├─ 输入: ε_n(k) 中 ε = E_F 的等能面
  ├─ 对称性: 继承自 Bloch 态的轨道成分（比如 B₁g 主导 → 费米面呈四方形）
  └─ 输出: 费米面几何形状、nesting 矢量、态密度分布
       ↓ (加上库仑 U → RPA 或 DMFT)
步骤 4: 自旋涨落 χ_s(q, ω)
  ├─ 输入: 费米面 + Hubbard U + 洪特 J
  ├─ 对称性: χ_s(q) 最大的 q 矢量反映了费米面的 nesting 条件
  └─ 输出: 有效配对相互作用 V(k, k') 的 q 依赖结构
       ↓ (代入 BCS 能隙方程)
步骤 5: 配对对称性 Δ(k)（多体）
  ├─ 输入: V(k, k') + 费米面上的态密度
  ├─ 对称性: 能隙方程本征值分解 → 最大 λ_Γ 对应的不可约表示
  └─ 输出: Δ(k) ∝ g_Γ(k)，即超导能隙的对称性（s, d, p, ...）
       ↓
步骤 6: 实验可观测量
  ├─ 比热: d 波有节点 → C ∝ T²（vs s 波的 C ∝ e^{-Δ/T}）
  ├─ 穿透深度: d 波 → λ ∝ T（vs s 波的指数衰减）
  ├─ STM 隧道谱: d 波节点 → 零偏压电导峰
  └─ NMR 自旋-晶格弛豫率: d 波 → 1/T₁ ∝ T³（vs s 波的 1/T₁ ∝ T e^{-Δ/T}）
```

**核心信息**：对称性标签（s、d、p）在起点（单电子轨道）和终点（配对序参量）都被使用，但描述的是完全不同的物理对象。前者通过费米面几何和配对相互作用间接"传导"到后者——这是群论统一语言带来的结构美，不是偶然。
