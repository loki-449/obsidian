# DFT 基础

## 核心思想
> 将多体电子问题转化为单电子问题，
> 用电子密度 n(r) 代替多体波函数作为基本变量。

## 理论基础

### Hohenberg-Kohn 定理
1. 基态能量是电子密度的唯一泛函
2. 真实基态密度使能量泛函取最小值

### Kohn-Sham 方程
$$\left[-\frac{\hbar^2}{2m}\nabla^2 + V_{eff}(r)\right]\psi_i(r) = \epsilon_i\psi_i(r)$$

其中有效势：
$$V_{eff} = V_{ext} + V_{Hartree} + V_{XC}$$

## 交换关联泛函

| 类型 | 代表 | 适用场景 |
|------|------|---------|
| LDA | PW92 | 简单金属 |
| GGA | PBE | 大多数体系 |
| meta-GGA | SCAN | 更高精度 |
| Hybrid | HSE06 | 半导体带隙 |

> 氢化物超导计算通常使用 **PBE** 泛函

## 计算流程
建立结构 → 设置参数 → 自洽计算(SCF) → 收敛判断 → 提取物理量
## 关键收敛参数

| 参数 | 含义 | 氢化物推荐值 |
|------|------|------------|
| ENCUT | 平面波截断能 | 600~800 eV |
| KPOINTS | k点密度 | 0.2~0.3 Å⁻¹ |
| EDIFF | 能量收敛标准 | 1e-8 eV |
| EDIFFG | 力收敛标准 | -0.001 eV/Å |

## 局限性
- 带隙低估（LDA/GGA）
- 强关联体系失效
- 色散力描述不足（需 DFT-D3 修正）
