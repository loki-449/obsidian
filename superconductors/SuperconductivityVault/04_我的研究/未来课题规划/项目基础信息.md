## 所有脚本目录

| 目录 | 路径 | 用途 |
|------|------|------|
| VASP 公共库 | `calculation/vasp/scripts/lib/` | bootstrap/path_config/vasp_common/scf_common/cohp_common/elfcar_io/lobster_basis |
| opt 结构优化 | `calculation/vasp/scripts/opt/` | setup / make_poscar / make_potcar / submit |
| scf_ELF | `calculation/vasp/scripts/scf_ELF/` | CONTCAR→POSCAR + ELF.pbs |
| scf_cohp | `calculation/vasp/scripts/scf_cohp/` | deploy_scf/submit_scf/extract_cohp/run_lobster/check_lobster_basis |
| Bader | `calculation/vasp/scripts/scf_bader/` | ACF.dat 批量 Bader 电荷分析 |
| ELF 分析 | `calculation/vasp/scripts/elf_analysis/` | ΔELF 热点提取 / ELF 谷确证 / Bader-ELF-键长关联 |

## 在所有环境都可部署

- 脚本打包：把 `calculation/vasp/scripts/` 目录完整拷贝到目标集群的 `$VASP_SCRIPTS_ROOT`
- 部署配置：`deploy.env` 文件描述本地 vs 集群根目录路径（`VASP_SCRIPTS_ROOT` / `VASP_WORK_ROOT`）
- 脚本内部：所有路径变量通过 `lib/bootstrap.py` 导入 `load_deploy_env()` 注入
