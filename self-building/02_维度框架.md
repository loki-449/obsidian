# 维度框架：四个层面及相互关系

> 四个维度不是并列关系，而是以目标身份为核心的整体。以下描述它们在生活中的权重分配和相互作用。

---

## 四维结构

```
       ┌─────────────┐
       │  学术身份   │  ← 主维度（职业重心）
       │ （60%权重） │
       └──────┬──────┘
              │ 支撑
              ↓
  ┌─────────────┐  ┌─────────────┐
  │  身体根基   │  │  外在呈现   │  ← 支撑维度
  │ （20%权重） │  │ （10%权重） │
  └─────────────┘  └─────────────┘
              ↑
       ┌─────────────┐
       │  生活基底   │  ← 底层维度（承载一切）
       │ （10%权重） │
       └─────────────┘
```

**权重解释**：权重代表能量分配，不代表重要性。生活基底权重低但优先级高——没它其他维度无法持续运转。

---

## 相互作用关系

| 交互 | 影响 |
|---|---|
| 身体 → 学术 | 精力是理论深度的先决条件。长期低精力下不可能有深度理论思考 |
| 身体 → 外形 | 健康是优秀外形的基础，不可跳过 |
| 外形 → 学术 | 外在状态影响学术场合的自信度和他人感知 |
| 生活 → 所有 | 日常秩序紊乱时，其他三个维度都会偏移 |
| 学术 ↔ 方向 | 学术进展是方向收束最显性的检验场 |

---

## 时间分配原则（非硬性，仅参考）

| 场景 | 学术 | 身体 | 外形 | 生活 |
|---|---|---|---|---|
| 工作日（研究为主） | 60-70% | 15-20% | 5-10% | 10% |
| 休息日 | 20-30% | 30-40% | 10-20% | 20% |
| 低谷期 | 30% | 30% | 10% | 30% |

**低谷期分配的意义**：方向收束在手里的核心检验——低谷时是否主动降低学术预期、提高生活维护比例，维持整体不失衡。
