## 思想演变轨迹

### 从追求高效到追求长期

"以前：我要以最快速度成长。现在慢慢变成：我要成长很多年。这两个目标，对策略的要求完全不同。如果目标是三个月，燃烧自己可能有效。如果目标是三十年，系统稳定比瞬时输出更重要。"

### 哲学立场的确立

"我突然发现我在宏大叙事中接受了虚无主义的同时，依旧选择荒诞主义：既然一切都没有意义了，那一切也就都平等了，那我就可以理所应当的挑选我在意且喜欢的去在这个荒诞世界所坚持了。"

### 价值追问的演化

"我不认可人单纯是要为快乐而生存，我是价值意义的追寻者，但我现在在思考这份价值的要求是否太过于绝对了。"

"我现在是在思考，作为人应该体验的价值，和泛泛然将所有体验都价值化的行为。"

### 关于自我修正的自觉

"人怎么可能不改变，我说的言之凿凿，不过是叙述的失真带来了重点强调不够全面罢了，我又不可能在叙述过程中不失真的表达，我在强调尺度的原因也就是再说，我不认可所谓的言之凿凿，我认可的只是我对变化改变进步的心态，这相反是一直在拥抱改变。"

### 从"生存模式"到"生命状态"

"以后一直记住一句话：不要为了追求成长，把维持成长能力的自己消耗掉。"

"真正强大的系统，不是偶尔爆发出惊人的能力，而是在岁月里始终保有学习、修正、创造和热爱的能力。"

"命运负责把我带到不同的路口，而我负责决定站在路口时，自己已经成长成什么样的人。"

### 关于道德与约束

"我不是道德价值高，而是我知道当丧失道德的约束我会变成一种什么样的野兽，同时我也清楚如果我内心不认可并且遵守这样的存在，我无法去做真正的follower。"

"不是因为认为自己天然不会伤害别人所以选择善良；而是因为知道人类（包括自己）拥有产生破坏性的能力，所以选择约束。"

### 关于骑士浪漫主义

"我依旧还是向往人类群星闪耀时的辉煌，向往简单的骑士英雄主义，向往虽千万人吾往矣的人生价值和践行方式。"

## 持续存在的张力问题

| 张力 | 描述 |
|---|---|
| 宏观 vs 细节 | 快速掌控宏观局势，但细枝末节处理方式一直偏弱 |
| 结构 vs 生命力 | 底层逻辑和秩序感压到生命力，但想获得更多维度的"活人感" |
| 责任 vs 承受力 | 愿承担自己的全部责任，但思考"承担痛苦本身是否等于价值证明" |
| 完美主义 vs 开始 | 审美决定了辨识度，但也让很多事情无法开始 |
| 自我修正 vs 过度否定 | 修正能力强，但可能从修正滑向否定 |
| 非人感 vs 人性 | 运作模式像机器，但抽象思考（风向）提供了一些"活人感" |
| 价值追求 vs 绝对压力 | 追寻价值，但价值本身可能变成新的绝对化枷锁 |
