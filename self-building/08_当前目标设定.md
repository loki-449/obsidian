# 当前目标设定（2026-07-24）

> 从身份声明出发，拆解到具体的时间节点和数字指标。
> 目标存在的意义是给你方向，不是给你压力。
> 50% 完成 + 方向在自己手里 = 成功。

## 一、学术目标

### 1.1 知识体系（范围+结构）

**核心要求**：对超导领域研究图谱有体系性了解。

- 不需要具备具体公式的完整推导能力
- 但需要清楚了解：
  - 自己相关领域的知识边界
  - 研究重点与什么物理量/问题相关
  - 关键结论脱胎于什么公式
  - 不同体系之间的差别
  - 差别中通过哪些近似确定了研究尺度和范围

**状态判断**：能在白板上无参考画出自己领域的研究图谱，标注关键方程、近似条件、体系边界。

**时间预估**：持续积累，贯穿博士阶段。博一结束前形成自己的"领域地图"v1.0。

### 1.2 产出目标（3年）

| 指标 | 值 |
|---|---|
| 总论文数 | ≥2 篇（导师要求高，不水文章）|
| 质量要求 | 学到真东西，反映自身努力和效率 |
| 时间窗口 | 3 年内完成 |
| 导师背景 | 要求高，不水文章。所以目标是"在他的手里学到真的东西以后，通过自身努力提高效率" |

**短期里程碑**
- 完成手里正在处理的工作
- 开始文章撰写
- 三个月内：对应工作内容有明显变化和进展

## 二、身体目标

| 备注 | 肌肉量高，外形像同龄110-120斤女性 | 保持肌肉量 |

### 2.2 运动

| 频率 | 每周 3-5 次 |
|---|---|
| 力量训练 | 每周至少 3 次 |
| 单次时长 | 含热身拉伸 ≥ 30min |
| 周总时长 | ≥ 150min |
| 每日安排 | 约 1h（含洗漱准备总长约 2h） |

### 2.3 健康认知（重要）

> S 功能偏弱——对自身的不适缺乏明确感知。家人也不善于观察自身健康状态，习惯于在牺牲身体健康和心理健康基础上去向外探索。

**需要建立的能力**：
- 学会感知和解读身体的信号（不适、疲劳、情绪低落）
- 区分"真实的累"和"Ni 路径锁定的惯性消耗"
- 建立健康监控习惯（定期体检 + 自检清单）

### 2.4 作息与心理健康

- 克制熬夜需求（熬夜往往是报复性或Ni发散的结果）
- 关注心理健康
- 不报复性生活（不因一天的低效而疯狂补偿）

## 四、作息与时间分配

### 4.1 每日时间结构

| 项目 | 时长 | 说明 |
|---|---|---|
| 高效工作 | <6h | 超过6h对大脑有损伤（研究依据） |
| 低效工作/辅助 | ~2h | 文献整理、数据归档、沟通等 |
| 总工作时长 | 8h | 含高效+低效 |
| 健身 | 1h | 含换装，外带洗漱共2h |
| 护肤穿搭 | 2.5h | — |
| 睡眠 | 7-8h | — |
| 三餐/通勤/休息/缓冲 | ~3-4h | 余量 |

> 总时长 = 20-21h，剩余 3-4h 为弹性时间。

### 4.2 典型日程结构（参考）

```
晨间（2.5h 护肤穿搭）
  ├── 护肤+化妆
  └── 穿搭准备 → 开启routine

工作（8h，含高效<6h + 辅助~2h）
  ├── 高效块 A（90min）
  ├── 高效块 B（90min）
  ├── 高效块 C（60-90min）
  └── 低强度工作（文献/整理/归档）

下午/晚间健身（1h）

洗漱（1h，含健身后）

晚间（护肤+放松+准备第二天）
```

## 五、方向收束判断标准

| 维度 | 判断方式 |
|---|---|
| 根本问题 | 是否还在自己坚持的路上努力，并且有所产出？|
| 产出匹配 | 产出的量是否符合这段工作时间内的需求？|
| 3个月检验 | 对应工作内容是否有明显变化和进展？|
| 日常检验 | 今天的每个选择，是让方向更清晰了，还是更模糊？|

**核心原则**：方向收束 ≠ 100% 执行。方向收束 = "我知道我在哪条路上，而且我知道这是我自己选的。"
